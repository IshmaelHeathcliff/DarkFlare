# 角色属性

当前项目登记了 21 个属性。稳定 ID 使用小写 `snake_case`；旧文档中的 `Health`、`CriticalMultiplier`、`Defence` 等 PascalCase 标识不再使用。

## 当前计算层

| 计算方式 | 规则 | 当前支持范围 |
| --- | --- | --- |
| 附加值 `Flat` | 在基础值上直接加减 | 普通属性与伤害 |
| 提高值 `Increase` | 普通属性与造成伤害会先同类相加，再按百分比乘算 | 普通属性、伤害与承受伤害 |
| 总增值 `More` | 每项分别乘算 | 普通属性、伤害与承受伤害 |
| 覆盖值 `Override` | 覆盖乘区前的属性值 | 非伤害的角色全局属性 |
| 伤害转换 `Conversion` | 将来源伤害的一部分转换为目标类型，总转换率最多 100% | 伤害管线 |
| 额外获得 `GainAsExtra` | 按来源伤害比例额外获得另一类型伤害 | 伤害管线 |

普通属性当前遵循“基础值经过附加或覆盖后，再结算提高值与总增值”。伤害先转换与获得额外伤害，再为每个伤害包结算附加值、提高值与总增值。目标承受伤害是当前例外：其提高值与总增值都会逐项乘算，尚未形成与其他属性一致的乘区语义。

旧设计中的“固定值在所有乘区后追加”尚无对应计算方式，不应作为当前规则。属性配置中的最小值与最大值主要用于定义和校验；除抗性等玩法明确处理的属性外，不应假设所有属性都会自动按配置范围截断。

## 已决定

- 属性稳定 ID 统一以本页 21 个小写 `snake_case` 标识为准。
- 暴击倍率统一表述为“暴击伤害”，基础倍率为 100%，属性值表示额外百分比。
- 混沌伤害与混沌抗性属于当前基础类型，不再标为远期候选。

## 待验证

- 魔力、力量、敏捷、智力、命中、闪避与暴击率接入实际玩法后的具体公式。
- 普通属性的覆盖值与多个来源叠加时是否需要更明确的优先级。

## 开放问题

- 是否仍需要增加乘区后的“固定值”计算层。
- 基础属性最终是直接提供战斗收益，还是只作为装备与技能需求。
