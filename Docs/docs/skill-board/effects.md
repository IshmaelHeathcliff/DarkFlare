# 棋盘天赋与火焰效果

`SkillBoardEffects.Resolve` 是纯投影入口：消费实际安装状态和成长激活记录，输出角色全局修改器与按火焰实例 ID 隔离的局部修改器。查询不点亮、重掷或改写棋盘。`FlameSteps` 同时暴露每枚可用火焰到已点亮图节点的只读最短步数，供玩家详情与范围高亮使用；与修改器筛选共用一次 BFS。技能入口见[手动技能](manual-skills.md)。

## 生效与距离

- 柴薪未点亮时，不提供全局 / 局部词条，其火焰也不可用。普通天赋还须自身点亮；裂缝不另外花点。
- 天赋 Radius = 0 表示全局，按柴薪 / 节点身份只加入角色一次；正数表示局部范围。
- 图使用已点亮天赋、大柴薪中心和已点亮柴薪裂缝；内部保存的显式连线与跨柴薪裂缝连接每条均为 1 步，跨空格长边也为 1 步。未点亮天赋阻断路径。
- 从火焰中心做无权最短路；天赋从自身节点、余烬从所在裂缝到火焰，距离不超过范围时生效。无路径不生效；环、多入口按最短路处理，旋转 / 平移不改变连线身份。中柴薪空白中心不生成节点。
- 余烬只允许占未连接裂缝，与连接互斥。所属柴薪点亮且目标火焰可用后，才沿有效网络提供效果。

火焰自身的隐式和显式词条只作用于自身实例；余烬和局部天赋不进入角色全局修改器，也不作用于没有棋盘中心的武器普通技能。武器普通技能仍接受角色全局天赋及既有合法装备效果。

## 事务与攻击

成长和棋盘事务在预检中准备最终 Actor 效果，提交时一并替换 `skill_board` 与 `player_growth` 来源、棋盘 / 成长状态，清理无效技能槽后才通知。失败保持旧状态，不靠事件回调顺序修复投影。恢复从相同权威记录重建，不重复保存或恢复一份派生修改器。

攻击将全局与该火焰的局部词条按既有标签、Scope 和伤害规则解析；局部暴击等非伤害属性也只在该次攻击生效。`AttackSnapshot.FlameInstanceId` 表示火焰，原 `SourceItemId` 仍表示武器伤害所有者，不能相互覆盖。发射后冻结词条与命中状态规则，飞行中换盘不修改已发出的快照。

`ModifierOriginKind.Talent / Flame / Ember` 保留稳定来源身份，解释显示本地化物品名称。开发窗口可查看具体来源；属性详情分别列出每枚活跃火焰的局部来源，避免把同定义火焰合成一个技能。

当前棋盘配置只支持原生修改器，并明确禁止 `ProvidedStatus`。所有权和激活资格由棋盘 / 成长 Validator、Mapper 与 Restore Preparer 证明，原生效果幂等重建；没有新增无消费者的 Talent `IStatusSourceRestoreProvider`。Talent 来源维持状态层仍不受支持，未来开放该配置时须同时实现来源提供方与恢复合同。

## 回归

`PlayerSkillsTests` 覆盖长边计一步 / 含边界、余烬未点亮阻断、无路径、旋转、同定义火焰隔离、局部暴击快照和全局来源重建一次。已有几何、成长与安装事务测试继续覆盖环 / 跨根、断根拒绝、过期预览、旋转 / 重连和退款；保存 / 连续 Session 测试覆盖恢复及资源生命周期。[阶段四证据](../plan/archive/0.7.1/acceptance/manual-skills/README.md)记录当次实际结果与未执行项。
