# 棋盘道具首轮图标合同

本组用于阶段二道具识别；阶段五的正式棋盘继续复用这组图标及既有皮肤。参考已有暗色 UI 与金属边线，不替换旧装备资产。通过 Unity MCP 的 Editor 脚本逐个绘制独立 PNG，先检查大柴薪样图，再展开其他成员；不使用图集拼图或切片。

固定合同：生成与交付均为 128×128 RGBA，完整画布，无缩放 / 裁剪。主体最长边 72–100 px，四边至少留 12 px；alpha 覆盖 0.08–0.65，光学中心 x=54–74、y=52–82。每种角色固定轮廓：柴薪为六角天赋盘，火焰为单团火，余烬为有裂纹的炭石，能量瓶为带金属口的储能瓶。容量档位用环纹区分；三种柴薪用天赋圈数量区分。此组不同角色不作动画帧大小一致性要求。

导入：Sprite Single、Full Rect、中心 Pivot、PPU=128/1.5、Point、无压缩、无 mipmap、sRGB、透明背景，Transform=(1,1,1)。唯一 Sprite GUID，加入既有物品 Addressables 分组；八个配置分别绑定独立图标。正式玩家展示使用原有格子尺寸、详情与商店布局，不改变碰撞。

自动审计、原生像素样图与 Editor / PlayMode 证据在阶段二验收目录记录。
