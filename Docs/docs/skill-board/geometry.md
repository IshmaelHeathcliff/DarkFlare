# 技能面板几何与柴薪生成

本模块提供三尺寸柴薪的纯规则、确定性布局生成及 Editor 调试预览。正式道具安装 / 交易 / 存档、点亮、能量成长和手动施法仍由[0.7.1 后续阶段](../plan/alpha-0.7.1-skill-board-plan.md)接入；放置校验不修改玩家状态。

## 坐标与固定占位

`HexCoordinate` 使用轴坐标 q / r，s = -q-r；距离为三轴差绝对值的最大值。一档旋转为 `(q,r) → (-r,q+r)`，每档 60°。坐标、平移、旋转、倍乘与距离超出整数范围时明确抛出 `OverflowException`，不会回绕到合法位置。

`SkillBoardGeometry` 提供中心 7 格保留区和六个相距中心 16 格的根。大主体半径 2 共 19 格，中半径 1 共 7 格，小为 `(0,0)`、`(1,0)`、`(0,1)` 的三角形，三格两两相邻。空格和大 / 中中心均参与碰撞；根距不是棋盘外边界。

几何处于 `Assets/Scripts/Runtime/Gameplay/SkillBoard/`，使用现有 Runtime 程序集，不依赖 UI、Session、物品或 `GameArchitecture`。Editor 工具位于 `Assets/Scripts/Editor/SkillBoard/`。

## 布局与连线

`FirewoodLayout` 保存尺寸、种子、生成合同版本、节点及显式无向边；集合是独立只读副本。节点 ID 按固定局部槽命名 `outer_i` / `inner_i`，大中心使用保留身份 `center`，不计入天赋 / 裂缝总数。`FirewoodPlacement` 只持布局引用、安装身份、锚点与六档旋转，位置变换不会改动节点身份或重新生成。

大 N 9–15、C 1–6 且 C 不超半数，内圈普通天赋 L 1–3 计入 N；大 N 15 必须 L 3，裂缝仅在外圈六角。中 N 4–6、C 1–3 且不超半数，中心保持空；小 N 2–3、C 1–2，允许 N 2 / C 2。

生成的外圈按环序连接实际节点，留空格可由显式边跨越；大中心经每个内圈天赋连接最近的外圈节点，同距离按节点 ID 排序。小三角形连接实际节点，2 节点用一条边，3 节点成环。连线不新增节点、碰撞格、天赋效果或已花点状态，中中心不是火焰插槽。

`Validate()` 检查数量、节点 / 身份重复、主体范围、裂缝位置和方向、缺失 / 重复边、连通性及大中心 / 内圈关系，返回带 Code、Subject、可选位置的中文问题。空格不打断边，空间相邻也不自动建立边。

## 端口与放置预检

大 / 中裂缝沿径向向外一格；小裂缝方向由[生成配置](../config-reference/skill-board.md)明确限定。未连接时，外伸格参与完整占位。

连接要求两件裂缝格相邻、方向互相指向、每个裂缝最多连接一件。端点落在对方裂缝上，连接后不保留额外外伸格，双方主体与节点身份仍独立。大可接中 / 小，中可接小，小可接小；大接大和中接中不合法。

`SkillBoardPlacementValidator.Validate(placements, connections, requireLargeRoots)` 先验证输入与固定主体，再证明端口配对，将有效连接端点合并到对方裂缝，最后检查未连接外伸格。中心保留区始终受保护；`requireLargeRoots = true` 额外限制大柴薪锚点为六个根，默认 false 供相对几何诊断。正式安装须启用根资格并增加所有权事务。

`FindConnections` 提供按稳定安装 / 节点身份排序的双向配对候选，实际合法性仍由 `Validate` 判断；候选发现不改变拓扑。投影溢出时该辅助方法抛出 `OverflowException`，`Validate` 则返回 `coordinate_overflow`；预览统一显示失败并停止绘制无效坐标。显式连接列表可成环，不选唯一父节点。未知裂缝、错尺寸、单向指向、一个裂缝接多件、共享第三格、主体 / 空格重叠和未配对外伸冲突均失败；失败不修改输入。

断开或旋转必须预检新的完整最终态。单纯删除连接但不移开相邻主体，会因恢复的外伸格落入对方主体失败；后续安装事务不能先删除连接再处理碰撞。

## 生成与复现

`FirewoodGenerator.Generate` 显式接收尺寸 / 种子，数量 0 表示随机，非零表示精确约束。先枚举合法 N / C / L，依次按 N、给定 N 的 C、给定 N/C 的 L 分层等概率选择。非法请求返回错误，不修剪裂缝、降低总数或无限重试。

裂缝候选只枚举外围角 / 三角顶点及允许方向，最大 64 个槽掩码，小方向展开有限。对称评分先比较非恒等旋转数，再比较反射数，再比较最小裂缝间距；方向与端口位置一起评价。大 / 中用六重对称群，小用三角形三重对称群。评分最高的端口布局归并旋转类，类与其可用朝向分别等概率抽取；普通天赋从剩余槽无放回选择，不要求对称。

反射仅用于评分，不作为玩家翻面操作，也不合并镜像变体。候选与类排序使用固定槽 / 方向顺序和 Ordinal 坐标键；小三角形绕重心转 120° 后重定位到固定三格。每次生成从当前配置构建有限候选，无跨配置缓存。

生成协议 `ContractVersion` 当前 1。数量、裂缝类 / 朝向、外圈普通节点和内圈位置使用互不影响的子种子，沿用稳定混合与 `System.Random`，不消费 Unity 全局随机或 GameplayRandom 通道，不写共享 SO。相同配置内容 / 种子 / 协议得到同布局；后续物品应保存实际布局，以免协议升级重掷历史实例。

## Odin 调试入口

菜单 `DarkFlare/技能面板/柴薪几何预览`。Odin 参数面板可选生成配置、尺寸 / 数量 / 种子、两件锚点和旋转；UI Toolkit 画布消费同一布局与预检结果，显示主体空格、天赋连线、裂缝、未连接外伸格与失败格。布局资产位于 `Assets/UI/SkillBoard/`。

- “双向连接样例”：大 A 锚点 `(16,0)`、中 B 锚点 `(20,0)`，相邻裂缝双向连接，最终占位 26 格。
- “共享第三格失败”：B 移到 `(21,0)`，两外伸格落在中间同一格，报 `extension_overlap`。
- 可旋转 A、检查大柴薪根资格、显示中心 / 六根；点击格子查稳定节点身份与外伸目标，滚轮缩放，右键 / 中键平移。
- 生成报告显示候选数、最优候选数、旋转类、对称评分、耗时及具体错误；预览不创建 Scene / 玩家状态，也不分配天赋效果。

窗口关闭释放 Odin PropertyTree 并取消项目变更监听。新建 / 重开窗口使用独立预览数据；配置编辑后生成使用当前内容，已有布局不被反向修改。当前仅为开发工具，正式玩家界面、本地化和手柄操作在后续阶段交付。

## 回归入口

`SkillBoardGeometryTests` 保护坐标溢出、合法数量全集、对称性、确定性 / 随机隔离、跨空格连线、不可变布局、完整占位、端口失败及六件闭环网络。字段覆盖与正式配置校验扩展既有入口；测试按模块维护，截图 / 采集脚本不作为永久运行测试。
