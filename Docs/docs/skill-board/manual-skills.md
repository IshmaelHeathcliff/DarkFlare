# 武器普通技能与六火焰槽

2026-10-26，`0.7.2-alpha.1` 已交付按住连放、大剑三投射物与每枚一次穿透；core v14 接续旧内容，Save Schema 12 保持。当前行为与[阶段验收](../plan/archive/0.7.2/acceptance/continuous-casting/README.md)一致。

0.7.1-alpha.4 已接入手动技能、冷却、棋盘效果及保存。阶段五已交付[玩家棋盘与分配界面](player-board.md)，Odin 开发窗口继续用于调试。范围与来源规则见[棋盘效果](effects.md)，当次验证见[阶段四验收](../plan/archive/0.7.1/acceptance/manual-skills/README.md)。

## 来源与分配

当前装备武器的 `ItemBaseDefinition.NormalSkill` 提供普通技能，使用独立 Attack，不需要柴薪、火焰或成长点。新角色沿用既有起始武器，六槽初始为空；卸下武器后普通技能不可用。场景 PlayerSkill 和旧 Configure 参数保留兼容 / 预热入口，不再决定玩家能力。

六个槽只保存已安装在大柴薪中心、且所属柴薪已点亮的火焰实例 ID。同一火焰再次分配会原子移槽，旧槽清空；同定义的不同火焰可独立分配。取回火焰时，在棋盘提交的最终态清除对应绑定，预览或失败不清槽。

玩家棋盘的六槽使用紧凑入口显示真实绑定与占用标识；选中后展开技能、耗蓝、状态、冷却及有内容槽的清除动作。选择已点亮火焰后按槽仍可直接分配，清槽后焦点回该槽；这些表现变化不改变六槽保存与输入规则。

| 操作 | 键鼠默认 | 手柄默认 |
| --- | --- | --- |
| 武器普通技能 | 鼠标左键 | 西键 |
| 火焰槽 1 / 2 | 1 / 2 | 东键 / 南键 |
| 火焰槽 3 / 4 | 3 / 4 | 左肩键 / 右肩键 |
| 火焰槽 5 / 6 | 5 / 6 | 左扳机 / 右扳机 |

七个入口均可在设置中重绑定。0.7.2 第一阶段接入短按首发与按住连放：有效按住期间，冷却结束且法力 / 动作允许时继续；松开不补发，不积攒欠发次数。没有有效按住时，冷却结束、遇敌、进图、复活和读档不会自动施法。鼠标按当前指针方向，手柄按右摇杆方向，每次发射重新取瞄准；方向为空沿用本次角色上次有效方向，初始向右。移动和自动目标查询不覆盖瞄准。Glyph 偏好只决定显示。

普通技能优先，再按火焰槽 1–6 的稳定顺序复核共享法力，各通道独立冷却。窗口、暂停、Shell、失焦 / 挂起、重绑定、设备移除、死亡、切图和 Session 结束使旧输入失效，恢复后须释放再按。换武器 / 换槽 / 取回只取消对应来源的保持意图，同帧换回也不复活；暂时无蓝或动作受限则在原按住仍有效时等待恢复。

## 运行态与提交

`PlayerSkillsModel` 保存六槽和普通技能通道冷却；`PlayerSkillStateRegistry` 验证来源、分配和施法。普通技能冷却在换装 / 卸下时继续保留；火焰冷却放在该道具的 `SkillBoardItemState`，换槽、取回、交易后仍随实例保留。两者使用玩法时间，暂停不推进。

Controller 捕获来源 ID、槽位、按下代次、输入世代和地图 owner，使用组件作用域中的单一可取消 UniTask 在帧末调度，允许 UI 消费同次点击。轻量技能 Query 读取真实冷却；命令仍复核当前玩家 / Session、存活、输入、暂停、来源、冷却、法力及合法伤害来源。HUD 点击既不能首发，也不能建立后续连放；指针移入可交互 HUD 时终止当前鼠标保持意图。

沿用 `FireProjectileCommand` 和预热的 Addressables。整组投射物先准备，准备期不碰撞 / 结算；全部成功且提交条件仍有效后才扣一次法力、启动一次冷却、发出一次攻击通知。空槽、来源过期、无蓝或组内任一枚失败不产生这些变更，已创建对象立即停用并通过地图注册表回收。生成失败不承诺已取得的根种子回退。`SkillCastResult.Projectiles` 与 `PlayerSkillCastEvent.Attacks` 提供只读整组结果，旧 `Projectile` / `Attack` 继续指向序号 0。

每次施法只消费一个攻击根种子；第 0 枚沿用旧种子，其他枚按稳定序号派生，各自冻结伤害、命中 / 暴击与来源。每枚独立记录已结算 Actor，穿透数表示额外目标数量；合法敌人的闪避同样消耗一次，友方 / 死亡 / 未登记目标不消耗。同 Actor 多碰撞体和事件重入不重复结算，不同投射物仍可分别结算同一目标；后续目标继续使用该枚的冻结快照。

Controller 通过 `AssignPlayerSkillCommand`、`CastPlayerSkillCommand` 与只读 `GetPlayerSkillsQuery` / `GetPlayerNormalSkillQuery` 接入。兼容读取器和底层 synthetic Actor 测试入口不参与正式 Player 的能力决策。技能 Prefab 在 NewGame / Restore 中按内容目录预热，取消和资源归属沿用 Session。

## 内容与持久化

正式大剑对应 `skill:great_sword_normal`（间隔 0.6 秒、耗蓝 1、速度 12、半径 0.16），core v14 调整为中心 / 左 10° / 右 10° 三枚、每枚额外穿透一个目标；其他单枚参数保持。战斧对应 `skill:war_axe_normal`（0.85 秒、耗蓝 2、速度 9、半径 0.24），维持单枚零穿透。两者使用已有投射物 Prefab 和装备武器伤害来源，尚未扩展独立近战动作表现。火焰沿用实际实例保存的技能与词条，不随默认大剑增强自动改变。

core v13 登记这两个技能；Save Schema 12 保存 `Run.Player.Skills.FlameSlots`、普通技能剩余冷却及物品扩展中的火焰剩余冷却。11→12 将已发布 `skill:basic_projectile` 的旧等待时间迁入普通技能，按当前武器配置取能力，六槽为空；不补物品或点数。无武器时保留不可用状态及等待时间，重新装备后可用。未知旧技能缺少映射时明确拒绝。

恢复预检校验六槽长度、唯一激活火焰、所有权、合法冷却与内容。Detached 火焰在预热期间冻结保存的剩余时间，最终提交才启动时钟；恢复成长 / 全局效果后再恢复绝对资源。当前 Schema 缺少技能字段会失败，不按历史档补默认。Settings Schema 1、地图 V4 保持。

## 查看与验证

运行 Session，打开 `DarkFlare/Debug/柴薪安装与能量瓶`。安装并点亮大柴薪、嵌入火焰后，填写“道具实例 ID”和“火焰技能槽（1–6）”，点击分配；清槽使用相应按钮。右侧只读快照显示分配、冷却和局部来源，所有变更调用正式 Command。

HUD 将独立普通技能和六槽合为紧凑图标区，常驻真实绑定、不可用短提示、冷却遮罩与秒数；名称、耗蓝和完整状态进入鼠标悬停说明。普通技能图标来自当前武器，火焰来自真实实例。技能热点与说明消费鼠标点击和旧保持；键盘 / 手柄仍按原绑定施法，详情沿既有菜单路径查看。进入窗口 UI 时隐藏火焰条，保留资源和普通技能；属性详情解释各火焰局部来源。长期回归集中在 `PlayerSkillsTests`、`ApplicationInputServiceTests`、保存测试和现有 PlayMode UI / 资源套件，临时采集只留归档证据。
