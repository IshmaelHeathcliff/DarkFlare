# alpha 0.3.0：统一物品操作与事务

> 状态：已完成；2026-09-08
> 上位计划：[独立窗口与交互拆分](../alpha-0.3.0-independent-ui-windows-plan.md)

## 交付与边界

接通交互合同中的移动、穿脱、购买、出售、打造放入 / 取回及明确世界丢弃。鼠标拖放、右键和手柄提交相同意图，提交前重新验证可见来源、实例、Session 与目标。商店 / 打造不可打开时继续隐藏顶部页签。

代表视觉组件在本切片后制作；本次沿用现有窗口风格，补充真实操作区、动作菜单和本地化反馈。属性解释、完整 HUD / 皮肤、十槽装备内容仍按后续阶段实施。

## 实施顺序

1. 领域事务：指定格购买无自动换位，发布事件前完成库存 / 背包 / 金币变更；世界丢弃先准备有效拾取物与位置，再转移归属，失败保持原物品。拾取提交清除世界归属，防止同帧重复拾取及快照双归属。
2. 共享输入：将全部来源纳入宿主的单一拖放与动作路由，包含商人物品、单窗玩家来源、装备与打造槽；移除旧入口重复消费。保留按格放置与跨面板几何导航。
3. 动作目标：指定背包格、兼容装备槽、买入 / 出售区、打造槽 / 取回区和丢弃区。预览不执行事务，显示动作、价格与失败原因；戒指明确选槽，丢弃通过明确动作入口。
4. 生命周期：关闭、暂停、Shell 接管、来源失效、设备断开及 Session 结束取消未提交操作；成功或失败后恢复有效焦点与唯一高亮。
5. 验证收尾：补充现有交易、拾取 / 存档与真实 UI 输入回归；三语言组合检查操作文字和菜单边界。运行项目两个测试程序集，清理一次性工具，更新模块文档与验收记录后归档本计划。

## 成功标准

- 相同意图在拖放、适用右键及手柄路径产生相同结果，单窗和背包组合均可操作。
- 精确购买失败不扣钱、不移库；非法放置、满包、权限失效和重复提交不丢物、不重复成交。
- 打造取回新格先完成移动再释放占用；失败仍在打造槽，取回原格不迁移物品。
- 丢弃保留实例、词缀和种子，生成失败无损；拾取物归属唯一、可重新拾取，保存继续后不会原地自动拾回。
- 导航使用实际方向和有效区域；拖动 / 菜单只有一个处理者，详情与唯一物品高亮不被后台窗口夺取。
- 新增长期测试只保护事务、输入可达与归属 / 生命周期合同，临时截图和诊断代码验证后清理。

## 交付结果

- `ItemInteractionSession` 和 `ItemActionRouter` 接管全部物品来源的拖放、右键与动作菜单，移除原背包专属拖放实现；不同输入在提交前共用领域预检。
- 指定格购买、出售、打造取回与世界丢弃接通；交易和拾取通知在归属与金币提交之后发布。保存继续保留丢弃物的身份、种子和词缀。
- 戒指明确选槽；穿戴按钮与拖放统一来源格回填。菜单外右键仅关闭菜单，不能穿透交易；操作设备断开取消搬运。
- 新操作区和菜单沿用现有主题，支持长文本换行。操作栏按实际可见窗口宽度对齐，来源列表滚动，交易按钮、落点和打造操作互不遮挡。
- 项目 EditMode 430/430、PlayMode 61/61 通过；三语言 × 六状态证据见[验收记录](../../assets/acceptance/alpha-0.3.0-actions/README.md)。保留 1 项新增领域回归、2 项真实输入回归，其他覆盖合并到现有装备、存档与布局测试，临时运行器 / 截图工具清理。
