## 目标与范围

让背包、商店、打造、属性、HUD 入口和应用 Shell 采用一致的材质、边框、分区与控件状态。沿用已批准的炭黑内底、旧铁轮廓、少量金铜角件与暖色正文，补齐实际缺少的正式组件，使皮肤与现有交互合同一起交付。

本阶段覆盖窗口与内嵌面板、标题 / 分隔、按钮 / 页签 / 关闭入口、物品与装备槽底板、来源选择器、浮窗 / 操作菜单 / 反馈、Shell 基础控件。HUD 保留当前资源与技能布局，入口、提示和中区参与风格统一。FrontEnd、Settings、Busy、Modal、Toast、Fatal 与暂停页均纳入复核。

十槽装备、空槽专属图标和新增装备内容仍在 [0.3.4](../alpha-0.3.4-equipment-completion-plan.md)。本阶段制作可复用槽位底板，沿用当前四槽与正式物品图标；不预先引入新槽位、配置或存档迁移。不增加自由拖窗、任意缩放、新设置项或新的 UI 框架。

## 组件与状态合同

| 家族 | 交付内容 | 必须保持的行为 |
| --- | --- | --- |
| 外框与内区 | 复用现有正式窗口底板；Shell 根据实际尺寸验证复用，内嵌区用更轻的边框和背景 | 外框不新增命中层，不挤占内容；窗口标题和关闭入口对齐 |
| 按钮 / 页签 | 主操作、普通操作、危险操作、图标关闭、活动页签使用统一层级 | Default、Hover、Pressed、Focus、Disabled 可辨；状态变化不改变盒尺寸与文字位置 |
| 物品 / 装备槽 | 背包格底、跨格物品框、装备槽、打造目标与来源行共享材质 | 不在每个格子堆叠厚装饰；稀有度、当前物品与投放目标分别表达 |
| 浮窗与反馈 | 物品详情、操作菜单、交互提示、操作反馈、Toast 使用一致底板 / 分隔 | 六词条与长名称完整可读；浮窗位置服从共享工作台，HUD 安全区可用 |
| Shell 控件 | Toggle、Slider、下拉、输入 / 重绑定控件、滚动条和模态按钮统一 | 焦点、值、错误 / 禁用说明清晰；下拉弹层不被裁切，滚动区保留手柄可达性 |

- 普通控件的 Hover 和手柄 Focus 可辨识；焦点只表示当前控件，不制造第二件选中物品。物品展示继续由共享选择 / 拖放会话驱动，不能为皮肤创建另一套状态缓存。
- 同一物品在多个来源视图出现时，沿用现有唯一高亮规则。拿起物品可保留源占位；目标显示有效 / 无效区域与动作文字，不将目标物品画成第二个选中物品。
- Disabled 优先禁止交互并保留可读原因，不能被 Hover / Pressed 伪装成可操作。无商店 / 打造上下文时顶部页签继续隐藏。
- 稀有度与操作反馈保持颜色及文字 / 形状语义；危险操作与错误状态不只靠颜色区分。金铜装饰明度低于真正的选中和焦点。
- 默认采用即时状态变化；不新增持续动画。若实际需要短过渡，接入现有 MotionProfile 与生命周期取消，Reduce Motion 下即时切换；不用缩放、抖动或放大图标补救布局问题。

## 布局与样式组织

正式画布为 1920×1080，按中文、英文、Pseudo Locale 验证。保留背包 560、商店 / 打造 760、属性 440 的窗口宽度，背包 10×6 与 48 px 格子 / 4 px 间隔。HUD 左右资源框 300×136、中区 840×136、底部间距 12；现有窗口与操作条不得侵入其交互区。

先使用真实最长文本测量消费者的最小 / 常规 / 最大尺寸，再冻结新图片规格。不通过缩小网格、字号或把重要文字省略来容纳装饰；边框状态应预留固定宽度，避免 Focus / Selected 触发布局跳动。中英字体优先可读，不对字形强行像素化。

`Theme.uss` 保持公共主题入口，公共视觉规则可拆为少量按职责划分的样式文件，由 Main 与 Shell 显式加载；窗口布局、详情布局和业务可见性保留在各模块。核对选择器优先级及模板加载顺序，避免靠越来越多局部覆盖修补公共状态。只清理本阶段触及且确认无消费者的旧规则 / 资源，不按文件年代批量删除资产。

装饰元素使用 Ignore picking，不参与焦点、物品来源和投放注册。继续共享 Main UIDocument / PanelSettings 与 Bootstrap 唯一 EventSystem，保留 Application 层排序和透明区域的命中规则。

## 美术生产顺序

执行时使用 `unity-2d-sprite-workflow` 与[美术资产规范](../../visual-asset-generation.md)，以现有正式窗口 / HUD 图片和[组件规范](../../ui-component-style.md)为参考。先确认现有资产能够复用的范围，不重复生成已通过的底板与 Glyph。

1. 记录组件消费者、实际尺寸、内容矩形、固定画布、可见边界、PPU / Pivot、Border、装饰保护区及拉伸范围。旧窗口的 1254 画布 / 96 Border / 0.125 Scale 只适用于已验证家族，不能照搬到小按钮或细槽位。
2. 先完成一个高频按钮 Pilot，在常规文字按钮、长文本按钮与图标关闭入口上验证状态和命中；不适合共用时再拆分明确家族。
3. 顺序补齐必要的槽位底板、浮窗 / 提示底板及 Shell 内区。每张 PNG 只含一个组件或一个需要独立形状的状态，文字、数值、物品和 Glyph 不烘焙进图片。仅颜色变化优先用运行时 tint / border 表达，不强制为每个状态生成重复图片。
4. 每个 Pilot 通过原生像素检查、自动审计和最小 / 最大消费者验证后，再生成必要派生图。九宫格切线不穿独特角件，长边无不可拉伸的纹理焦点；不合格重新生成，不人工裁切或按对象缩放补救。
5. 使用 Unity MCP / Editor API 导入、布局与绑定；Sprite Single、Point、无压缩 / Mipmap，沿用 Addressables 依赖管理。记录 manifest、生成过程、GUID 引用及实际运行结果，禁止生产组件拼图或手工切片。

正式资产数量由消费者审计确定，不以“新增多少 PNG”作为完成标准；所有本阶段家族都须有实际消费者与通过证据。

## 验收与长期测试

按[测试维护规范](../../testing/test-maintenance.md)先复用现有覆盖，再补真实缺口，不新增 `Alpha033...` 套件。优先扩展 `Phase1UxPlayModeTests` 的文本边界、唯一高亮、真实输入与窗口组合；资产规格加入既有视觉合同；Shell、可访问性及 Session 用例保留各自独立失败场景。

| 检查 | 当次必验 |
| --- | --- |
| 组件状态 | 默认、Hover、Pressed、Focus、Selected、Disabled；文字按钮、图标按钮、格子 / 跨格物品、槽位、表单和滚动条 |
| 物品工作台 | 背包 / 商店 / 打造单独打开；背包 + 商店 / 打造、加属性三窗；来源展开、长反馈、空 / 满背包、六词条与长名称 |
| 操作与导航 | 拖动装备 / 丢弃 / 买卖 / 打造双向、右键等价操作、手柄拿起 / 放置、边缘四向跨窗、取消与失败回退；装饰不阻挡目标 |
| Shell 交接 | 物品拿起时打开设置 / 返回确认；取消恢复、确认离开、重绑定捕获 / 取消、下拉与滑块、暂停返回；一次返回只处理一层 |
| 设备与动态 | 鼠标点击入口、手柄返回后 Glyph 正确、真实鼠标移动再切键鼠；Reduce Motion、平台挂起及恢复 |
| 生命周期 | NewGame / Continue、返回前台再进入；HUD / 物品提示 / Shell 不残留旧状态或重复订阅 |

正式截图为 1920×1080 × 三语言。组件状态板可作为当次验收工具，但不进入生产 UI；Busy / Fatal 等错误画面使用隔离故障注入，不改玩家数据。截图与结果保存在 `Docs/docs/assets/acceptance/alpha-0.3.3-ui-style/`，验收后删除采集脚本、临时资产和 `.meta`，不保留检查历史截图 / 结果文件存在的测试。

收尾运行项目 EditMode / PlayMode 全量并保存本次真实计数。最终 Addressables / Windows Player 封板仍安排在 0.3.4；若本阶段引入新的着色器、遮罩、字体或平台专属渲染依赖，则当阶段补针对性 Player 验证，不能只依靠 Editor 截图。
