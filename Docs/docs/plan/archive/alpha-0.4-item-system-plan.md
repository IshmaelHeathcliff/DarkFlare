# alpha 0.4：统一物品系统

## 基线与目标

2026-09-12：alpha 0.3 已归档，当前实现为 0.3.4-alpha；最近记录 EditMode 434/434、PlayMode 65/65。本次以代码和开发模块文档为准，不读取或修改人工设计目录。

目标：金币、材料和装备统一进入格子背包；堆叠与消耗为独立属性；装备打造消耗材料；怪物掉落以金币和材料为主。保留消耗品、交易物、任务道具类型，不增加其具体玩法。

## 实施顺序

1. 核对物品、背包、交易、打造、掉落、UI 和存档合同。
2. 扩展物品分类、堆叠数量与消耗配置；金币余额改为背包统计，接通原子收支。
3. 接入材料打造与正式内容，调整掉落权重和数量。
4. 接通数量 / 材料需求展示、交互限制和旧档迁移。
5. 补充有长期价值的行为回归，运行 EditMode / PlayMode 与编辑器验证。
6. 更新模块文档和版本，将完成计划归档。

## 成功标准

- 金币与材料拾取后占用物品栏；兼容堆叠合并，空间不足不丢物品。
- 装备不堆叠；堆叠性和可消耗性独立；预留类型不能被当作装备打造或穿戴。
- 买卖和打造成功时准确变更数量；失败不改变物品或资源，不发送成功事件。
- 新存档保存数量，历史金币迁移不丢失，装备身份、位置、词条保持兼容。
- 正式怪物掉落金币和材料的比例高于装备；新增配置通过内容校验。
- UI 显示数量与打造材料需求，键鼠 / 手柄继续使用现有操作入口。

## 完成记录

2026-09-12 完成，版本 `0.4.0-alpha`。统一物品、堆叠与消耗、金币收支、材料打造、掉落、UI 及历史存档迁移全部接通。最终权重为每条装备 100、金币 2000、矿石 500；金币上限 100、矿石上限 50。

EditMode 442/442、PlayMode 67/67 通过；新增行为回归纳入现有测试模块，清理临时截图采集。总结见[统一物品系统](../../item-system.md)，证据见[阶段验收](../../assets/acceptance/alpha-0.4-items/README.md)。
