## 目标与范围

1. 盘点全部测试文件和方法，核对相关模块合同，取得当前测试基线。
2. 区分长期行为、配置 / 架构治理、重复断言、一次性发布 / 迁移验收和旧 UI 布局锁定；逐文件记录决定及保留覆盖。
3. 删除或合并已确认冗余项，历史发布数据归档到文档；保留真实迁移历史夹具、玩家数据隔离及生命周期回归。
4. 运行精简后的项目 EditMode / PlayMode，检查编译、Console、测试环境恢复；仅修复本次清理导致的问题，既有问题单列。
5. 建立长期测试维护规范与完整审计记录，更新项目指南及 Alpha 0.3 前置条件，归档本计划。

## 完成标准

- 所有项目测试文件都有审查结论；删除项说明为何无长期价值，合并项能追溯到保留覆盖。
- 不以测试名含版本号或测试数量下降作为删除依据；核心事务、失败回退、存档兼容、输入、资源与 Session 隔离不失去必要覆盖。
