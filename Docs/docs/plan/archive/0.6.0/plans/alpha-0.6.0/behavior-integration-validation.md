## 隔离样例与适配

保留一个可复用诊断样例而非新增正式 NPC 内容：同一份定义创建两个独立实例，分别执行“等待 → 沿注入路径巡逻 → 等待”，再通过受控命令触发打断 / 停止。一个实例采用 HFSM 包含 BT 子流程，另有单独 HFSM / BT 的纯上下文测试。样例逻辑不查找玩家、不随机生成怪物，不写正式存档。

样例装在独立测试 / 诊断场景，由 Editor 安装入口或测试准备，不修改 Bootstrap / Main 的正式对象；复用现有动画资源，不为验证框架制作一整套美术。诊断场景不加入生产构建列表；开发验收包使用单独构建配置、产品名和隔离数据路径。

HFSM 状态处理器中的树适配仅负责 Start / Tick / Abort 和结果映射，组合类放 Runtime。核心不感知 GameObject；Runtime 的行为身份包含 Session generation、所属场景 / 地图代次和注册序号。动作回执再带单调 ActionInstanceId，防止同实例重入动作接收上次完成回调。

调用外部能力前验证当前代次与行动许可；在 Tick 内发生事件导致注销时，先同步使动作授权失效，集合移除与核心 Stop 在该 Tick 边界完成。禁止遍历集合时删除当前元素导致漏处理其他角色，禁止边界前继续产生新的命中 / 移动副作用。

## 动画唯一所有者

F4 先在样例证明通用桥接，再处理现有 ActorAnimatorController 中实际受影响的订阅 / 消费责任。现有角色默认沿用旧战斗表现；后续接入行为动作的角色通过显式配置选择行为驱动攻击表现，不能两条入口同时生效。

一次动作开始建立语义与动画映射，完成 / 中断时撤销其表现状态；受伤、死亡和复活复用既有领域事件。只在 Controller 消费事件，领域 System / Command 负责发布。动画回调如需报告观察结果走 Command，不能由 Controller 直接发送领域事件或修改 Model。

缺失 Animator、参数不存在 / 类型错误、组件禁用 / 销毁、动作先取消后收到回调，均不改变核心执行结果；表现错误有界记录。0.6.0 不让实际动画结束决定攻击伤害或树是否完成。

## 调试数据与界面边界

- Editor 图显示真实拓扑边、活动父子路径、树节点结果、被中断节点和最后转移原因；不以一行文本列表或静态截图替代图形化调试。
- 通过 Query 获得一次一致快照并验证实例身份；面板不能重新执行 Guard 来“补充”显示。已销毁对象、无 Session、旧代次显示失效状态。
- Inspector / 选择 /参数摘要沿用 Odin；拓扑视图可用 UI Toolkit。图布局按定义缓存，按需更新节点状态，避免每次刷新重建整棵视觉树。
- Development Player 显示同源只读摘要，按需启用；输入经现有 Input System Context，关闭后恢复原焦点与 Gameplay 输入，不能复用战斗按键而同时触发攻击。
- 0.6.0 提供样例实际具备的数据；怪物感知扇形 / 攻击距离在 0.6.1 接入，Boss 阶段在 0.6.2 接入，触发批次在 0.6.3 接入。未提供的数据明确显示不适用，不伪造占位结果。

## 验收矩阵与成本

| 层次 | 关键证明 | 测试归属 |
| --- | --- | --- |
| Core 独立性 | HFSM / BT 各自运行，共享定义实例隔离，无反向依赖 | 现有 EditMode 程序集内按 HFSM / BehaviorTree 模块维护 |
| 生命周期 | Start / Stop / 重启、暂停、注销、取消、异常清理、迟到结果 | 纯规则优先 EditMode；Unity / Session 真实接点 PlayMode |
| 组合与动画 | Exit → Abort、参数映射、订阅次数、禁用 / 复用、无 Animator 对照 | 组合单测 + 必要 PlayMode 样例 |
| 可视化 | 图与当前状态一致，选择两个实例不串数据，窗口关闭不停止模拟 | Editor Play 实际检查和截图；输入 / 生命周期长期回归 |
| Player | 开发面板可用、键鼠 / 手柄可达、原有输入不被吞、发布入口关闭 | 当次隔离 Windows Player，记录中英 / 伪本地化与设备方式 |
| 性能 | 纯 Tick、转移 / Abort、诊断开启 / 关闭分别测量，缓冲有界 | 可重复诊断用例 + 当次数据，不将毫秒跑分写成易抖动单测 |

0.6.0 用 500 / 1000 个无场景对象的核心实例做规模与分配采集，记录每次访问量、时间分位数和每实例内存；用少量可见样例验证 Animator / UI。该结果仅证明基础框架开销，不能替代总计划的 500 / 1000 活动怪物完整场景验收。

正常 Tick 及预分配状态切换按零分配目标验证，使用有效正向探针；构建 / 创建、异常与快照格式化分别记账。诊断窗口关闭后详细采集 lease 与事件订阅归零；关闭 Domain Reload 连续 Play 不保留静态注册。
