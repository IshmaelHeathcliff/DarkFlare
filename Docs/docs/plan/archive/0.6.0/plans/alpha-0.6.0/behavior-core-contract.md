# 0.6.0 核心 API 与执行语义

状态：2026-09-22，F1–F6 完成，本文作为原实施合同归档。实际 API 见[HFSM](../../../../../behavior/hfsm.md)与[行为树](../../../../../behavior/behavior-tree.md)。入口见[行为基础执行计划](../alpha-0.6.0-behavior-foundation-plan.md)。下文保留规划时期的类型名称，实际使用以模块文档和代码为准。

## 两模块的公共边界

HFSM 位于 `Runtime/Core/HFSM/`，命名空间 `DarkFlare.HFSM`；行为树计划位于 `Runtime/Core/BehaviorTree/`，拟用 `DarkFlare.BehaviorTree`。同属已有 `DarkFlare.Core`，互不引用，不增加 asmdef。两模块各自暴露定义、实例、执行结果和只读诊断；不为了相似命名提前抽象共同引擎。

| 对象 | 所有权与约束 |
| --- | --- |
| Definition / Builder | 构建后冻结拓扑、稳定 ID、初始入口和优先级；数组 / 集合复制或只读封装，不暴露可变底层；定义可供多个实例使用 |
| Instance | 绑定一个显式 TContext，独占活动路径、节点游标、计时及诊断缓冲；主线程或调用方串行驱动，不宣称线程安全 |
| 状态 / 动作实例 | 定义内工厂为每个 Instance 创建独立处理器；无状态逻辑可复用静态方法，有状态对象和捕获可变数据的闭包不得跨实例共享 |
| Tick | 调用方传入模拟 deltaTime；拒绝负值、NaN、Infinity；零值不推进也不执行正常 Tick 回调，Stop / Abort 仍立即有效 |
| 生命周期 | 未启动、运行、已停止、故障明确区分；运行时重复 Start 拒绝，重复 Stop / Abort 幂等；故障后须显式 Reset 才可重新启动 |
| 查询 | 只能获取稳定拓扑和执行后快照；不得触发条件重算、随机消耗、节点 Tick 或用户回调 |

核心不自行读取 Time、创建 UniTask / CTS、使用 QFramework 单例或访问 Animator。状态 / 叶节点可调用注入的能力接口，实际资源与异步由 Runtime 适配器拥有。调试 ID 使用稳定字符串，运行时编译为索引，避免每 Tick 字符串路径拼接与反射。

## HFSM API

| API / 类型 | 合同 |
| --- | --- |
| `HfsmBuilder<TContext>` | 添加状态、父关系、复合状态初始子状态及转移；Build 时完整验证拓扑 |
| `HfsmDefinition<TContext>` | 冻结的状态 / 转移定义，创建独立运行实例 |
| `IHfsmState<TContext>` | Enter、Tick、Exit；Exit 接收正常转移 / 停止 / 故障等原因，不直接调用状态机递归转移 |
| `HfsmInstance<TContext>` | Start、Tick、Stop、Reset、状态路径与最近转移查询；Reset 只在停止 / 故障且清理已完成后接受 |
| `HfsmTransitionInfo` | 来源、目标、显式优先级、自转移策略及原因；Guard 在 Builder 注册后由定义内部持有，诊断不执行 Guard |

Build 拒绝重复 / 空 ID、未登记引用、父子环、多个根、不可达状态、复合状态无合法初始子状态、叶状态却配置子入口、非正执行容量。第一版一个显式根，死亡和休眠都是通用根下的业务状态，核心不内置这些名字或优先级。

每 Tick 顺序固定：

1. 接纳一次调用方时间步和上下文快照；检查实例运行态和重入门禁。
2. 只检查当前活动路径上的转移。显式优先级高者优先；同优先级由父到子，再按声明顺序。业务将死亡 / 失活等紧急转移配置为最高优先级，不能依赖注册先后猜测。
3. Guard 无副作用，实际判定一次并记录结果；首个成立的有效转移获选，其余标记为“未评估”。每 Tick 最多提交一次，不递归执行瞬时转移链。
4. 找到源 / 目标路径最低共同祖先，从叶向上退出，再从祖先下方向目标进入；目标为复合状态时沿初始子状态进入叶。兄弟间切换不重复退出 / 进入公共父级。
5. 对转移后的活动路径由根到叶各 Tick 一次。Tick 回调造成的业务事实供下一时间步判断，不能在当前调用栈再次转移。

目标已是当前叶时：默认 Ignore（不退出 / 进入，也不增加转移次数），并继续检查其他候选；显式 Reenter 才重入该叶。复合状态重入显式退出其活动子树并从该复合状态重新进入，公共外层祖先不受影响。禁止含糊的自动重入。

回调内重入 Start / Tick / Stop / Reset 立即拒绝；外部注销由 Runtime 先撤销动作许可、排队到当前 Tick 边界清理。Exit 抛错也要尝试清理其余已进入状态，每个最多一次；返回 Faulted 和原始 / 清理异常，不能将部分进入误报为成功或继续执行旧攻击。核心不承诺回滚用户回调的外部副作用。

## 行为树拟定 API

| API / 类型 | 合同 |
| --- | --- |
| `BehaviorTreeBuilder<TContext>` / `BehaviorTreeDefinition<TContext>` | 冻结节点和边，Build 时拒绝环、重复 ID、多父运行节点、空组合节点及非法参数 |
| `IBehaviorAction<TContext>` | Enter、Tick、Exit；每次 Enter 对应一次正常或中断 Exit，持有的可变数据归独立实例 |
| `BehaviorTreeInstance<TContext>` | Start、Tick、Abort、Reset，拥有节点运行内存、时间和访问预算 |
| `NodeStatus` | 执行返回值仅 Success / Failure / Running；未访问、中断、故障属于诊断状态，不假冒普通失败 |
| `TreeTickResult` | 根执行状态或 Faulted，并带访问量 / 错误信息；预算耗尽是明确故障，不伪装 Running 或无目标 |

首版节点集合限于 Action、Condition、Wait、MemorySequence、PrioritySelector 和 Guard。Sequence 记住 Running 子节点；完成的前置步骤不会在每帧重跑。Wait 仅消费模拟时间，树终止后不会自动重启，必须由宿主显式请求新一次执行。

PrioritySelector 采用显式 Guard 与子分支一一对应：每次 Tick 从高到低评估条件，选中更高优先分支时，先 Abort 原 Running 分支，再 Enter 新分支。新分支 Failure 后可尝试下一候选，但每个分支同一 Tick 最多尝试一次。旧分支 Guard 失效且无替代时中断旧分支并返回 Failure。Guard 装饰器逐 Tick 重查自身条件，条件失效先中断 Running 子树。

每棵树只推进一次实例时钟；同 Tick 的多个顺序动作共用当前时间戳。新进入 Wait 的截止时间从进入时计算，不能在一个时间步内让多个新进入的 Wait 各自重复消耗完整 deltaTime。长帧可以使已等待的节点到期，但仍受节点访问预算限制，不补发多轮攻击。

Build 按拓扑估算每 Tick 最大访问量，拒绝超过配置预算的定义；运行中另有防御性计数。预算耗尽或回调异常时，停止调度并中断所有 Running 节点，记录 Faulted；清理使用独立且有界的已进入节点列表，不受耗尽的执行预算阻止。

## 诊断与开销

- 拓扑和名字是定义数据，运行状态是每实例数据；未评估条件、上次评估 Tick 和结果必须可区分，不能将旧结果渲染成当前事实。
- 默认只维护当前活动路径 / 节点结果及故障信息；详细 Guard / 转移轨迹通过调试 lease 按需启用，固定容量环形缓冲，不无限增长。
- 复制诊断使用调用方复用的缓冲或显式一次性快照；不向 UI 暴露运行时可变数组。编辑器 5–10 Hz 采样为初始建议，不改变模拟步长。
- 核心正常 Tick 和已有实例的状态切换目标零托管分配；构建 / 创建、异常、Runtime 动作、UI 格式化、保存分别统计，不能混淆为整场零分配。
- 0.6.0 不序列化通用执行栈或委托。后续怪物 / Boss 保存业务语义，由各自适配器重建核心实例；核心预留稳定 ID 和只读运行信息即可，不提前实现任意节点恢复框架。

## 必须保留的核心回归

HFSM：兄弟 / 跨层转移顺序、父级高优先转移、自转移两种策略、初始子路径、停止 / 重启、Guard 只评估一次、回调重入拒绝、Enter / Exit 异常后的清理、同定义不同实例隔离。

行为树：Running 延续、Sequence 游标、高优先抢占先退出后进入、Guard 失效、整树 Abort 幂等、树完成后不自动重启、同 Tick 等待不重复计时、长帧访问有界、异常与预算故障清理、多个实例互不干扰。

分别只引用对应模块和普通 C# 上下文编写用例；组合测试另外验证状态 Exit 恰好 Abort 一次树。依赖审查检查两模块没有互相引用或 Unity / Runtime 类型泄漏，复用现有测试基础设施，不按版本创建新测试程序集。
