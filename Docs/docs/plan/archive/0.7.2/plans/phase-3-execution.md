## 确定的界面与操作行为

| 区域 / 状态 | 计划行为 |
| --- | --- |
| 顶部摘要 | 仅常驻天赋点、属性点、能量池和下一兑换成本；去掉格坐标读数，开发排查使用现有调试窗口 |
| 视图工具 | 一个紧凑入口展开回中、适配、缩放和根定位选择；移除原来整排常驻文字按钮，根编号与逻辑身份保持 |
| 默认浏览 | 画布优先，详情收起；首次进入适配中心、六根和当前网络，之后保留会话内视图，不写入存档 |
| 选择与详情 | 选择节点或背包道具后可展开相应详情；只显示相关操作，失败原因和必要条件仍可读，长说明可滚动 |
| 中心与属性 | 中心显示瓶子摘要与两类充能来源；属性格显示该属性实际分配 / 最终值，只提供当前属性的分配动作 |
| 已安装网络 | 移动、点亮、取出、拆卸按对象显示；多连接选择、拆卸退款、属性分配和整瓶充能仍预览后明确确认 |
| 六技能槽 | 紧凑显示真实绑定和槽状态；选中槽后再显示完整技能信息与已有分配能力，有内容时才提供清除动作 |
| 背包 | 继续与棋盘并排，保持格子尺寸和装备瓶入口；拖放复用唯一 `ItemInteractionSession`，不隐藏来源换取画布比例 |
| 底部反馈 | 预览 / 错误 / 确认仅在对应操作需要时展开；不能因收起详情而隐藏待确认的消费或退款 |

初版目标为：1920×1080、相同窗口边界下，**画布占棋盘窗口内容区至少 65%**。分母取 `.board-content` 实际布局面积，分子取 `board-viewport` 内可见画布面积，扣除遮盖它的展开面板；背包不计入分母。默认浏览、详情展开两种状态分别记录，三语言均与修改前同条件比较；不足时先调整摘要、槽区及详情布局，不用隐藏必要操作或扩大统计外框达标。

### 键鼠与手柄可达性

- 鼠标继续滚轮缩放、中键平移、点击选择和拖放。工具菜单支持点击，菜单点击不穿透到棋盘或普通攻击。
- 手柄方向输入继续移动六邻居游标，接近边缘时自动平移。缩放、回中、适配及根跳转通过工具菜单完成，避免走过大量空格。
- 首次焦点进入画布；提交可进入当前选择的操作区，操作区始终能到达工具入口，空格无可用操作时直接落到工具入口。方向导航不能永远被画布截留，也不能将一次提交同时用于分配和菜单选择。
- 工具菜单使用现有 UI 导航 / 提交 / 返回；视图动作后回到画布并保持合理的逻辑游标，菜单关闭恢复原焦点。拿起柴薪时肩键仍双向旋转 60°，其余情况下仍循环窗口。
- 返回先关闭当前工具弹层或取消正在进行的拖放 / 预览，再退出详情回画布，最后关闭棋盘并恢复进入前窗口组合；一次输入只处理一层。
- 提示读取 Application 输入服务的实际绑定，支持重绑定与设备族切换；不新增第二份 InputActionAsset，也不直接轮询 `Gamepad.current`。

## 属性方位与统一显示变换

用户已确认以最终位置为准，允许调整角度和显示映射，不锁定原先的 15°。采用**屏幕坐标下整体顺时针 30° + 中心属性显示映射**；这是表现调整，保持领域轴坐标、六根和安装身份。

| 属性身份 | 显示所在逻辑保留格 | 旋转后相对方向 |
| --- | --- | --- |
| `strength` | `NeighborDirections[4]`，`(0,-1)` | 正上方 |
| `dexterity` | `NeighborDirections[2]`，`(-1,1)` | 左下方 |
| `intelligence` | `NeighborDirections[0]`，`(1,0)` | 右下方 |

三格均在原中心保留区内；属性数值仍由原 `StatIds` 和成长事务保存，调整显示对应格不交换玩家已分配数值。另三邻格仍留白，中心仍用于充能。

1. 在现有 `SkillBoardProjection` 附近集中维护显示旋转及属性映射，不复制到 UXML、Controller 和标签各处。数学关系为 `显示点 = 顺时针旋转30°(原投影点)`，命中先逆旋转再做原轴坐标舍入。
2. 格中心、六边形顶点偏移、节点、裂缝外伸、连线、预览和效果高亮使用同一变换。标签只旋转锚点，文字保持正向；标签尺寸兼容三语言，不再依赖旧方向的固定偏移假设。
3. `CellPosition`、`SelectAt`、`CenterOn`、可见网格原点 / 范围、缩放和平移都使用一致的坐标空间；旋转后仍覆盖整个视口，不留未绘制的角落。
4. Fit 遍历实际显示范围和顶点并加安全边距；展开 / 收起详情后正确更新布局。超大网络受最小可读缩放限制时保留滚动浏览与定位能力，记录边界，不能虚报所有节点均已适配可见。
5. `Step` 使用变换后的邻居方向评分，保持稳定并列规则；六根编号不按屏幕重新编号。显示旋转不调用安装 `Rotate`，不更改大柴薪根资格、六档 60° 旋转、连通或范围步数。

闭环至少覆盖：背包安装 → 双向 60° 旋转 → 多连接选择 → 火焰 / 余烬嵌入 → 点亮与实际范围 → 六槽分配 / 清除 → 逐件取出 → 拆卸退款；中心分别用装备瓶、背包瓶充能并验证取消不消费；三属性分别确认分配正确身份。
