## 实际交付

- 将整排回中、适配、缩放及六根定位收进视图工具；移除常驻格坐标读数。默认详情收起，选中节点、属性、背包物品或技能槽后显示相关操作。
- 顶部摘要合并为紧凑一行；六槽保留真实绑定与状态标识，完整信息进入选中槽详情，只显示当前有内容槽的清除动作；清除后焦点回对应槽。
- 统一显示投影顺时针 30°，力量 / 敏捷 / 智力映射至保留邻格 4 / 2 / 0，最终位于上 / 左下 / 右下；三属性以颜色区分。缩小时标签用短引线避让，文字保持正向并适应扩展文本。
- 格中心、六边形顶点、预览、连线、裂缝、效果高亮、鼠标反投影和手柄方向统一；Fit 使用实际主体、外伸与当前候选边界。首次展开在布局完成后适配，此后保留会话内视图。
- 手柄连续导航在边缘自动平移；工具菜单提供缩放、回中、适配和快速定位。自定义导航消费 Unity 默认焦点行为，避免移动游标后焦点跳到背包。
- 展开后的焦点等待有效布局，确认操作自动滚动到可见位置；切换窗口、挂起、取消、面板解绑与 Session 停止清理待执行焦点。返回逐层处理工具、预览、详情与窗口。
- 安装、双向 60° 旋转、嵌入、点亮、取出、拆卸退款、六槽与中心整瓶充能沿用现有事务。多连接必须逐项选择并确认，连接说明可换行；没有改变安装坐标、节点身份或保存格式。

## 回归与排查

- 在 `SkillBoardGeometryTests` 补充属性身份 / 最终方向、相邻六边形共边及边界两侧命中；扩展既有投影往返与屏幕方向覆盖。
- 在原 UX 套件补充鼠标平移 / 缩放后的命中和三属性分配、手柄连续平移 / 工具 / 窗口交接、真实多连接取消 / 提交 / 保存恢复；增强原安装闭环的清槽和保存身份断言，以及三语言确认可见性。
- 初次立即聚焦新展开控件会落空，改为等有效布局后聚焦，并清理旧请求；没有放宽真实焦点断言来跳过故障。
- 连续手柄导航最初 12 次只移动 6 格，逐步记录显示焦点在画布与背包间交替。现对已接管的导航调用 `FocusController.IgnoreEvent`，保持每次输入只由当前所有者处理；[修正前记录](navigation-before-fix.xml)。
- 首轮综合 PlayMode 116/117，属性页跨窗导航失败。将默认焦点拦截限定在天赋窗口，保留其他窗口原有导航路径；原失败断言不变，跨窗与棋盘 / 瓶子联合定向 9/9。[修正前全量](playmode-before-navigation-scope-fix.xml)、[修正后定向](navigation-scope-regression.xml)。
- 多连接说明最初继承单行样式而裁切，改用 Toggle 的文本区并明确换行；[修正前记录](links-before-wrap-fix.xml)。最终三语言连接、消费预览和确认按钮均重新采集并检查。

长期新增仅为三项 UX 行为与一项几何行为，继续使用原模块套件；未新增按版本命名的永久测试。临时截图测试和运行桥接在验收后清理，不用旧结果文件作为运行断言。原有字体工作区修改独立保留。

收尾核对的 18 个源码 / 配置文件哈希全部一致，相关文档与源码为 UTF-8 / LF，文档链接检查无缺失。42 个临时文件已在逐一验证截图副本后清理，Unity 内临时采集测试、运行桥接及对应 `.meta` 均已删除，删除后重新编译通过；见[清理与检查记录](cleanup-and-checks.json)。
