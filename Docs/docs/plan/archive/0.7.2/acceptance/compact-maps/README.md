## Editor性能

同机、同Unity、1920×1080，先以只读旧JSON构造内存地图，再恢复当前正式布局，正式源文件不来回改写。旧图与新图都使用真实怪物、导航和资源owner；仅性能压力采样临时提高测试玩家耐久，防止死亡中断，结束前恢复。旧图100存活、新图300存活，Boss各1且不计入普通Alive列。没有把300总名额当作300同时存活。

[原始4次预算样本](profile/)、[最终带2ms让出条件的样本](profile-budget/)、[统计](performance-summary.json)。GC / 主线程来自有效ProfilerRecorder，导航及生成来自运行诊断；采样本身、Editor、UI与保存工作均会计入，不能当作Player帧预算。
