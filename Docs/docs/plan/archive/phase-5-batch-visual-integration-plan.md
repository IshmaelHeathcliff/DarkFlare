# 阶段 5：批量视觉接入与表现反馈

状态：已完成并归档

完成日期：2026-08-07

## 目标

在不改变伤害、掉落、交易、打造、装备、刷怪与 AI 事务的前提下，为现有最小循环补齐首版可辨识视觉、战斗反馈和统一 UI 主题。

## 执行批次

### 批次 A：内容辨识与动态图标

- 生成并导入裂爪猎犬、铁壳尸傀的独立动画资源。
- 补齐六件装备图标，并保留现有大剑图标。
- 新增 Addressables Sprite 缓存与预热流程。
- 将世界掉落、背包、装备槽、商店、打造、详情和 HUD 统一接入物品图标。
- 扩展内容校验和自动化测试。

验收结果：三种怪物可凭外观辨识；七件装备在所有入口使用一致图标；正式路径不再固定回退到大剑图标。

### 批次 B：地图、交互物与战斗反馈

- 在现有 5×5 地表和 `WorldBounds` 上增加地表变化、营地、路径、装饰和边界装饰。
- 制作商人与打造台 Prefab，并接入交互焦点表现。
- 增加命中闪白、伤害数字、怪物血条、死亡淡出和投射物冲击反馈。
- 保持现有交互范围、刷怪、伤害和掉落时序。

验收结果：世界对象不再依赖方块颜色区分；核心战斗状态均有清晰反馈；临时表现可正确清理。

### 批次 C：统一 UI 视觉

- 建立共享主题 USS 和固定 UI 图标。
- 重构 HUD、装备槽、商店、打造和详情面板的图标与稀有度呈现。
- 完善鼠标与手柄的 Default、Hover、Pressed、Selected、Focused、Disabled 状态。
- 保留唯一 `UIDocument`、唯一 `EventSystem` 以及现有选择和滚动状态。

验收结果：键鼠和手柄均能持续辨识焦点、选择和禁用状态；世界与各面板的物品视觉一致。
