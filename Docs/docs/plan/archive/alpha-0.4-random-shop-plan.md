# 随机商店与主动刷新

2026-09-16：已完成。承接 alpha 0.4.2 的交易与消耗品。

## 行为与实现

- 正式商店每批生成 16 件独立商品，从完整装备和四种药水候选池按权重有放回抽取；数量、候选权重和装备稀有度权重可配置。初始装备品质权重普通 40、魔法 40、稀有 18、传奇 2；普通无显式词条，其余按已有品质容量和最小数量随机生成合法词条。
- 买一件移除一件，不自动补位或刷新；同基底可以出现不同品质和词条的独立商品。药水每份数量为 1，买入背包后可合堆。
- 增加键鼠 / 手柄可达的免费刷新按钮。刷新先完整生成候选库存，成功后一次性替换未售库存并通知 UI / 存档；失败保留原库存与玩家金币。
- 复用 ItemGenerator / CraftingOperations 的词条规则，不另写词条算法。每次刷新使用独立随机种子并记录日志，不推进战斗、掉落或打造随机通道；当前库存完整保存，后续刷新不承诺跨读档重放相同商品。
- 旧档恢复原有库存，关闭再打开商店不刷新；主动刷新后应用新配置。现有物品 DTO 足以保存品质、词条和库存，不新增存档结构。

## 顺序与验收

1. 扩展商人配置、纯生成与合法性校验，接通原子替换和刷新 Command / Event。
2. 添加本地化按钮及结果反馈，刷新时清除旧商品操作 / 浮窗，保留有效焦点；更新正式配置。
3. 扩展已有交易与 UI 测试：确定性生成、合法品质词条、失败保留原状态、购买仅减一件、旧引用拒绝、重开不补货、刷新标脏与存档恢复、键鼠 / 手柄按钮可达。
4. 运行相关及全量回归，验证三语言与界面边界，更新交易模块和配置文档，完成后归档计划。

不改怪物掉落、玩家出售语义或打造成本。运行版本暂保持 0.4.2-alpha，不在本任务自动发布新版本或 Git 提交。
