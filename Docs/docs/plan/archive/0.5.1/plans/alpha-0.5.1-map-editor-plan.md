## 交付与边界

交付 Unity 内可实际使用的 Odin 地图工作台：从空图手绘四地表，编辑障碍 / 装饰 / 交互记录及区域，撤销 / 重做、保存与 JSON 交换；AI 可通过连接中的 Editor 读取地图、预检并原子应用相同操作，人工可接着修改。

沿用 `.dfmap` V1，不扩充传送入口、游泳、飞行或区域移动代价。当前区域为 Named / Safe / Spawn，交互为 Trader / Crafting。世界排序与对象正式表现绑定属于 0.5.2，城镇 / 野外和跨图出口属于 0.5.3，Flow Field / A* / Job / Burst 和目标流场预览属于 0.5.4。本阶段的编辑器连通诊断使用 D 的静态邻接，不交付怪物寻路。

以正式四材质包及已有几何样例验收；补充城镇布局草稿和野外布局草稿作为编辑样例，不把它们计为可游玩的双地图。地图编辑器自身使用键鼠；不新增运行时 UI 或要求手柄在 SceneView 绘图。

## 已核对的实现与缺口

路径相对 `Assets/Scripts/`。

| 当前入口 | 本阶段处理 |
| --- | --- |
| `Runtime/Maps/MapDocumentJson`、`MapDocumentCompiler`、`CompiledMapDocument` | 复用严格结构 / 内容校验、规范导出和脱离快照的编辑副本；新增操作合同，不复制 DTO 或反序列化规则 |
| `Editor/Maps/MapDocumentPage.SaveSource/AtomicWrite` | 现有写入没有磁盘 baseHash、编辑会话或 Undo；抽出可复用文件事务适配器，保留旧配置中心入口 |
| `MapDocumentImporter`、`MapEditorDefinitionIndex` | 复用稳定导入身份与依赖跟踪；索引 Hash 仅覆盖身份 / 路径，不能当作定义内容未变的证明 |
| `MapTerrainPreviewSession/Frame` | 可消费内存快照并原子发布；目前每次完整填充 Tilemap、完整编译几何，不能按鼠标事件频率调用 |
| `MapGeometryInput/Snapshot/Projection` | 复用 footprint、代价、区域、CheckEdge 和容量拒绝；落点合法不等于与起点连通 |
| `MapObjectDefinition` | 已有能力、矩形 footprint、交互类型与外观变体 ID，但没有 Sprite / Prefab 引用；工作台先用轮廓、接地点和类别标记定位对象，正式表现绑定不在此处另建一套 |

## E1：共享编辑事务与文件冲突保护

E1 已完成。先建立不依赖窗口的纯操作内核和 Editor 会话适配，再制作画笔；同一 MapId / 源 GUID 在本 Editor 中只有一个写会话，多窗口共享它。

### 状态与接口

- 文档语义、磁盘基线、预览快照分开拥有。会话保存源 GUID / 路径、打开时文件字节 Hash、最后成功保存的语义 Hash，以及当前工作副本。脏状态比较语义内容，不因为重绘、保存或请求编号变化而变脏。
- 纯 `MapEditService`（计划名）接收 DTO / lookup 快照、类型化操作与取消令牌，只产生候选文档和 diff；不调用 AssetDatabase、Undo 或 SceneView。文件、Unity Undo、请求串行化与生命周期位于 `Editor/Maps/` 适配器。
- 一次拖拽、一组批量操作、导入替换各是一个事务。在副本按顺序模拟，最终完整校验成功后才更新工作副本；同批次可先清除旧 override 再重绘地表。任何失败不留下前半笔。
- revision 由服务管理，有效变更增加一次；无效操作或语义无变化不增加。Undo / Redo 恢复布局但生成新的修订，不能让历史 revision 重新成为可提交版本。Unity Undo 只回放语义载体，服务的单调版本与请求代次不回退。
- AI 的 baseRevision + baseHash 指向当前工作副本；文件字节 Hash 单独用于 Save 的磁盘冲突检查。发布候选前复核工作版本、会话 generation 和本次用到的定义内容，定义变更必须重新校验，不能仅检查地图 SourceHash。
- 为撤销载体使用 Editor 所有的可序列化临时对象，不写入导入 MapDefinition。E1 原型必须验证 Unity Undo 的分组、跨窗口、保存后撤销及域重载恢复，验证通过后再固定内部载体实现。

### 文件与恢复

- Apply 修改工作副本，不自动保存；Save 显式落盘。无 UI 的 AI 调用也打开同一会话，避免另设“直写磁盘”旁路。
- Save 先生成并验证规范候选，紧邻替换前复核磁盘字节 Hash / 文件存在状态；使用唯一同目录临时文件，复用原子替换和 ImportAsset。失败保留工作副本与脏状态，磁盘仍是旧完整文件或新完整文件，不留下半写文件。
- 原子重命名本身不保证跨进程 compare-and-swap。首期仅承诺本 Editor 写操作串行化及可检测的外部修改；记录最后检查到替换之间的竞争窗口，不宣称排他锁覆盖任意外部编辑器。替换后若导入失败，明确显示“文件已写入、导入失败”，保留恢复副本，后续回退仍须检查当前磁盘版本。
- 新建 / 另存为默认创建新 MapId，拒绝覆盖已有目标或重复身份；普通 Export 保留 MapId。导入外部文档先显示新增 / 删除 / 修改摘要，再作为一个工作副本替换事务。缩图或改变 cellSize 会影响足迹 / 区域时必须列出后果；默认拒绝越界，只有显式裁剪操作才删除数据。
- 关闭、换图遇未保存内容提供保存 / 放弃 / 取消；域重载及进入 Play 前取消笔画和预览，将有效草稿与磁盘基线写入 `Library` 下有界恢复记录。恢复时复核原源身份及磁盘变化，不自动覆盖源。Editor 崩溃只保证最近完成的恢复检查点，不保证尚未结束的笔画。

E1 成功标准：内存原子性、无操作修订、单调 Undo、磁盘冲突 / 写失败、源删除 / 移动、重复身份、草稿恢复均有行为验证；配置中心旧导入 / 导出继续可用。

## E2：工作台与地表绘制

- 新建 Odin 工作台，复用项目配置 / 属性面板风格；先验证隔离编辑舞台的 SceneView 原型。证明地表可见、XY 拾取正确、选择不污染 Main、退出后回到原舞台，才接入正式画笔。不另外实现通用二维画布。
- 复用地表快照、Tile 资源和几何生命周期，按需要抽出场景无关的填充适配层。现有只读诊断窗口保留用于规则核验，不让它与工作台各维护一份可编辑源。
- 实现地表选择、方形笔刷尺寸、擦除到默认材质、吸管、矩形、连续线与四邻接洪水填充。拖动插值填格，消除快速鼠标移动造成的漏格；越界 / 负坐标使用同一坐标转换。
- 变体按显示格选择兼容 VariantId，可清除 override；修改地表使原 override 失配时，默认预检报告并拒绝，用户可显式选择同时清除受影响 override。手工与 AI 必须使用同一策略。
- 鼠标按下至释放只形成一个 Undo 分组；Esc、失焦 / 切舞台 / PlayMode 取消未完成笔画，释放 hot control 与订阅。绘图只捕获自己的输入，不截获属性文本编辑、SceneView 浏览与其他窗口快捷键。
- 绘制时立即显示笔刷覆盖与待提交范围；笔画完成后合并请求并异步解析。正式画面、对象叠加与几何使用完整版本，构建中标过期。禁止每个 MouseDrag 完整重建物理碰撞；几何刷新可手动触发或在笔画后延迟合并。
- 图层可显示 / 隐藏 / 锁定；支持工具快捷键、Ctrl/Cmd+Z、Redo、保存、吸管、取消，焦点行为可验证。预览错误不吞掉可修复草稿。

E2 成功标准：从空图绘制四材质、快拖不漏格、单笔撤销 / 重做恢复语义与变体；SceneView 拾取覆盖负 origin、cellSize=0.5、外侧视觉半格与 chunk 边界；Main 和原活动场景没有脏改动。

## E3：对象、交互与区域工具

- 按能力 / ContentId 搜索对象定义，吸附放置、选取、移动、直角旋转、复制、批量删除；完整编辑 appearanceVariant 与 Trader / Crafting 绑定。复制必须分配新的 objectId，重试同一已提交事务不能再生成一份。
- 单一对象记录可组合障碍、装饰、交互；选择 footprint / 标记只定位记录，不将临时 Transform 当作权威数据。只有工作台产生的预览对象可被工具操作；撤销不销毁其他场景对象。
- 矩形与简单多边形区域：新建、顶点增删 / 移动、类型、priority、Spawn 定义；完成手势前可显示临时非法形状，提交时自交、退化、多余绑定、越界完整拒绝。
- 显示物理阻挡、接地点、区域类别、净空 / 落点和错误位置。选中商人 / 打造台时用合法的周边站位候选诊断，不能要求角色走到阻挡对象中心。
- 复用 CheckEdge 做有界静态连通诊断，起点、目标 / 目标集和半径由用户显式指定；没有传送 / 必达标记时不猜测哪一个点是入口。Connected / Disconnected / NoLegalEndpoint / BudgetExceeded 区分，预算耗尽不是断路。仅将它用作工作台诊断，不引入运行时路径跟随或流场缓存。

E3 成功标准：五类语义均可编辑并正确往返；U 形绕行、封路后恢复、重叠 Safe / Spawn、多个半径及高密度几何容量错误能定位。没有正式 Sprite 绑定的定义也能通过清晰标记完成布局编辑。

## E4：AI 批处理、Schema 与交换入口

人工工具在 E1–E3 已消费同一操作内核；本切片将它暴露为结构化 Editor 静态入口，可通过现有 Unity CLI / MCP `run_script` 调用。AI 不依赖模拟鼠标或修改场景 YAML，不启动第二个写入 Editor。

| 操作 | 首期约束 |
| --- | --- |
| PaintCells / FillRect / PaintLine / FillRegion | 逻辑格坐标、明确地表 ID；FillRegion 明确为地表四邻接洪水填充，以起点原材质为匹配条件，和 Named 区域记录无关 |
| SetVariant | 显示格坐标、兼容 VariantId 或清除；不改通行 |
| UpsertObject / RemoveObject | 完整对象记录 / 明确 ID；rotation 沿用 DTO 的 0/90/180/270 度；移除不存在 ID 视作无变化 |
| UpsertRegion / RemoveRegion | 完整区域记录 / 明确 ID；点为逻辑格单位，可为小数 |
| SetMapMetadata | 白名单头字段；revision 由服务控制，MapId 由新建 / 复制控制；palette 重排必须重映射索引，禁止改变旧格语义 |

- 冻结独立 `patchVersion=1`，不修改地图 formatVersion=1 或玩家 Save Schema。未知字段 / 操作 / 版本、非有限数值与错误坐标类型拒绝。文档、枚举、示例与实际校验器保持同源，禁止任意类型名或表达式反序列化。
- DescribeSchema / ListDefinitions / ReadMap / ReadRegion 支持分页与过滤；返回内容 ID、能力、可用变体、坐标说明及文档状态。预算初值：Patch ≤1 MiB、每批 ≤256 操作、每批最多访问 262,144 个逻辑格 / 候选；读取每页 ≤4,096 格或 ≤256 条对象 / 区域。重叠区域反复访问也计预算，先估算显式大范围再分配，洪水填充逐访问计数。
- PreviewPatch 返回候选 diff、变化计数、受影响显示格 / 区域、失效 override、结构问题及可选几何 / 连通诊断；不改工作副本或磁盘。ApplyPatch 必须再次验证基线和定义，不能信任旧 preview。
- 返回稳定结果码、JSON path、operationIndex、对象 / 区域 ID、位置和建议；区分 InvalidDocument、Conflict、Cancelled、BudgetExceeded、GeometryUnavailable、IoFailure 和 ImportFailed。当前 MapDocumentCompiler 只报告首错，本阶段先提供可靠路径和操作定位，不为追求“完整错误列表”复制编译规则。
- operationId + 规范 payload Hash 在会话内做有界幂等：同 ID / 同内容返回原回执（带当前工作版本），不同内容报冲突。Undo 不清除回执而让旧批次再次执行；回执淘汰 / 重启后旧请求必须通过基线检查，不能保证跨重启的永久去重。首期最多保留 256 份回执，不保存大地图副本到每份回执。
- Apply 不自动 Save；显式 Save 使用相同磁盘事务和冲突信息。缺内容的跨工程导入先返回必需 ContentId 清单 / 缺项，不按名称近似匹配；交换 JSON 不嵌入贴图、Prefab 或运行时状态。

E4 成功标准：真实连接 Editor 完成 Read → Preview → Apply → Save → Read，并由人工继续绘制；重复请求、Undo 后重试、两窗口共享、过期 preview / 定义变更、半批失败和文件冲突均符合合同。

## E5：交互、性能与阶段收尾

1. 分别从空图用人工工具和同等 Patch 创建四材质、障碍 / 装饰 / 交互 / 区域，再导出、重导入并继续编辑。比较规范语义（忽略两条流程自然不同的 revision / 新建身份），相同种子与坐标保持稳定自动变体；不能仅对比操作日志。
2. 覆盖保存后 Undo / Redo、换图 / 关闭提示、Play / 域重载、外部修改 / 删除 / 重命名、撤销期间旧预览回调、磁盘写失败、坏 JSON、引用失效和重复 MapId；测试写入隔离目录。
3. 64² / 128² / 256² 连续区域地图各测三轮拖拽、区域填充、批量对象 / 区域、预览和 Undo；记录操作耗时、主线程最长停顿、托管分配与历史占用。初始目标：128² 笔刷覆盖反馈 P95 ≤50ms，笔画结束到完整地表预览 P95 ≤1s；正式几何计时单列，不算逐帧绘图预算。未达标先定位，不减少绘制内容或隐藏失配画面。
4. Undo 历史建议最多 64 笔且按序列化载体计 ≤64 MiB；E1 验证 Unity Undo 能否执行文档级预算，必要时缩减保留历史并明确通知，不能同时维护两套互不一致的 Undo。会话恢复记录单地图 ≤8 MiB、合计 ≤64 MiB，清理已保存 / 明确放弃草稿。
5. 合法文档允许保存，即使可选几何诊断超过 D 容量；必须显著标记 GeometryUnavailable，不能标可导航或复用旧几何。逐格随机 256² 源继续作为容量拒绝用例；需要发布可玩地图时在后续发布入口强制运行相应几何校验。
6. 优先扩展 MapDocument / Importer / Preview / Geometry 测试；新增 MapEdit 模块测试保护事务、冲突、身份和恢复，交互验证真实快捷键 / 鼠标与可见舞台。临时截图 / 跑分脚本完成后删除，保留证据。
7. 定向验证后运行项目完整 EditMode / PlayMode 与内容 / 配置校验，恢复 Reload Scene Only、场景 / 预览资源基线。更新 `maps/map-editor.md` 当前实现文档并归档本计划；完整 0.5.1 验收后再更新开发版本，core / Save Schema 不为纯编辑器改动升级。

## 完成记录与后续

E1–E5 均已完成；下一阶段为 0.5.2 世界层级，另行细化实施计划。

- 实现共享事务、独立磁盘基线、单调 Undo、幂等回执、冲突草稿保留、Odin 工作台、隔离 SceneView、四地表画笔、对象与区域、可选静态连通诊断和 AI 入口。
- Unity Undo 预算使用本载体清理，可能留下空组；不会删除其他工具的历史。保存 / 放弃清理完整草稿，但保留轻量修订记录，避免重开后旧请求重新生效。
- 元数据首期白名单为 seed / origin / cellSize / width / height；不开放 palette 重排、静默裁剪或地表集迁移。多边形顶点在属性面板显式应用，确保非法临时形状不会半笔写入。
- 最终候选的跨操作错误以文档路径定位，operationIndex=-1；不把全图语义错误误标为最后一条操作造成。
- 128² 实测反馈 P95 ≤6.41ms，笔画到完整预览 ≤0.64s；256² 大面积批次仍可能有约 0.81s 主线程停顿。内存补采为整个 Editor 帧级计数，不宣称零分配。
- EditMode 697/697（含 MapEditTests 21 项）、PlayMode 77/77；内容校验 0 项问题。城镇 / 野外草稿与生成 Patch 已交付，尚未作为可玩双地图接入 Main，未构建 Windows Player。
