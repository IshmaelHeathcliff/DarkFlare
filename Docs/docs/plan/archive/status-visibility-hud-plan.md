# 状态显示分档与右上角 HUD

2026-09-14：已完成，承接状态阶段 4。

1. StatusDefinition 增加显示、可隐藏、从不显示三档，旧配置默认显示；纯展示配置不进入冻结战斗规则或存档。
2. 可隐藏默认显示，提供当前 Session 共用开关；显示不受开关影响，从不显示不进入 HUD 或状态查看。用户已确认此默认规则；显示开关在当前界面绑定期间共享。
3. HUD 状态条移动至右上角，保留层数、时间、悬停详情；菜单提供键鼠 / 手柄均可操作的隐藏开关。
4. 补充三档过滤、切换后浮窗 / 焦点、HUD 位置与原有输入的回归，更新模块文档并归档计划。

成功标准：隐藏不改变实际状态或其效果；两个显示入口过滤一致；右上角 HUD 不抢 Gameplay 方向输入；旧配置与存档兼容。
