# 阶段 6：整体验收与初版优化收尾

状态：已完成并归档

## 验收基线

- 当前及后续视觉、UI 验收只保证 `1920×1080`。
- 不再把 `1280×720` 与 `2560×1440` 纳入常规验收、自动化分辨率循环或正式截图。
- 已完成阶段保留原三档分辨率记录作为历史证据，不代表后续继续维护三档基线。
- 本阶段不扩展玩法、数值、内容池或美术范围，只验证现有初版优化的整合质量。

## 执行项

1. 将仍在运行的三档分辨率自动化收敛为 `1920×1080`，保留键鼠、手柄、焦点和布局边界断言。
2. 复用现有 PlayMode 端到端用例验证战斗随机重放、交易、打造、四槽换装、暂停恢复与动画反馈。
3. 在 Main 场景以 `1920×1080` 检查世界 / HUD、背包、商店和打造，并只保存最终有效截图。
4. 重复进入 Main，检查 Addressables 句柄、输入模式、暂停状态以及临时 Tween / UniTask 表现对象的清理。
5. 运行全量 EditMode、PlayMode、五个项目程序集编译、Console、Markdown 图片链接与 `git diff --check`。
6. 同步玩法、输入 UI、装备和视觉文档；完成后归档阶段 5 返工计划与本执行计划，并结束初版体验优化总计划。

## 完成门槛

- `1920×1080` 下世界边界、HUD、背包、商店、打造、详情和焦点状态均无关键遮挡或越界。
- 键鼠与手柄可完成菜单开关、选择、四槽换装、购买、出售和打造；状态恢复逻辑不回退。
- 固定种子战斗、掉落、伤害和怪物生命可复现，关闭固定种子后保持正常变化。
- 场景重复进入后不存在重复 Addressables 加载、失效 Handle、暂停残留或临时表现对象残留。
- 全量自动化、程序集编译、Console 和仓库检查均通过。
