## 目标与边界

玩家无需 Odin、输入实例 ID 或调试发放，即可通过键鼠 / 手柄完成获得道具 → 装备瓶收集 → 中心充能 → 属性分配 / 点亮 → 安装火焰与余烬 → 分配六槽 → 施法 → 保存继续。保留现有获取渠道和首轮参数，不增加洗点、自动换瓶、自动拆卸、自动施法、药水中心充能或新近战动作。

阶段四的普攻、六键、重绑定、冷却、迁移和最小 HUD 直接复用；阶段五验证它们与新界面的实际操作闭环。新功能与验收完成后才推进 `0.7.1-alpha.5`，不提前标记整个 0.7.1 完成。

## 界面与操作方案

采用现有 UIToolkit、RuntimePanelView / PanelRenderer、Theme / Components、Localization 与图标。通过 Unity MCP 创建 / 布局 / 导入并在 Editor 中验证；不直接修改已打开场景的 YAML。新增 MonoBehaviour 引用按 SerializeField / OnValidate 合同处理，不额外建立 EventSystem 或 Action Asset。

棋盘从已有菜单 / HUD 按钮进入，手柄经现有菜单路径可达，不要求新增 Gameplay 快捷键。建议采用宽棋盘工作区＋背包侧栏＋棋盘内滚动详情；进入时暂时隐藏其他大窗口并保存窗口组合，退出恢复有效组合和来源焦点。背包保持原格子尺寸，商店 / 打造授权与物品归属不变；棋盘不与全部既有窗口强行横排。

### 中心 7 格与充能

- 2026-10-16 用户已确认：中心一格显示能量瓶短暂选择；周围力量、敏捷、智力各占一格、呈三角排布，另三格暂留白。完整中心 7 格仍保留碰撞，留白格不能安装柴薪；继续复用 strength / dexterity / intelligence。
- 初期中心仅接受能量瓶。沿用 SelectEnergyBottleQuery：背包 / 专栏仍是物品所有者，中心只显示引用；关闭、取消、移动 / 出售源瓶、换装或 Session 变化使选择失效。
- 选择 → 显示实际能量、可兑换两类点数、池中余量及下一成本 → 明确确认“充入并消耗整瓶”。未满可用、空瓶拒绝，专栏瓶消费后清空，不自动更换；失败保持原状态。
- 专属瓶栏显示图标、容量、当前能量和满瓶文字，提供装备 / 更换 / 卸下 / 选择充能；提示只有装备瓶收集、溢出舍弃及满瓶需手动更换。它不占原十个战斗装备槽。
- 三属性显示已分配值、最终属性、可用属性点；先提供每次 1 点的明确分配操作。柴薪与普通天赋各自显示花费、资格与已点亮状态，不增加赠点或洗点机制。

### 无边界视图、键鼠和手柄

- 绘制中心保留区、六空洞、主体空格、中心空位、节点、显式长连线、实际裂缝连接及未连接外伸格。连线跨空格也按实际图展示，中柴薪中心明确留白。
- 只绘制视口内网格和必要节点；空白棋盘不创建无限 VisualElement。平移 / 缩放与数据修订按需重绘，不引入逐帧全盘查询。坐标溢出给出失败，不把可视范围当成玩法边界。
- 键鼠支持指针定位、滚轮缩放、中键平移、拿起 / 放置 / 取消；提供回中心、六空洞跳转、缩放和适配已安装网络按钮。
- 手柄使用既有 UI.Navigate 移动焦点；画布内以逻辑格游标和六邻居的屏幕方向选择，自动平移显露目标。中心、六根、背包、详情和六槽均有明确切换路径，不依赖鼠标或六根之间的巨量空格导航。
- 持有柴薪时，既有上一个 / 下一个窗口输入临时用于反向 / 正向 60° 旋转，优先由放置状态消费；空闲时恢复窗口循环。显示真实绑定 Glyph。平移缩放也有可聚焦按钮，不直接轮询设备或新增输入资产 owner。
- 操作状态收敛为浏览、携带道具 / 移动预览、选择中心瓶 / 充能预览、确认操作。Cancel 先撤销本层临时操作，再关闭棋盘 / 返回上层；暂停、Settings / Modal、失焦、设备拔出、面板重载和 Session 停止都清理捕获与待提交请求。

### 安装、连接、点亮与拆卸

- 从背包拿起只建立临时引用；旋转、移动指针和失败预览均不先移走道具或改变旧布局。预览的主体 / 空格 / 外伸格和提交共用同一候选最终态。
- 大柴薪对准六空洞；中小对准合法裂缝候选。唯一配对可展示并选中，多候选按稳定身份列出供选择；最终确认提交完整选定连接，不静默选一个父节点，也不因相邻自动获得词条。
- 点击节点打开详情，区分安装、嵌入与花点激活。火焰仅放大中心；余烬仅放未连接裂缝。非法类型、背包不足、断根、失去激活路径、连接 / 余烬互斥和过期预览都有本地化原因。
- 拆卸先逐件取出嵌入物，再明确选择“断连并取回本件”，展示将移除的连接及退还的实花天赋点，整次通过 Remove 预检提交。不能先写入单纯断线态导致外伸碰撞，也不递归取回其他柴薪。
- 范围预览高亮实际受影响火焰及可解释的路径步数；局部天赋 / 余烬采用正式已点亮最短路径结果，不画几何半径冒充范围。需要路径轨迹时提取共用纯图查询，不在 UI 再造一套 BFS。

### 六槽分配与信息

选择已安装点亮的火焰 → 选择槽 1–6 → AssignPlayerSkillCommand；另提供清槽。重复分配显示原子移槽结果，取回同步清槽，冷却继续随实例保留。普通技能只显示当前武器来源，不占火焰槽。

棋盘详情显示实际布局 / 变体、节点词条、激活花费、来源、局部路径范围、所属槽和冷却；中英与 Pseudo Locale 均可换行 / 滚动。沿用已有八类道具图标及资源皮肤；只有确认缺少生产美术组件时再调用生成技能，按单组件 PNG 合同制作，不扩大为全项目皮肤重做。
