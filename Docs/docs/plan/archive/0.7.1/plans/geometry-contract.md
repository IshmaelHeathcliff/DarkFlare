## 已确认规则

| 对象 | 固定主体形状 | 天赋 + 裂缝总数 N | 裂缝数 C | 其他约束 |
| --- | --- | --- | --- | --- |
| 面板中心 | 中心及相邻六格，共 7 格 | 不参与柴薪节点计数 | — | 中心支持能量瓶充能；力量、敏捷、智力三角排布。7 格均保留，柴薪不得覆盖。 |
| 初始空洞 | 六个位置，距面板中心 16 格 | — | — | 六芒星六顶点排布，每个接受一件大柴薪；棋盘无固定外边界。 |
| 大柴薪 | 半径 2 的完整六边形，共 19 格 | 9–15 | 1–6，且 C ≤ floor(N / 2) | 中心是火焰空位；内圈 1–3 个连接天赋计入 N；外圈允许留空。裂缝只在外圈六角。 |
| 中柴薪 | 半径 1 的完整六边形，共 7 格 | 4–6 | 1–3，且 C ≤ floor(N / 2) | 中心始终留白，暂时不能安装任何道具；六个外围格承载节点。 |
| 小柴薪 | 三格两两相邻的三角形 | 2–3 | 1–2 | **允许裂缝超过总数一半**；可连接小柴薪。无额外“至少一个普通天赋”限制。 |

节点总数只计算天赋和裂缝，不计算中心空位、普通空格、裂缝外伸连接格、嵌入的火焰或余烬。大小为主体形状大小，未连接的裂缝延伸格也占位；连接后的占位合并规则见下节。

大、中柴薪的裂缝接入更小柴薪：大可接中或小，中可接小；小与小连接是明确的同尺寸例外。火焰进入大柴薪中心，余烬进入裂缝，柴薪之间只通过裂缝相连。

大 / 中 / 小柴薪、火焰、余烬的背包尺寸均为 **1×1**，能量瓶为 **2×1**；这些矩形尺寸与棋盘主体 / 插槽属于不同空间合同，不缩小柴薪 19 / 7 / 3 格主体。能量瓶装入中心不在棋盘上另占两个六边形格。柴薪和普通天赋分别花点点亮，几何放置不代表已激活，见[成长合同](energy-progression-contract.md)。

最初五项澄清确认了小柴薪半数例外、完整形状占位、内圈计数、外圈留空和小三角形。2026-10-06 的下一步问答进一步确认：中柴薪沿径向外伸、小柴薪采用向外模板方向；**外伸端点直接与另一件柴薪的裂缝点重合，双方方向互相指向，每个裂缝最多连接一件柴薪，连接后没有额外外伸点**；内部连线允许跨空格。该最新规则替代先前拟定的“双方外伸格共享一个中间格”。

## 坐标与旋转的表达

采用轴坐标 `(q, r)`，第三轴 `s = -q - r`。两个格子的距离为 `max(|Δq|, |Δr|, |Δq + Δr|)`。距离表示格子中心之间的最少邻接步数，不使用屏幕像素距离。

六个方向依次为 `(1, 0)`、`(0, 1)`、`(-1, 1)`、`(-1, 0)`、`(0, -1)`、`(1, -1)`；六个初始空洞为这些方向乘 16。中心保留区为 `distance((q, r), (0, 0)) ≤ 1`。

| 数据 | 局部坐标表达 |
| --- | --- |
| 大柴薪主体 | 距局部中心 ≤ 2；内圈 6 格，外圈 12 格，中心 1 格 |
| 大柴薪裂缝候选 | 六方向乘 2，仅角格 |
| 大柴薪外伸连接格 | 对应裂缝的方向乘 3；每个裂缝沿径向延伸一格 |
| 中柴薪主体与外伸 | 距局部中心 ≤ 1，中心为空但占空间；外围裂缝沿对应六方向外伸至方向乘 2 |
| 小柴薪主体与外伸 | `(0, 0)`、`(1, 0)`、`(0, 1)`；三对距离均为 1；裂缝从顶点向外相邻一格，允许方向由模板显式记录 |
| 一档旋转 | `(q, r) → (-r, q + r)`；六档，每档 60° |
| 放置 | 对主体、节点和连接格一起旋转，再加锚点平移 |

同一局部节点身份在旋转后保持不变。连续六次旋转必须还原坐标、连接方向、节点与范围来源；旋转不是重新生成。中柴薪径向与小柴薪向外模板方向已确认，方向随主体一起旋转；小模板不得将端点放在自身主体内。

用户已确认棋盘**无固定外边界**；“六空洞距中心 16 格”仅表示初始空洞位置，不能据此把所有柴薪限制在半径 16 内。中心属性的具体格子映射未指定，示意布局不作为新增规则。

## 完整占位与裂缝直接连接

未连接时，每件柴薪的占位集合为“固定主体全部格子 ∪ 此实例裂缝的外伸连接格”。天赋数量少不会缩小主体：大柴薪 19 格、中柴薪 7 格、小柴薪 3 格中的空格仍参与碰撞。

中心的火焰空位也是柴薪主体占位，火焰是该插槽的内嵌道具，不能因此允许另一件柴薪覆盖中心。余烬同理：必须由裂缝插槽证明所有者，不能以独立棋盘占位绕过插槽校验。

连接时，外伸端点直接落在另一件柴薪的裂缝节点格，不在两件之间保留额外桥接格；固定主体之间仍不能重叠。这个端点与裂缝的合并是明确例外，不能允许端点落到普通天赋、空格、火焰中心或面板中心保留区。

配对要求裂缝格相邻、双方外伸方向互相指向，且每个裂缝最多连接一件柴薪。占位校验先证明配对，已配对端点并入对方裂缝，最终只计算全部固定主体与未连接外伸格；断开连接时重新纳入外伸占位并预检，不能先删除连接再留下冲突。单向指向和两外伸端点共享第三格都不是合法配对。

正式安装规则已确认连接柴薪与安装余烬互斥。拆卸先逐件手动取出火焰 / 余烬，再从末端手动断连、逐件拆除柴薪；末端以拆下后其他柴薪仍连接至少一个初始空洞判定，适用于环和跨根网络。正式事务已由[阶段二](phase-2-execution.md#2-权威棋盘与事务)落实，几何预检不能代替安装 / 拆卸资格。

双向相接的局部例子：

| 部件 | 锚点 | 裂缝世界格 | 未连接时的外伸目标格 |
| --- | --- | --- | --- |
| 大柴薪 A | `(16, 0)` | `(18, 0)` | `(19, 0)`，是 B 的裂缝格 |
| 中柴薪 B | `(20, 0)` | `(19, 0)` | `(18, 0)`，是 A 的裂缝格 |

两个完整主体互不相交，裂缝格相邻，连接后没有第三个中间格，两个节点身份各自保留。A 位于六个初始空洞之一且避开中心保留区；方向不匹配或已有连接的相邻裂缝不可配对。

## 合法数量与布局生成

必须先选择合法数量组合，再生成布局；不能先分别随机总数和裂缝数，再静默裁掉越界裂缝。

| 尺寸 / 总数 | 合法裂缝数 |
| --- | --- |
| 大 N = 9 | 1–4 |
| 大 N = 10–11 | 1–5 |
| 大 N = 12–15 | 1–6 |
| 中 N = 4–5 | 1–2 |
| 中 N = 6 | 1–3 |
| 小 N = 2–3 | 1–2，允许超过半数 |

大柴薪再选择内圈天赋数 L，满足 `1 ≤ L ≤ 3`、`0 ≤ N - L ≤ 12`、`C ≤ N - L`。例如 N = 15 必须 L = 3；不能生成“15 个节点、只有 1 个内圈天赋”的超容量盘。内圈连接天赋不能同时充当裂缝。

裂缝总是尽可能对称排布。对称优先针对裂缝集合，不要求随机普通天赋或词条也对称。实现采用合法候选枚举、对称性排序和独立种子打破等价布局。数量分层等概率选择，最高评分端口按旋转类与朝向分别抽取，普通天赋按剩余槽无放回选择；这是技术合同，不登记为用户指定的概率。

大柴薪六角的可行对称范例：两个裂缝取对角，三个取交替角，四个取两组对角；一个、五个无法达到六方向完全对称，选择其数量下的最大可用对称性。中柴薪按外围六格处理；小三角形按模板方向评价完整端口布局，不能套用大柴薪六角索引。

内部天赋连线允许跨过空格，空间相邻不是连线的必要条件；空格仍属于主体占位，不打断已定义连线。连线通过显式节点身份表达，不自动在途经格生成节点或赋予效果。大柴薪内圈天赋连接中心与外圈；空格、连线与花点激活各自分开，具体激活资格留在成长阶段确定。

## 几何诊断输出

调试预览应能显示锚点、旋转、节点类型、全部占位、裂缝与连接格、中心保留区、连接关系和具体失败原因。生成校验报告应指出非法数量组合、内圈容量、非角大裂缝、重复节点、端口落入主体、旋转后占位冲突与不支持的连线。

这些输出用于规则和事务验证；正式玩家界面只显示与当前操作相关的放置失败、连接和效果范围，不展示内部坐标 / 随机流等实现细节。
