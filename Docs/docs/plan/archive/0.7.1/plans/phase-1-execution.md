# 0.7.1-alpha.1 几何与生成实施计划

状态：2026-10-06，**A–E 已完成并验收，运行版本 `0.7.1-alpha.1`**。源码身份为 `main` / `8ee25b1` 加当次未提交实现；Unity `6000.6.4f1`。入口：[活动总计划](alpha-0.7.1-skill-board-plan.md) · [几何合同](geometry-contract.md) · [阶段验收](../acceptance/checklist.md#一几何与生成)。实际测试、截图、修复记录和源码 SHA-256 见[验收报告](../acceptance/geometry/README.md)。

## 本阶段交付

建立可独立测试的六边形规则与柴薪布局生成器，提供 Odin 调试预览。完成中心 7 格、六根距离 16、大 / 中 / 小主体、六档旋转、完整占位和合法端口碰撞校验；生成数量与布局可以复现，失败原因可以定位。

此阶段的预览使用独立样例数据。正式道具所有权、交易 / 存档、能量成长、技能输入与玩家棋盘 UI 继续由后续阶段交付；生成布局的数据合同为它们保留稳定节点身份，不提前写入玩家存档。

纯几何与生成按 Utility 职责组织，不依赖 `GameArchitecture`、输入或 UI，也不注册空 Model / System。阶段二接入权威棋盘 Model、事务 System 和 Command / Query；此时再按实际生命周期注册。Editor 只展示规则结果，不复制一套生成或碰撞逻辑。

配置复用[配置中心](../../../../config-center.md)的非内容配置显式发现与中文 Odin 标注。原拟 `DarkFlare/Data/` 菜单在回归中暴露了正式内容登记要求，因此生成模板改用 `DarkFlare/技能面板/柴薪生成配置`，沿用已有显式类型发现方式，保留配置中心访问而不新增正式物品身份。新增顶层 / 可达嵌套类型同步登记[字段覆盖入口](../../../../config-reference/README.md#变更流程)，逐字段写职责、默认值、范围和消费者。模块入口为 `Docs/docs/skill-board/geometry.md` 与字段参考 `Docs/docs/config-reference/skill-board.md`。阶段一配置不进入正式物品内容池；后续内容登记时再评估 core 版本。

## 生成与连接的技术合同

1. 先枚举 N / C / L 合法组合并核对几何可行性。大 N = 15 必须 L = 3；小 N = 2、C = 2 仍合法。不能用“必须有普通天赋”删除小柴薪已确认组合。
2. 内部连接使用显式节点 ID 边，允许跨空格，不以六边形相邻图代替天赋连线。大 / 中柴薪外圈按环序连接实际节点并跳过空位置；大中心经 L 个内圈天赋连接外圈，小柴薪连接实际 2–3 个节点。所有边端点须存在，不能沿线填入额外天赋 / 裂缝或改变 N；中柴薪空中心不成为可花点节点或火焰插槽。连线只表达路径，后续花点与技能可用性仍服从正式激活合同。
3. 在数量与连线约束均满足的候选中评估裂缝对称性。先比较保持裂缝及外伸方向集合不变的非恒等旋转数量，再比较反射数量，最后最大化最小裂缝间几何距离；小柴薪使用三角形的对称变换。反射只用于评分，不增加玩家翻面操作。
4. 先等概率选可行 N，再等概率选该 N 下可行 C，大柴薪再选可行 L；对称最高档端口候选按允许旋转归并等价类，再选类与合法朝向。数量抽取不因某个数量拥有更多布局而自动获得更高权重；发现数学合法组合不可生成时报告并解决约束冲突，不静默缩小用户范围。候选类的规范排序与重定位方式在实现中一并写明。
5. 生成器显式接收种子与模板内容，布局记录固定 `ContractVersion = 1`，沿用现有 `System.Random` 和稳定混合子种子方式，分开数量 / 布局等子流。不调用 `GameplayRandomSystem.NextSeed`、`UnityEngine.Random` 或不稳定的字符串哈希；不改现有随机通道枚举。正式物品种子入口在阶段二接入。稳定排序不依赖字典遍历，生成结果不写回共享 SO。
6. 为数量可行性与布局候选做有限搜索和剪枝，不物化无界笛卡尔积；预览记录候选数、最优对称评分、搜索耗时与失败原因。本次每次生成重建有限候选，不维护跨配置缓存；模板修订立即影响后续生成。保存实际布局，后续升级不靠新算法重新生成旧道具。
7. 放置先检查固定主体互不相交，再证明相邻裂缝双向指向且各自未占用，合并已连接外伸格，最后检查全部主体与未连接外伸格。不能把端点 / 裂缝的合法重合一律判为主体碰撞，也不能允许端点进入普通天赋或空格；单向指向、隔格共享外伸点与一个裂缝接入多件均失败。断开或旋转需重新预检最终占位。连接记录保存双方稳定端口身份；不同空洞可连通，网络允许环，不能强行选唯一父节点。

## 验证与完成门槛

| 验证 | 保护的行为与执行方式 |
| --- | --- |
| 坐标 / 旋转 | 所有尺寸、六档姿态及负锚点；旋转与平移组合保持距离和局部身份，越界运算不能绕过碰撞 |
| 数量 / 模板 | 覆盖每个合法 N / C 与可行 L，包括小两裂缝、大最大节点；跨空格连线保持连通而空格仍碰撞。非法数量、重复节点 / ID、非角大裂缝、内伸端口、缺失边端点与非法中心连接有明确负例 |
| 对称 / 随机 | 与独立小规模候选枚举结果比较最优性；同输入重放、旋转不重掷，配置输入与现有随机状态保持不变；用确定性映射检查分布步骤，不靠容易波动的统计阈值证明概率 |
