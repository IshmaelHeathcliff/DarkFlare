# 物品窗口 UI 修正

## 目标与计划

1. 阅读进度、装备、输入和物品窗口文档并确认实现。
2. 删除详情图标；按 48 px 格子 / 4 px 间距重排十槽，弱化空槽灰阶图案。
3. 接入 Shift / 手柄左扳机按住对比，兼容双戒指与窗口生命周期。
4. 商店 / 打造默认打开背包，统一 560 px 宽并居中，隐藏重复来源和摘要；顶部关闭全部返回游戏。

## 成功标准

- 装备槽不小于指定格尺寸，十槽互不重叠，背包完整可见。
- 对比按住显示、松开消失；拖放 / 暂停 / 关闭时无残留，戒指能显示两个对应物品。
- 商店与打造联动背包，窗口同宽；顶部关闭清理所有窗口并恢复玩法输入。
- 相关测试通过，视觉检查记录实际结果。
