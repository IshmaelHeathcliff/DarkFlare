## 技术与美术合同

详细规格见[地表资产家族合同](../../../../maps/terrain-art-contract.md)。复用现有暗色奇幻风格参考，不添加草、石板、道具等其他地表语义到泥土 Pilot。源图只承担材质纹理，几何分区始终来自 B 的 Wang Key。

编译源与输出分离：源为高分辨率完整单图，C2 固定全画布等比采样至 64×64，再按统一周期边和分区规则编译；禁止逐张裁切、按内容缩放或人工修 Pivot。每个生产输出单独 PNG / Single Sprite，不组装 SpriteSheet。所有兼容边仅由该边端点材质、固定采样相位和边合同决定，不能受其余角、坐标随机数或 VariantId 影响。

第一版保留 B 的整数分区形状；只增加材质纹理，不暗中修饰水岸以改变几何。需要轮廓美化时另立可量化的渲染 / 几何共同修订。鞍点仍不提供零宽通行。

## C1 验证策略

使用 Unity Editor API 读取 Prefab 和 Preview Scene；不修改玩法半径、场景布局或镜头。材质先以独立 Sprite 在隔离预览中显示，按 Main 正交 size=5、1920×1080 与既有角色 Sprite 同框；可以显示格线与半径圆用于尺度判断。该预览无物理模拟，不等于 D 的可达性验收。

执行技能单图审计，保存不可变源图、完整提示词、输入参考 Hash、审计结果和截图。C1 不新增按历史资产数量断言的测试，也不扩展地图运行时结构；C2 起为确定性编译、失败回退与资源生命周期补充已有模块测试。一次性尺度 / 截图脚本在完成后清理。

## C2 实施细化

1. 纯编译算法按整数重叠面积将完整方图采样到 64×64（sRGB 字节域、四舍五入），X 后 Y 对边同步，固定 2 px 硬边 / 至第 8 px 羽化；变体继承基准材质边带。分区调用 B 的 TerrainPartition，不变更地表归属。
2. Editor `TerrainTextureSources` 配置地表集、各材质基准源和显式变体绑定。变体按既有 VariantId 绑定，可覆盖其 Key 中部分材质，未覆盖的材质使用基准；每个规则候选都必须有明确绑定，不能静默丢失变体。
3. 编译前校验完整地表集、源尺寸 / Alpha / 身份，摘要包含原始源内容、规则与算法修订。最多首期四材质（256 Key），不将四材质发布上限混入 B 的 64 材质语义支持。
4. 输出目录按源配置 GUID 和内容摘要隔离，成功整批生成独立 PNG / Sprite / Tile 与只读目录资产后，才更新配置中的产物引用。失败 / 取消只删除本次创建的隔离目录，旧产物保持；已有修订不得覆盖，损坏产物报告错误。历史修订先保留，避免破坏既有消费者。
5. 扩展既有独立预览的正式模式，显式选择源配置；检查源修订、RuleHash、全部 Tile，缺失 / 过期拒绝，不以诊断色补洞。复用会话取消、整帧发布和场景释放。
6. 测试整数面积预期、周期边和角、变体边带、全部 256 Key 兼容边、确定性摘要、编译失败 / 取消与旧产物不变、真实正式预览资源释放。只创建真实泥土源的正式配置和样例，其他材质在长期测试中使用合成像素，不作为生产艺术交付。

## C3 实施细化（完成）

1. 保持已批准泥土源不可变，逐张生成草地 / 水 / 道路基准和四材质第二源，每张先审计再扩展。统一原生 1254×1254，不透明；继续使用既有完整画布 64×64 编译合同。
2. 草地为低饱和灰橄榄色短草块面；水为冷暗蓝灰、稀疏短涟漪，无岸线或反射物；道路为灰褐压实细砾、稀疏断续车辙，不画道路边界、石板或标线。道路轮廓由地图四角归属决定，源图仅表达路面。
3. 在 Data/Maps/Terrain 独立资源包目录建立正式 dirt / grass / water / road 与 terrain_set:basic；水不可步行，其余沿用单位代价。每种纯地表绑定 00 / 01 两个规则候选（00 复用基准源），混合 Key 使用基准；编译 256 个基准 Key + 8 个纯地表候选。
4. 建立单一正式显示目录与稳定 Addressables 地址，通过既有资源 owner / lease 加载；源图与 Editor 配置不进入运行时依赖。发布前严格校验源 / 规则 / Tile 修订、地址与依赖；旧编译目录保持不变，禁止把旧修订继续标记为当前资源。
5. 用持久四材质技术样例复核单材质、混合边和两变体；保存原生像素与 Main 镜头截图、真实 PNG 共享边量化、Addressables 加载 / 释放与内容校验。补充必要的长期资源目录回归，完整项目测试通过后更新模块文档。C4 的最终地图观感 / 压力验收继续保留为后续独立步骤。

## C4 实施细化（完成）

1. 复用 B 的拓扑 / 边界 / 压力文档生成器，显式映射到正式地表身份与变体；持久化正式拓扑和跨块样例，提供菜单入口，仅补缺失文件，不覆盖已有内容。
2. 采集正式拓扑、边界的 1920×1080 与每显示格 64 px 原生渲染，另按 Main size=5 检查接点近景；角色尺度沿用同修订的 C3 实际 Main 证据。验证渲染输出共享边逐像素一致、不透明，并人工复核水岸、道路、孤点、鞍点、三 / 四材质交点、变体与跨块。
3. 256×256、seed=19260817，三轮冷 / 相同快照热 / (31,31) 单格修改，分别记录端到端构建、规则比较 / 求解、首次渲染及内存；区分已加载的持久资源与预览自建资源。相同快照重算 0、单格修改重算 4、关闭后自建资源回到基线，不将 Editor 观测视为怪物导航预算。
4. 在正式 Tilemap 已开始填充时取消 / 关闭，验证旧帧不被迟到结果替换、持久 Tile 存活、自建场景与资源释放。既有测试已覆盖诊断取消和正式失败恢复，补充正式构建中取消的独有生命周期覆盖，清理一次性截图与测量脚本。
5. 通过相关回归和内容校验后总结正式样例与资源模块，归档整个 C 计划并修正入口链接；0.5.0 继续进入 D 同源几何，运行版本保持不变。
