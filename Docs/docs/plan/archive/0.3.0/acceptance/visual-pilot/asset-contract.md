- 内底使用接近 `#111821` 的低对比炭黑石材；外框旧铁，金铜只作局部细线。硬边颗粒目标为源图约 8 px，对应边框约 1 屏幕像素；中央接近均匀暗色，避免拉伸明显裂纹。
- Alpha 阈值 8，主体包围盒宽高 1254，覆盖率 0.95–1，中心 x/y 均在 621–633；面板满幅，无外部投影或透明外边距，允许四角小切角透明。
- Sprite Single、Full Rect、PPU 100、Pivot (0.5,0.5)、Point、无压缩、Mipmap Off、sRGB On、Alpha Is Transparency、Wrap Clamp。
- 不烘焙文字、标题、物品、分隔线、关闭按钮、数量或状态光圈；状态由现有活动窗口 / 唯一物品高亮管理。背景自身不参与命中和导航。
- 先逐图运行单图审计，再检查原生像素和真实窗口；量化通过不能替代视觉检查。未通过不得扩展家族。

## 首次输出与重新冻结

首张请求 1024×1024，工具实际输出 1254×1254 RGB，不符合最初合同，未导入。第二次生成前将画布固定为 1254×1254，保留 Border 96 与 Slice Scale 0.125；该底板为刻意不透明满幅，允许 RGB（alpha_required=false）。不对首张事后放宽审计，也不进行逐图裁切或缩放。

## 最终消费者验收

为确保展开属性后仍能读取完整行，收尾将窗口组高度从 872 调整为 896，装备区只去除 24 px 空白，保留大槽 152 px。底板画布、Border 和 Slice Scale 均未修改。最终三档检查为最小 560×788（Pseudo 背包）、常规 560×798（中文 / 英文背包）、最大 760×798（商店 / 打造）；三语言全部组合见 layout-check.txt。同一九宫格在这些尺寸下均通过截图复核。
