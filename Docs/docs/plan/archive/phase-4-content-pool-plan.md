# 阶段 4：标签、词条与内容池填充

> 状态：已完成
> 完成日期：2026-08-06
> 当前模块说明：[首批内容池](../../content-system.md)

## 目标

在不新增 AI、复杂随机机制和正式美术的前提下，把现有内容扩充为 14 个标签、12 个实际生效词条、7 件装备和 3 种怪物，并同步接入掉落、商店、打造与刷怪池。

## 实施范围

1. 把稳定 ID 统一为小写 `snake_case`，将 `Afflixes` 通过 AssetDatabase 迁移为 `Affixes` 并保留既有 GUID。
2. 增加内容配置校验器和配置中心“内容校验”页。
3. 配置 12 个当前管线实际支持的词条，补齐标签兼容、互斥组与权重。
4. 配置 2 武器、2 护甲、3 戒指，以及七件普通商品和完整打造池。
5. 配置均衡、迅捷、重装三种怪物，建立独立 Prefab、掉落表和加权刷怪池。
6. 保留阶段 3 的独立随机通道、怪物生命倍率和表级掉落语义。

## 完成结果

- 正式资产达到 14 标签、12 词条、7 装备、3 怪物、3 掉落表和 3 个独立 Addressable 怪物 Prefab。
- `DamageCalculator` 使用技能上下文与伤害包标签的并集匹配转换和元素额外伤害，`physical` 条件可正确生效。
- 商店、打造、掉落与刷怪池使用同一批正式内容，不存在孤立词条或装备。
- `ContentConfigurationValidator` 覆盖数量、ID、范围、运算、标签、兼容性、池覆盖、Prefab 与 Addressables。
- Main 前 12 个固定种子生成实例覆盖三种怪物并可完整重放。

## 验收结果

- 全量 EditMode 87/87 通过。
- PlayMode 12 项中 10 项通过、2 项 Input System 上游用例按原标记忽略、0 失败。
- 正式装备购买、打造、四槽装备 / 卸下和出售，以及固定种子 `24681357` Main 前 12 个实例双次重放均通过。
- Runtime、Editor、EditMode 与 PlayMode 四个程序集编译 0 警告、0 错误。
- 三个怪物 Prefab 均通过 Main Addressables 预热，最终 Unity Console 无错误。
