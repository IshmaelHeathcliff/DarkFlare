# 0.7.1 技能面板几何与生成合同

状态：2026-10-06，**用户确认规则与拟定技术表达**；尚无对应运行时实现。执行入口见[技能面板计划](../alpha-0.7.1-skill-board-plan.md)，验证路径见[验收清单](acceptance.md)。

## 已确认规则

| 对象 | 固定主体形状 | 天赋 + 裂缝总数 N | 裂缝数 C | 其他约束 |
| --- | --- | --- | --- | --- |
| 面板中心 | 中心及相邻六格，共 7 格 | 不参与柴薪节点计数 | — | 中心支持能量瓶充能；力量、敏捷、智力三角排布。7 格均保留，柴薪不得覆盖。 |
| 初始空洞 | 六个位置，距面板中心 16 格 | — | — | 六芒星六顶点排布，每个接受一件大柴薪。 |
| 大柴薪 | 半径 2 的完整六边形，共 19 格 | 9–15 | 1–6，且 C ≤ floor(N / 2) | 中心是火焰空位；内圈 1–3 个连接天赋计入 N；外圈允许留空。裂缝只在外圈六角。 |
| 中柴薪 | 半径 1 的完整六边形，共 7 格 | 4–6 | 1–3，且 C ≤ floor(N / 2) | 中心始终为空，六个外围格承载节点。中心安装火焰的权限尚未指定。 |
| 小柴薪 | 三格两两相邻的三角形 | 2–3 | 1–2 | **允许裂缝超过总数一半**；可连接小柴薪。无额外“至少一个普通天赋”限制。 |

节点总数只计算天赋和裂缝，不计算中心空位、普通空格、裂缝外伸连接格、嵌入的火焰或余烬。大小为主体形状大小，额外的裂缝延伸格也占位。

大、中柴薪的裂缝接入更小柴薪：大可接中或小，中可接小；小与小连接是明确的同尺寸例外。火焰进入大柴薪中心，余烬进入裂缝，柴薪之间只通过裂缝相连。

能量瓶背包尺寸 2×1 与棋盘中心插槽属于不同空间合同；装入中心不在棋盘上另占两个六边形格。柴薪和普通天赋分别花点点亮，几何放置不代表已激活，见[成长合同](energy-progression.md)。

五项澄清已经确认：小柴薪允许两个裂缝并超过半数；连接允许共享一个连接格；碰撞使用整个固定形状；大柴薪总数包含内圈连接天赋且外圈可留空；小柴薪采用三角形。

## 坐标与旋转的拟定表达

采用轴坐标 `(q, r)`，第三轴 `s = -q - r`。两个格子的距离为 `max(|Δq|, |Δr|, |Δq + Δr|)`。距离表示格子中心之间的最少邻接步数，不使用屏幕像素距离。

六个方向依次为 `(1, 0)`、`(0, 1)`、`(-1, 1)`、`(-1, 0)`、`(0, -1)`、`(1, -1)`；六个初始空洞为这些方向乘 16。中心保留区为 `distance((q, r), (0, 0)) ≤ 1`。

| 数据 | 局部坐标表达 |
| --- | --- |
| 大柴薪主体 | 距局部中心 ≤ 2；内圈 6 格，外圈 12 格，中心 1 格 |
| 大柴薪裂缝候选 | 六方向乘 2，仅角格 |
| 大柴薪外伸连接格 | 对应裂缝的方向乘 3；每个裂缝沿径向延伸一格的拟定表达 |
| 中柴薪主体 | 距局部中心 ≤ 1，中心为空但占空间 |
| 小柴薪主体 | `(0, 0)`、`(1, 0)`、`(0, 1)`；三对距离均为 1 |
| 一档旋转 | `(q, r) → (-r, q + r)`；六档，每档 60° |
| 放置 | 对主体、节点和连接格一起旋转，再加锚点平移 |

同一局部节点身份在旋转后保持不变。连续六次旋转必须还原坐标、连接方向、节点与范围来源；旋转不是重新生成。中、小柴薪裂缝外伸方向须由模板显式记录，具体允许方向仍待确认。

“六空洞距中心 16 格”不是面板半径上限，不能据此把所有柴薪限制在半径 16 内。中心属性的具体格子映射未指定，示意布局不作为新增规则。

## 完整占位与共享连接格

每件柴薪的占位集合为“固定主体全部格子 ∪ 此实例裂缝的外伸连接格”。天赋数量少不会缩小主体：大柴薪 19 格、中柴薪 7 格、小柴薪 3 格中的空格仍参与碰撞。

中心的火焰空位也是柴薪主体占位，火焰是该插槽的内嵌道具，不能因此允许另一件柴薪覆盖中心。余烬同理：必须由裂缝插槽证明所有者，不能以独立棋盘占位绕过插槽校验。

共享连接格是唯一已确认的柴薪碰撞例外：两件柴薪连接允许共享一个连接格，且只能裂缝与裂缝相接。它不允许主体、天赋格、空格、火焰中心或面板中心保留区重叠。是否仅限双方延伸端点、是否允许多于两件共享，见主计划的待明确项。

拟定的双方延伸端点共享例子（只说明几何可行性）：

| 部件 | 锚点 | 裂缝世界格 | 延伸连接世界格 |
| --- | --- | --- | --- |
| 大柴薪 A | `(0, 0)` | `(2, 0)` | `(3, 0)` |
| 中柴薪 B | `(5, 0)` | `(4, 0)` | `(3, 0)` |

两个完整主体互不相交，交集仅为 `(3, 0)`。该局部例子不是把大柴薪放在面板中心；实际放置时整体平移到合法区域。相邻但未满足正式端口配对的格子，不可自动建立裂缝连接。

## 合法数量与布局生成

必须先选择合法数量组合，再生成布局；不能先分别随机总数和裂缝数，再静默裁掉越界裂缝。

| 尺寸 / 总数 | 合法裂缝数 |
| --- | --- |
| 大 N = 9 | 1–4 |
| 大 N = 10–11 | 1–5 |
| 大 N = 12–15 | 1–6 |
| 中 N = 4–5 | 1–2 |
| 中 N = 6 | 1–3 |
| 小 N = 2–3 | 1–2，允许超过半数 |

大柴薪再选择内圈天赋数 L，满足 `1 ≤ L ≤ 3`、`0 ≤ N - L ≤ 12`、`C ≤ N - L`。例如 N = 15 必须 L = 3；不能生成“15 个节点、只有 1 个内圈天赋”的超容量盘。内圈连接天赋不能同时充当裂缝。

裂缝总是尽可能对称排布。对称优先针对裂缝集合，不要求随机普通天赋或词条也对称。拟定采用合法候选枚举、对称性排序和独立种子打破等价布局；旋转等价布局的概率与随机数量分布须在实现前明确，不能声称已指定均匀分布。

大柴薪六角的可行对称范例：两个裂缝取对角，三个取交替角，四个取两组对角；一个、五个无法达到六方向完全对称，选择其数量下的最大可用对称性。中柴薪按外围六格处理；小三角形在实际外伸方向确定后评价完整端口布局，不能套用大柴薪六角索引。

节点空间相邻与天赋效果的连线 / 激活不是同一合同。内圈天赋必须满足用户所述连接中心与外圈的作用；在连线规则确认前，不把“留空格允许碰撞占位”误读为“所有天赋可无连接悬空生效”。

## 实现前校验输出

调试预览应能显示锚点、旋转、节点类型、全部占位、裂缝与连接格、中心保留区、连接关系和具体失败原因。生成校验报告应指出非法数量组合、内圈容量、非角大裂缝、重复节点、端口落入主体、旋转后占位冲突与不支持的连线。

这些输出用于规则和事务验证；正式玩家界面只显示与当前操作相关的放置失败、连接和效果范围，不展示内部坐标 / 随机流等实现细节。
