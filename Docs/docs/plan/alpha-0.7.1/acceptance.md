# 0.7.1 技能面板阶段验收清单

状态：2026-10-06，**待执行**。本文定义通过条件，不是已通过报告。主入口见[执行计划](../alpha-0.7.1-skill-board-plan.md)，核心规则见[几何合同](geometry.md)、[技能重构 / 六键施放合同](manual-skills.md)及[能量瓶 / 成长合同](energy-progression.md)。

每阶段记录实际提交 / 工作区身份、运行版本、Unity 与包版本、定向 / 完整测试结果、截图或日志、未执行项。2026-09-29 的项目回归仅为历史基线；未执行的 Player、设备和跨进程项目不得标作通过。

## 一：几何与生成

- [ ] 中心保留区恰为 7 格，六根距中心均为 16；安装不能覆盖中心保留区，根距不被当成棋盘外边界。
- [ ] 大 19 格、中 7 格、小 3 格三角形的主体占位正确；空节点、中心空位和裂缝延伸格均参与碰撞。
- [ ] 大 / 中数量组合受半数限制，小允许两个裂缝；大 N = 15 时强制三个内圈天赋，非法配置给出可定位错误。
- [ ] 大裂缝只在六角，外伸一格；中 / 小按已确认模板规则。旋转六次还原，同布局旋转不改变节点身份或随机结果。
- [ ] 对称布局在可行候选中优先；同种子 / 同生成合同得到同布局，不消耗战斗 / 掉落随机流。
- [ ] 正常共享端口通过；主体 / 空格 / 中心重叠、非裂缝接触、未配对端口、超出共享容量失败。端口例外不放宽其他碰撞。

纯规则使用按模块命名的 EditMode 回归；Odin 预览记录代表性的数量边界、旋转和共享格，截图只保留为当次证据。

## 二：物品、能量瓶、安装与持久化

- [ ] 大柴薪进初始空洞；中 / 小通过合法裂缝接入，小与小连接可行；跨根连接和环不会产生重复所有者或重复节点。
- [ ] 变体的布局、种子、词条和稳定身份在移动、旋转、交易及保存恢复后不变；火焰、余烬交易复用现有价格与所有权事务。
- [ ] 安装 / 取回 / 交换成功后背包、棋盘、插槽和连接一致；碰撞、背包不足、类型不符、过期预览失败时零部分变更、零成功事件。
- [ ] 按确认策略取回带嵌入物或跨根连接的柴薪；任一容量 / 连接预检失败全部回退。余烬与连接端口互斥规则有正反例。
- [ ] 三种能量瓶背包占位均为 2×1、容量不同；瓶内能量始终处于容量内，移动 / 换装和保存恢复保留数值与身份。
- [ ] 专属栏只接受能量瓶，装备 / 替换 / 卸下原子提交，背包不足完整回退；未装备瓶不自动获得能量。
- [ ] 击杀积蓄证明玩家归属，普通攻击 / 持续伤害归属一致；重复死亡、读档重建、场景销毁不重复奖励，满瓶按已确认规则处理。
- [ ] 中心能量瓶实际归属或引用合同落实；放入、取回与充能请求能证明所有权，不产生重复所有者或悬空引用。
- [ ] 新存档保存权威布局、安装关系和变体；旧档按明确迁移规则建立有效默认面板，不丢失原技能可玩性，不在恢复时重新生成物品。
- [ ] 六槽技能分配保存稳定来源引用；旧单技能 / 自动间隔迁移至可手动施放的技能与剩余冷却，不恢复自动循环、不重复发放起始道具。
- [ ] 重复实例、非法占位、内容缺失和拓扑错误在恢复预检失败；运行中的 Session、有效存档和玩家数据不被污染。

扩展已有物品、背包事务、交易和 Save Restore 测试，使用隔离数据根；真实旧档夹具长期保留。新增存档合同进入此阶段时评估 Schema 迁移。

## 三：中心充能、属性分配与点亮

- [ ] 未满瓶也能充入全部实际能量，同时消费该实例；瓶子删除、装备 / 中心清空、能量池和点数首次通知时均为一致最终态。
- [ ] 剩余能量跨瓶累计，够多点时按逐点递增成本兑换；每 1 天赋点同时发放 1 属性点，分瓶与合瓶的等量能量得到相同兑换结果。
- [ ] 花天赋点、换瓶、切图和读档不降低下一点成本；预览和正式提交共用曲线，非法曲线 / 溢出失败不损失能量。
- [ ] 取消、重复请求、所有权变化、瓶子在预览后继续积蓄、成长 Revision 变化和提交失败均不部分消费或重复加点；保留外部合法变化。
- [ ] 三属性分配分别扣可用属性点，点数不足不修改；仅影响当前玩家，保存恢复 / 属性重建不重复加值或修改共享配置。
- [ ] 柴薪与普通天赋分别扣天赋点点亮，点亮柴薪不自动获得全部词条；重复点亮、非法节点 / 上游资格、余额不足失败不扣点。
- [ ] 已点亮物品取回 / 转移按确认合同处理，不能复制或遗留效果 / 点数收益；物品身份、激活记录和点数保持一致。
- [ ] 成长余额、累计兑换数、属性分配和激活记录保存恢复一致，旧档初始化不重放充能 / 发点；起始技能与点亮规则不会产生不可战斗软锁。

复用物品使用、装备事务、属性重建与存档测试，新增独立成长规则覆盖；优先用纯逻辑验证递增阈值、余额守恒和点数失败回退，不建立按版本命名的永久套件。

## 四：技能重构、六键施放、天赋与余烬

- [ ] 无技能输入时，进图、遇敌、冷却结束、复活与继续游戏均不施放；六个输入槽能请求对应技能，空槽不调用默认技能。
- [ ] 单次按下最多一次施放；冷却中连按、换槽、重复引用及同帧请求不能绕过冷却 / 法力校验；失败不扣法力、不启动冷却、不排队补发。
- [ ] 火焰安装获得技能，取回按确认规则清除 / 禁用绑定；多个火焰的分配、施放和冷却可操作并可恢复，六槽最小 HUD 反映真实状态。
- [ ] 冷却遵循玩法暂停，重绑定、菜单切换、保存恢复与换槽不重置冷却；请求中来源变化或 Session 取消不能施放另一枚火焰。
- [ ] 全局天赋仅按来源应用一次；局部天赋与余烬只影响确认距离内的火焰。验证边界、刚好越界及范围起点。
- [ ] 未点亮普通天赋没有词条效果，点亮后按来源生效；火焰与裂缝资格服从最终柴薪激活规则，六槽绑定不能绕过。
- [ ] 两个同技能定义火焰，只有一个在范围内时效果不串用；标签、伤害转换和已有条件仍沿用现有管线。
- [ ] 旋转、移动、拆卸和重连后目标集合正确；已发射攻击保留旧快照，后续攻击使用新效果，没有重复倍率或残留。
- [ ] 脱离所有根、通过第二个根仍连通和成环网络的生效规则符合确认合同，不依赖安装顺序。
- [ ] Talent 来源提供方完成所有权预检与幂等重建；不同时恢复派生效果和来源效果，切图 / 连续 Session 无残留。

扩展已有伤害、属性、状态来源、技能保存、输入与 Session 生命周期覆盖。通过实际按键、行为与最终效果验证，不以源码字符串或字段数量替代测试。

## 五：玩家操作与综合收尾

- [ ] 键鼠可拿起、旋转、放置、取消、取回和查看详情；预览形状、共享端口和失败原因与正式事务一致。
- [ ] 手柄能完成相同路径，焦点跨六空洞与嵌入网络可达；取消 / 关闭恢复焦点及输入上下文，不泄漏拖拽状态。
- [ ] 六槽技能分配与键鼠 `1`–`6` 默认绑定可操作；手柄六槽均可施放，瞄准按最终确认方式执行，HUD 显示实际 Glyph、冷却和空槽状态。
- [ ] 六技能 Action 均可重绑定，冲突、取消、设备拔出与 Settings 提交失败恢复旧绑定；旧设置保留既有覆盖，新槽获得默认绑定。
- [ ] UI 操作、重绑定捕获、失焦 / 挂起和死亡均不穿透施法；按住跨 Context 切换不补发，释放重按后正常响应。旧 `Attack` 不与技能入口重复响应。
- [ ] 键鼠 / 手柄可装备瓶子、查看当前能量 / 容量、中心预览与充能、三属性分配和独立点亮；显示下一天赋点成本、角色余量与两类可用点数。
- [ ] 能量瓶未满时充能可达，取消与失败反馈保留状态；消耗后中心 / 专栏显示更新，力量、敏捷、智力显示真实分配与最终属性。
- [ ] 中文、英文和 Pseudo Locale 的名称、词条、失败原因与范围说明可读，无关键文本裁切；1920×1080 完成常规视觉矩阵。
- [ ] 场景关闭 / Session 取消时释放预览任务、事件与 Addressables 资源；重复打开和连续 Session 不累积监听或资源。
- [ ] 代表性内容覆盖三尺寸柴薪、全局 / 局部天赋、火焰 / 余烬变体及三档能量瓶；完成积蓄 → 充能 → 属性分配 / 点亮 → 六键施法 → 保存 / 继续的闭环，并验证交易归属。
- [ ] 实际受影响定向回归及项目 EditMode / PlayMode 通过；新增 / 受影响测试完成保留、合并或清除审查。
- [ ] 当前模块说明、配置入口、版本域和进度已同步；计划与真实验收材料按 `archive/0.7.1/` 的 `plans/`、`acceptance/` 归档，并创建版本 `README.md`。

使用现有 UI 输入与生命周期测试；一次性截图采集和发布检查脚本验收后清理。只在用户针对当前任务明确要求时执行 Player 构建，未执行项如实记录。
