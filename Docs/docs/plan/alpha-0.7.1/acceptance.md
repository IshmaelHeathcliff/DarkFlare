- [x] 大 19 格、中 7 格、小 3 格三角形的主体占位正确；空节点、中心空位和裂缝延伸格均参与碰撞。

## 二：物品、能量瓶、安装与持久化

实际交付见[阶段二归档计划](../archive/0.7.1/plans/phase-2-execution.md)与[当次验收](../archive/0.7.1/acceptance/items-energy/README.md)。本阶段验收权威道具、安装和积蓄，不提前切换技能运行时；正式迁移与无默认自动施放在阶段四一起验收。

- [x] 大柴薪进初始空洞；中 / 小通过合法裂缝接入，小与小连接可行；跨根连接和环不会产生重复所有者或重复节点。
- [x] 棋盘无固定外边界，距中心超过 16 仍能合法安装；中心保留区和完整占位照常校验，中柴薪中心拒绝任何道具。
- [x] 大 / 中 / 小柴薪、火焰、余烬背包均占 1×1；安装后仍按棋盘完整主体 / 插槽规则，不把背包尺寸当棋盘占位。
- [x] 变体的布局、种子、词条和稳定身份在移动、旋转、交易及保存恢复后不变；火焰、余烬交易复用现有价格与所有权事务。
- [x] 柴薪、火焰、余烬、能量瓶均可由实际怪物掉落和商店库存生成；拾取 / 购买 / 再出售 / 恢复保持合法实例状态，收益结算不额外消耗掉落随机流。
- [x] 安装 / 取回 / 交换成功后背包、棋盘、插槽和连接一致；碰撞、背包不足、类型不符、过期预览失败时零部分变更、零成功事件。
- [x] 先逐件手动取出火焰 / 余烬，再从末端手动断连、逐件拆除柴薪；嵌入物未取出时拒绝，不自动回收网络。拆下后其他柴薪均仍连至少一个初始空洞；验证环 / 跨根经另一根连通可以拆、桥接拆除导致断根失败和最后一件可取回。
- [x] 单件拆卸统一预检背包、拓扑和恢复外伸格，任一失败完整回退；只断线但原位两主体产生外伸冲突的状态不能提交。
- [x] 已连接裂缝拒绝余烬；装有余烬的裂缝拒绝连接，先取出后才能连接；失败不替换或丢弃已有物品。
- [x] 三种能量瓶背包占位均为 2×1，容量暂定小 1000 / 中 2000 / 大 4000；基价按小 100、容量倍率暂列中 200 / 大 400 配置。瓶内能量始终处于容量内，移动 / 换装和保存恢复保留数值与身份。
- [x] 专属栏只接受能量瓶，装备 / 替换 / 卸下原子提交，背包不足完整回退；未装备瓶不自动获得能量。
- [x] 每种怪物使用配置基础能量与实际实例的词条计算收益；固定其他条件增加词条数量、提高怪物整体稀有度或提高词条自身稀有度均增加收益，取整 / 边界 / 溢出符合最终数值合同，不以生成权重代替稀有度。
- [x] 击杀积蓄证明玩家归属，普通攻击 / 持续伤害归属一致；重复死亡、读档重建、场景销毁不重复奖励。只有装备瓶收集，单次收益超过剩余容量时仅填至容量，其余舍弃；空栏 / 满瓶不收集、不转存。
- [x] 满瓶后不自动更换或装备背包瓶，玩家手动换瓶后只获得新击杀收益；旧瓶保留满值，已舍弃能量不补发，换装失败保留原装备与瓶内能量。
- [x] 中心采用原所有者保留物品、中心仅持短暂选择引用的合同，不新增持久化所有者；本项仅验收合同，选择 / 取消 UI 与消费、成长统一留待阶段三。
- [x] 新存档保存权威布局、安装关系和变体；Schema 9 旧档显式初始化棋盘 / 专栏，保留原单技能及剩余冷却，不重复发放起始道具、不在恢复时重生成物品。
- [x] 火焰以稳定实例 ID、技能内容与安装来源供后续六槽查询；阶段二不提前生成第二份六槽权威数据或删除现有技能循环，旧档继续可玩。
- [x] 重复实例、非法占位、内容缺失和拓扑错误在恢复预检失败；运行中的 Session、有效存档和玩家数据不被污染。

扩展已有物品、背包事务、交易和 Save Restore 测试，使用隔离数据根；真实旧档夹具长期保留。新增存档合同进入此阶段时评估 Schema 迁移。

## 三：中心充能、属性分配与点亮

实施顺序与已确认规则见[阶段三实施计划](../archive/0.7.1/plans/phase-3-execution.md)。2026-10-15 用户确认三组建议，本阶段已实现并通过验收；正式玩家操作与手柄矩阵仍在阶段五。

- [x] 未满瓶也能充入全部实际能量，同时消费该实例；瓶子删除、装备 / 中心清空、能量池和点数首次通知时均为一致最终态。
- [x] 剩余能量跨瓶累计，够多点时按逐点递增成本兑换；每 1 天赋点同时发放 1 属性点，分瓶与合瓶的等量能量得到相同兑换结果。
- [x] 花天赋点、换瓶、切图和读档不降低下一点成本；预览和正式提交共用曲线，非法曲线 / 溢出失败不损失能量。
- [x] 取消、重复请求、所有权变化、瓶子在预览后继续积蓄、成长 Revision 变化和提交失败均不部分消费或重复加点；保留外部合法变化。
- [x] 三属性分配分别扣可用属性点，点数不足不修改；仅影响当前玩家，保存恢复 / 属性重建不重复加值或修改共享配置。
- [x] 柴薪与普通天赋分别扣天赋点点亮，点亮柴薪不自动获得全部词条；重复点亮、非法节点 / 上游资格、余额不足失败不扣点。
- [x] 已点亮物品取回 / 转移按确认合同处理，不能复制或遗留效果 / 点数收益；物品身份、激活记录和点数保持一致。
- [x] 点数账目符合已确认的守恒合同；旋转 / 重连 / 跨根后的剩余激活网络合法，过期预览不会静默退款、断激活或丢弃记录。
- [x] 成长余额、累计兑换数、属性分配和激活记录保存恢复一致，旧档初始化不重放充能 / 发点；起始技能与点亮规则不会产生不可战斗软锁。

复用物品使用、装备事务、属性重建与存档测试，新增独立成长规则覆盖；优先用纯逻辑验证递增阈值、余额守恒和点数失败回退，不建立按版本命名的永久套件。

## 四：技能重构、六键施放、天赋与余烬

实施顺序与确认规则见[阶段四计划](phase-4-execution.md)。普通技能独立普攻、六槽仅放火焰且同实例单槽；局部范围走已点亮网络最短路、每边 1 步；瞄准使用指针 / 右摇杆。以下仍是未执行的通过条件。

- [ ] 无技能输入时，进图、遇敌、冷却结束、复活与继续游戏均不施放；六个输入槽能请求对应技能，空槽不调用默认技能。
- [ ] 单次按下最多一次施放；同一火焰重复分配拒绝或原子移槽，不能留下两个绑定；冷却中连按、换槽、取回再装及同帧请求不能绕过冷却 / 法力校验；失败不扣法力、不启动冷却、不排队补发。
- [ ] 装备武器即可获得对应普通技能，无需火焰或点亮；不同武器按各自配置更新技能，卸下时不可用。换装后旧请求不能施放新武器技能，普通技能不串用火焰局部效果。
- [ ] 火焰安装获得技能，取回按确认规则清除 / 禁用绑定；多个火焰的分配、施放和冷却可操作并可恢复，六槽最小 HUD 反映真实状态。
- [ ] 六槽分配与冷却保存类型明确的武器 / 火焰来源；旧单技能 / 自动间隔迁移为当前武器普通技能与剩余冷却，不新增棋盘物品或点数，不恢复自动循环。无武器旧档可在装备后取得普通技能，非空成长账目保持原值。
- [ ] 冷却遵循玩法暂停，重绑定、菜单切换、保存恢复与换槽不重置冷却；请求中来源变化或 Session 取消不能施放另一枚火焰。
- [ ] 全局天赋仅按来源应用一次；局部天赋与余烬在已点亮网络取最短路，每条内部连线 / 裂缝连接算 1 步，未点亮天赋阻断，包含边界。验证天赋自身 / 余烬裂缝起点、跨空格长边只计 1 步、几何近但路径远、无路径、多入口与环 / 跨根。
- [ ] 未点亮普通天赋没有词条效果，点亮后按来源生效；火焰与裂缝资格服从最终柴薪激活规则，六槽绑定不能绕过。
- [ ] 两个同技能定义火焰，只有一个在范围内时效果不串用；标签、伤害转换和已有条件仍沿用现有管线。
- [ ] 旋转、移动、拆卸和重连后目标集合正确；已发射攻击保留旧快照，后续攻击使用新效果，没有重复倍率或残留。
- [ ] 导致剩余网络断根的拆卸失败且保留原效果；通过第二个根仍连通、成环网络与已点亮上游的生效规则符合确认合同，不依赖安装顺序。
- [ ] Talent 来源提供方完成所有权预检与幂等重建；不同时恢复派生效果和来源效果，切图 / 连续 Session 无残留。

扩展已有伤害、属性、状态来源、技能保存、输入与 Session 生命周期覆盖。通过实际按键、行为与最终效果验证，不以源码字符串或字段数量替代测试。
