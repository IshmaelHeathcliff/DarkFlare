# Alpha 0.7.1 技能面板与技能重构执行计划

状态：2026-10-06，**核心几何、六键手动施法、能量瓶与点数成长要求已确认，尚未开始实现**。目标系列为 `0.7.1-alpha`，首次实际交付使用 `0.7.1-alpha.1`。当前运行版本仍为 `0.7.0-alpha.2`；本次规划不推进版本、内容目录或 Schema。

入口：[0.7 总计划](alpha-0.7-plan.md) · [启动基线](alpha-0.7.1-startup.md) · [几何与生成合同](alpha-0.7.1/geometry.md) · [技能重构与六键施放](alpha-0.7.1/manual-skills.md) · [能量瓶与天赋成长](alpha-0.7.1/energy-progression.md) · [阶段验收清单](alpha-0.7.1/acceptance.md)。本计划依据用户规则、五项几何确认、六键手动施法及三项成长澄清整理，不涉及人工管理的游戏设计文档。

## 交付目标

- 技能面板采用六边形棋盘；中心 7 格保留给能量瓶充能位置及力量、敏捷、智力三角排布，六个初始空洞距中心 16 格。
- 空洞安装大柴薪；大柴薪中心安装火焰获得对应技能。大、中、小柴薪可旋转，通过裂缝延伸的连接格接入，最终连接不同空洞；小柴薪可连接小柴薪。
- 柴薪天赋提供全局或范围效果；裂缝也可安装余烬，对范围内火焰提供技能强化。柴薪、火焰、余烬作为有稳定实例身份的道具支持变体和交易。
- 同时完成技能运行时重构：取消默认自动施放，提供 6 个可分配、可重绑定的技能输入槽；默认键鼠拟定为 `1`–`6`，接入手柄、六槽 HUD、技能冷却与旧档迁移，详见[六键施放合同](alpha-0.7.1/manual-skills.md)。
- 增加大 / 中 / 小三种不同容量的能量瓶，背包均占 2×1；专栏装备后积蓄打怪能量，未满也能在棋盘中心整瓶消耗充能。余量跨瓶累计，每兑换 1 天赋点同时得到 1 属性分配点，天赋点能量成本逐点递增。
- 基础属性点分配到力量 / 敏捷 / 智力；柴薪和普通天赋分别花天赋点点亮，放置不自动获得全部词条，详见[成长合同](alpha-0.7.1/energy-progression.md)。
- 完整形状参与碰撞，包括内部空格、中心空位和裂缝延伸格。两件柴薪连接时允许共享一个连接格，其余占位不得重叠。
- 新状态接入现有物品、存档、Session、输入、本地化及效果生命周期；键鼠和手柄都能完成安装、旋转、取回、查看范围、充能、属性分配及点亮。

节点数量、形状、裂缝限制及共享格细则以[几何合同](alpha-0.7.1/geometry.md)为准。等级解锁、洗点 / 重置费用、打造配方和额外交易功能未在本轮指定，不自动加入范围。

## 实现边界

### 几何、配置与数据

- 坐标、旋转、形状、碰撞和生成校验作为不依赖 UI 的规则；棋盘坐标与背包矩形坐标分别建模。
- 配置使用现有 ScriptableObject / Odin 和内容登记；形状、节点、端口、效果范围、变体引用分开表达。字段和验证错误使用中文标注，玩家文本通过 Localization。
- 生成时固定节点布局、裂缝、词条和变体身份；旋转、移动、交易、保存恢复均不能重新掷骰。明确独立随机流及生成合同版本，防止消耗现有战斗 / 掉落随机流。
- 安装状态使用稳定物品与局部节点身份，记录平移、六档旋转和连接；连接可形成环和跨根网络，不能仅用父子树表示权威拓扑。

### 物品与安装事务

- 每个实例同一时刻仅有一个权威所有者。棋盘安装、背包取回、交易与存档必须同时校验身份、目标容量、完整占位、插槽角色和连接合法性。
- 事务先预检最终态再提交，最终态一致后由 Model / System / Command 发事件。碰撞、容量不足、过期预览或无效连接时，物品、连接、效果和事件均不能留下部分变化。
- 裂缝安装柴薪与余烬互斥属于拟定实现合同，须在阶段二前确认共享端口与余烬的关系。取回含火焰 / 余烬或跨根连接的柴薪时，先确定取回策略；不能丢弃嵌入道具或盲目递归删除网络。
- 能量瓶复用物品预检 / 提交与消费模式，瓶内能量随实例保存；专栏、背包与中心间流转保持唯一所有者。充能时将整瓶消费、池内余量、累计获得数和两类点数一起提交，失败不得留下部分成长。详见[成长合同](alpha-0.7.1/energy-progression.md)。

### 能量与点数成长

- 装备的能量瓶承接有效怪物死亡收益，重复通知、旧档恢复和场景销毁不重复奖励；未装备不自动充背包其他瓶，容量与溢出按明确合同处理。
- 角色充能池保留不足下一阈值的余量；兑换每 1 天赋点同时发放 1 属性点，下一点成本拟定由累计已获得数决定。花点、换瓶和读档不能降低兑换序号。
- 柴薪与普通天赋独立点亮并扣天赋点；属性点独立分配到三主属性。激活记录、点数余额和永久分配保存权威身份，派生属性 / 效果只重建一次。

### 技能、效果与生命周期

- 六个输入槽引用已获得的火焰技能实例；技能系统持有权威冷却并校验施放，按键触发一次请求，冷却就绪不自动释放。输入、HUD、技能分配、保存与失败边界统一遵循[六键合同](alpha-0.7.1/manual-skills.md)。
- 全局天赋按来源身份参与现有角色聚合；局部天赋和余烬解析为指定火焰实例的效果集合。移除、旋转和重新连接后重算目标，避免重复应用和残留。
- 效果和技能可用性消费正式激活状态；未点亮的普通天赋不提供词条，点亮柴薪不代替周边天赋花点，绑定技能槽不能绕过激活资格。
- 同一技能定义的两枚火焰仍为独立实例。标签条件沿用现有管线，范围判定与条件判定分别处理；已发出的攻击继续使用原快照，后续攻击采用新面板结果。
- Talent 来源效果通过正式来源提供方证明和重建，恢复时不依赖 UI。内容缺失、重复实例、非法占位及非法拓扑在 Restore 预检阶段失败，不能污染正在运行的 Session。
- QFramework Model 持有权威状态，System 计算事务与效果，Controller 通过 Command / Query / Event 接入。异步预览与 Addressables 句柄绑定 Scene / Session 取消和资源所有者；不由 Controller 直接修改 Model 或发送事件。

## 待明确项与进入条件

这些事项未由本轮规则明确，不能在代码中默认为已获确认；实施对应阶段前解决，已确认几何的独立工作可先推进。

| 进入阶段 | 待明确事项 | 拟定处理 |
| --- | --- | --- |
| 一 | 中 / 小柴薪的端口外伸方向；天赋连线是否受相邻格约束；面板是否有固定边界 | 大柴薪角端口沿径向外伸；其余外伸方向随模板记录。先用无固定外边界的坐标规则与可平移视口，保留显式边界校验入口。拟定方案不等同于规则确认。 |
| 二 | 共享格是否仅限双方延伸端点、单格能否多于两件共享、已连接裂缝能否再放余烬 | 建议限双方延伸端点、每格两件、接入柴薪后不能再装余烬；必须明确后再开放安装。 |
| 二 | 取回嵌入物 / 跨根连接的柴薪；中心能量瓶归属；中柴薪中心能否放火焰 | 制定保持物品身份和网络完整的原子事务；仅大柴薪中心安装火焰已明确，能量瓶中心放置不改变背包 2×1 规格。 |
| 二 | 三种瓶容量、怪物 / Boss 收益、满瓶溢出、获得途径与专栏交换规则 | 数值通过配置表达，未装备 / 满瓶不能静默转存其他瓶或角色池；三档均占 2×1。 |
| 三 | 递增成本曲线、每次点亮成本、零能量瓶、取回已点亮柴薪后的点数处理 | 余量跨瓶累计和每 1 天赋点配 1 属性点已确认；建议累计获得数控制后续成本，空瓶拒绝无变化，洗点费用不自动加入。 |
| 三 | 柴薪点亮与中心火焰 / 裂缝 / 下游资格、未连接或脱离初始空洞网络生效规则 | 柴薪和普通天赋分别花点已确认；补齐连线与激活条件，不能假定装入即全部生效，核对起始技能兼容方案避免软锁。 |
| 四 | 距离按几何还是天赋路径、范围边界、余烬起点；瞄准、重复槽位和实例冷却 | 范围建议几何距离、包含边界、裂缝节点为起点；六键手动触发已确认，瞄准待确认，拟定按火焰实例计冷却且换槽不重置。 |
| 五 | 三属性的中心 7 格映射、能量瓶充能输入与其他消耗品兼容 | 三属性统一为力量 / 敏捷 / 智力；智力复用 `intelligence`，不新增重复属性。 |
