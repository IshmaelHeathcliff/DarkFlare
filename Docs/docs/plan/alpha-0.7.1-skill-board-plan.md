## 交付目标

- 技能面板采用六边形棋盘；中心 7 格保留给能量瓶充能位置及力量、敏捷、智力三角排布，六个初始空洞距中心 16 格。
- 空洞安装大柴薪；大柴薪中心安装火焰获得对应技能。大、中、小柴薪可旋转，通过裂缝延伸的连接格接入，最终连接不同空洞；小柴薪可连接小柴薪。
- 棋盘无固定外边界；中柴薪中心始终留白，暂不能安装道具。拆卸先手动取出火焰 / 余烬，再从末端手动断连、逐件拆除；拆后其余柴薪仍须连至少一个初始空洞。柴薪、火焰、余烬背包均占 1×1，棋盘主体占位保持几何合同。
- 柴薪天赋提供全局或范围效果；裂缝也可安装余烬，对范围内火焰提供技能强化。柴薪、火焰、余烬作为有稳定实例身份的道具支持变体和交易；这三类及能量瓶均可怪物掉落与商店购买。
- 同时完成技能运行时重构：取消默认自动施放，提供 6 个可分配、可重绑定的技能输入槽；默认键鼠拟定为 `1`–`6`，接入手柄、六槽 HUD、技能冷却与旧档迁移，详见[六键施放合同](alpha-0.7.1/manual-skills.md)。
- 增加小 / 中 / 大能量瓶，容量暂定 1000 / 2000 / 4000，背包均占 2×1；小瓶基价暂定 100，按容量倍率暂列中 200 / 大 400。仅专栏装备后积蓄打怪能量，满瓶停止收集，未满也能在棋盘中心整瓶消耗充能。余量跨瓶累计，每兑换 1 天赋点同时得到 1 属性分配点，天赋点能量成本逐点递增。
- 基础属性点分配到力量 / 敏捷 / 智力；柴薪和普通天赋分别花天赋点点亮，放置不自动获得全部词条，详见[成长合同](alpha-0.7.1/energy-progression.md)。
- 完整形状参与碰撞，包括内部空格、中心空位和未连接裂缝的延伸格。最新连接规则为外伸端点直接落到另一件柴薪裂缝点，连接后没有额外外伸格；固定主体之间不得重叠。
- 新状态接入现有物品、存档、Session、输入、本地化及效果生命周期；键鼠和手柄都能完成安装、旋转、取回、查看范围、充能、属性分配及点亮。

节点数量、形状、裂缝限制及直接连接细则以[几何合同](alpha-0.7.1/geometry.md)为准。等级解锁、洗点 / 重置费用、打造配方和额外交易功能未在本轮指定，不自动加入范围。

## 实现边界

### 几何、配置与数据

- 坐标、旋转、形状、碰撞和生成校验作为不依赖 UI 的规则；棋盘坐标与背包矩形坐标分别建模。
- 配置使用现有 ScriptableObject / Odin 和内容登记；形状、节点、端口、效果范围、变体引用分开表达。字段和验证错误使用中文标注，玩家文本通过 Localization。
- 生成时固定节点布局、裂缝、词条和变体身份；旋转、移动、交易、保存恢复均不能重新掷骰。明确独立随机流及生成合同版本，防止消耗现有战斗 / 掉落随机流。
- 安装状态使用稳定物品与局部节点身份，记录平移、六档旋转和连接；连接可形成环和跨根网络，不能仅用父子树表示权威拓扑。

### 物品与安装事务

- 每个实例同一时刻仅有一个权威所有者。棋盘安装、背包取回、交易与存档必须同时校验身份、目标容量、完整占位、插槽角色和连接合法性。
- 事务先预检最终态再提交，最终态一致后由 Model / System / Command 发事件。碰撞、容量不足、过期预览或无效连接时，物品、连接、效果和事件均不能留下部分变化。
- 用户已确认裂缝连接柴薪与安装余烬互斥。拆卸前先逐件手动取出火焰 / 余烬，再手动断连、逐件拆除柴薪；末端按拆后其他柴薪仍连至少一个初始空洞判断，环 / 跨根采用同一判定，不自动递归回收网络。
- 能量瓶复用物品预检 / 提交与消费模式，瓶内能量随实例保存；专栏、背包与中心间流转保持唯一所有者。充能时将整瓶消费、池内余量、累计获得数和两类点数一起提交，失败不得留下部分成长。详见[成长合同](alpha-0.7.1/energy-progression.md)。

### 能量与点数成长

- 每种怪物配置基础能量，结合实际词条数量、怪物整体稀有度与词条自身稀有度提高收益；装备瓶承接有效怪物死亡收益，超出剩余容量直接舍弃，满瓶后必须手动更换。未装备 / 满瓶不转存背包瓶或角色池，重复通知、旧档恢复和场景销毁不重复奖励。
- 角色充能池保留不足下一阈值的余量；兑换每 1 天赋点同时发放 1 属性点，下一点成本拟定由累计已获得数决定。花点、换瓶和读档不能降低兑换序号。
- 柴薪与普通天赋独立点亮并扣天赋点；属性点独立分配到三主属性。激活记录、点数余额和永久分配保存权威身份，派生属性 / 效果只重建一次。

### 技能、效果与生命周期

- 六个输入槽引用已获得的火焰技能实例；技能系统持有权威冷却并校验施放，按键触发一次请求，冷却就绪不自动释放。输入、HUD、技能分配、保存与失败边界统一遵循[六键合同](alpha-0.7.1/manual-skills.md)。
- 全局天赋按来源身份参与现有角色聚合；局部天赋和余烬解析为指定火焰实例的效果集合。移除、旋转和重新连接后重算目标，避免重复应用和残留。
- 效果和技能可用性消费正式激活状态；未点亮的普通天赋不提供词条，点亮柴薪不代替周边天赋花点，绑定技能槽不能绕过激活资格。
- 同一技能定义的两枚火焰仍为独立实例。标签条件沿用现有管线，范围判定与条件判定分别处理；已发出的攻击继续使用原快照，后续攻击采用新面板结果。
- Talent 来源效果通过正式来源提供方证明和重建，恢复时不依赖 UI。内容缺失、重复实例、非法占位及非法拓扑在 Restore 预检阶段失败，不能污染正在运行的 Session。
- QFramework Model 持有权威状态，System 计算事务与效果，Controller 通过 Command / Query / Event 接入。异步预览与 Addressables 句柄绑定 Scene / Session 取消和资源所有者；不由 Controller 直接修改 Model 或发送事件。
