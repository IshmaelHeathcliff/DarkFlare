# Alpha 0.6：行为管理、Boss 与有限刷怪

状态：2026-09-22，**实施中，0.6.0 行为基础与 0.6.1 普通怪物完成**，下一阶段 0.6.2 守卫 Boss。当前交付 `0.6.1-alpha` / core v7 / Schema 6 / 地图 V2，见[验收](../behavior/acceptance/0.6.1/README.md)。启动依据见[启动记录](archive/alpha-0.6-startup.md)。

## 已确认目标

- 轻量 HFSM 与行为树，可复用于怪物、Boss、NPC；运行时可视化调试，与 Animator 桥接且解耦。
- HFSM 与行为树作为两个独立核心模块，统一放入现有 `DarkFlare.Core` 程序集；各自可单独使用，不相互依赖，不另建行为核心程序集。玩法接入、Animator 桥接及可视化在核心之外实现。
- 普通怪物：玩家不在激活范围时静止；进入激活范围但未进入视野时小范围闲逛；发现玩家后导航追逐；攻击范围内发动攻击。
- 交付守卫型 Boss：近距离挥击、带预警的冲锋、低血量强化阶段，独立刷新点。
- 刷怪地图具有固定怪物总量；部分入图生成，其余按玩家接近触发生成，完善配置与实现。
- 离开地图保留状态，返回继续；玩家可以手动重置刷怪地图，重置后刷新。正常切图和继续游戏不自动重置。

## 实现依据与职责

- `MonsterController` 保存怪物身份、冻结冷却与行为 DTO；MapScope 统一驱动行为和导航。普通怪物已由行为系统接管攻击，导航直接接触攻击入口已移除。
- `MonsterSpawner` 当前按间隔补充到 `MaxAliveCount`；有限刷怪需独立记录名额、预生成 / 待触发 / 已生成 / 已消耗状态，不用当前存活数替代总量。
- `MapScope`、`WorldMapRuntime` 与 `SessionSnapshotSource` 已管理地图冻结、导航意图和保存；新行为与刷怪状态必须进入同一事务及校验链，失败切图不得消耗名额或复制 Boss。
- `ActorAnimatorController` 已消费战斗事件和速度；行为核心不读取 Animator 状态，不以 AnimationEvent 作为唯一伤害 / 完成条件。

HFSM 管理生命周期和高层模式，行为树编排复合行为；二者既能组合也能单独使用。核心分别位于 `Assets/Scripts/Runtime/Core/HFSM/` 与 `Assets/Scripts/Runtime/Core/BehaviorTree/`，由已有 `DarkFlare.Core.asmdef` 管理。组合适配位于 Runtime，核心无 Runtime / Editor 反向依赖。纯 C# 核心显式 Tick，采用实例隔离上下文与取消 / Abort 合同。场景适配通过 QFramework Command / Query / Event、现有导航及战斗系统工作。避免每个节点独立 Update / 协程或字符串黑板热路径。

行为系统与导航系统由地图作用域的共同调度入口按次序驱动，导航不得承担行为决策。保持唯一速度提交者；Boss 冲锋也必须经过同源碰撞与行动许可，不绕开导航安全检查直接写 Transform。现有 QFramework 没有查到可直接复用的 HFSM / 行为树实现；实施时先复核依赖，优先薄适配，避免引入超出需求的大型框架。

## 版本、性能与交付门禁

- 0.6.1 已交付 core v7 / Schema 6；后续 Boss 与刷怪配置按新增合同继续评估内容及存档版本，不提前修改。地图布局新增触发批次 / Boss 点时评估 V3，若能无损扩展既有对象 / 区域合同则避免重复数据源。
- 延续 Alpha 0.5 Player 基线机器与测量条件；按用户最新要求调整 Alpha 0.6 的目标规模：300 常规单位总帧 P95 ≤16.7ms，600 压力单位 ≤33.3ms，导航预算分别 2 / 3ms。行为调度、感知、树执行、动画桥接分别记录成本。0.6.1 已完成更高的 500 / 1000 单位实测，保留原始证据。
- 增补全部休眠、集中唤醒、300 / 600 追逐、密集闲逛、攻击中断、Boss 与怪群同场、连续触发及重置。不能用大量休眠单位代替活动怪物压力验收。
- 预热 10 秒、采样 60 秒、三轮；分别测关闭 / 开启调试窗口。默认关闭调试时纯核心稳态目标零分配；转移、攻击、可视化采样和保存分别统计，不把导航零分配外推到整场游戏。
- 至少 20 轮切图 / 手动重置验证注册、任务、资源 lease、图实例和原生容量收敛。大型保存 / 恢复耗时及内存沿用 I 的独立记录方式。
- 所有新旧存档测试使用隔离目录，保留真实迁移夹具；测试覆盖行为和事务，不新增按版本命名的永久成功记录检查。
