# Alpha 0.7 执行计划

状态：2026-09-30，**0.7.0 已完成，0.7.1 启动基线已核对**，当前运行版本为 `0.7.0-alpha.2`。首项简易 SemVer 版本对象及应用接入完成，执行合同和当次验收见[0.7.0 归档](archive/0.7.0/plans/alpha-0.7.0-semver-plan.md)，日常 API 见[版本管理](../version-management.md)。0.7 里程碑继续保持 alpha；[0.7.1 启动准备](alpha-0.7.1-startup.md)记录当前基线，功能范围待明确。

## 基线与顺序

- 0.7 启动基线：`751225c`、`0.6.5-alpha`，见[启动记录](archive/0.7/plans/alpha-0.7-startup.md)。
- 当前交付：`0.7.0-alpha.2`；core v10、存档 Schema 9、设置 Schema 1、地图格式 V4 保持不变。
- 0.7.1 准备基线：`main` / `e2b97d2`；0.7.0 验收记录中的 6 个文件哈希与当前文件全部匹配，本次未重跑测试，见[启动核对](alpha-0.7.1-startup.md)。
- 后续按 `0.7.1-alpha`、`0.7.2-alpha` 推进；阶段使用各自的 `alpha.1`、`alpha.2` 等完整版本。
- 下一里程碑仍处于 alpha 时进入 `0.8.0-alpha`，明确进入 beta 时进入 `0.8.0-beta`。
- 阶段号只在实现与相关验证完成后推进；小版本收尾保留最终阶段号，不退回无阶段号的 `alpha`。
