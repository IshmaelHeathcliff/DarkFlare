# Alpha 0.5：地图创建、地图数据与动态寻路

状态：2026-09-17 总计划已建立，尚未开始实现。当前运行版本 `0.4.2-alpha`，core v5、Schema 3；版本号只在对应阶段完成验收后更新。

## 目标与已确认范围

用同一份地图数据驱动手工 / AI 编辑、Dual Grid + Wang Tile 地表、障碍物与装饰、交互和区域、世界排序及导航。交付可往返的城镇与野外：城镇支持交易 / 打造，野外支持怪物生成、绕障追逐及现有战斗掉落循环。

用户已明确：

- 至少泥土、草地、水、道路四类地表，各自支持变体。
- 地图数据包含地表、障碍物、装饰物、交互点、区域；编辑器可手绘、方便导入导出、支持 AI 自动编辑。
- 完善所有对象层级，世界遮挡基本依据接地点 Y 排序。
- 寻路采用 Grid Navigation + Flow Field + Spatial Hash + Separation，使用 Job / Burst 优化并应用于怪物。
- 正式性能验收规模为 **500 个活动怪物**，**1000 个压力测试**。
- 切图保留地图状态，离开期间暂停模拟，返回后继续。

首期工程建议：四种地表为互斥语义；泥土 / 草地 / 道路可行走、水不可步行，道路默认不额外加速。保留通行配置扩展点，本版不追加游泳、飞行、桥梁或多高度寻路。这些是计划默认值，并非已确认的平衡规则。

## 已核对的实现与差距

路径相对 `Assets/Scripts/`。此表是本轮定向阅读结论，不代表全仓代码审计或新测试结果。

| 现有实现 | 本版处理 |
| --- | --- |
| `Editor/GroundTilemapSetup.cs`、[地表模块](../ground-tilemap.md)：5×5、8 单位大地砖，只承担视觉 | 替换为数据编译出的 Dual Grid 地表，新增四材质及导航语义；旧资源待消费者迁完再清理 |
| `Runtime/Gameplay/Visuals/WorldSortingSystem.cs` 已有接地点 Y、类别、稳定 ID 排序 | 扩展覆盖地图对象和实体特效，保留稳定规则，评估大量动态对象排序开销 |
| `Runtime/Gameplay/Actors/MonsterController.cs` 每只 FixedUpdate 直线追逐并遍历全部怪物分离 | 集中采样与 Job 计算，替换全量邻居遍历，行为命令仍走现有战斗系统 |
| `Runtime/Gameplay/Spawning/MonsterSpawner.cs`、`Bootstrap/CameraFollowTarget.cs` 只看矩形 Bounds | 出生采样改用区域 + 导航净空，镜头使用地图范围，障碍几何来自同一地图源 |
| `GameplaySceneConfiguration` 强制同时存在刷怪器、商人和打造配置 | 拆出地图能力配置，使城镇可不刷怪、野外可没有商人和打造台 |
| Scene Flow 只支持 FrontEnd 与单 Main / Session 进出 | 在现有仲裁中增加 ChangeMap，保持 Session 与玩家连续性，不另建场景加载入口 |
| `Persistence/SaveDtos.cs` 无 MapId，怪物上限 512、文档上限 16 MiB；状态容量还依赖怪物上限 | 增加活动地图与分地图快照，统一审核数量 / 字节 / 状态层预算与迁移 |
| [状态生命周期](../status-lifecycle-ui.md)共用 Session 时钟 | 离场地图导出冻结快照，恢复时重定位时间；不能只隐藏 GameObject 让状态继续计时 |

`Packages/packages-lock.json` 已解析 Burst `2.0.0`、Collections `6.6.0`、Mathematics `1.4.0`，均为间接依赖。导航阶段将实际使用的包声明为直接依赖并核对本机包 API，不在规划阶段升级包。已安装 AI Navigation 不改变用户指定的网格 / 流场路线；本版不要求全工程迁入 Entities。

## 总体成功标准

1. 手绘与 AI 都能从空地图生成四种地表及五类数据，导出后重导入保持稳定 ID、变体和布局；渲染、碰撞、导航不需要各维护一份地图。
2. 城镇可交易 / 打造，野外可刷怪、寻路、战斗、掉落；切图不重发物品、不刷新库存、不清空野外、不补算离场时间。
3. 动态单位、交互对象和高大装饰的遮挡遵循接地点；特殊层用途明确，没有随意固定 Order 破坏世界遮挡。
4. 500 活动怪物追逐移动目标时满足[性能预算](./alpha-0.5/navigation.md#性能预算与测量)，1000 压力场景无异常、越界或无法恢复的卡死；不可用 Editor 的一帧耗时替代 Player 测量。
5. 网格修订、切图、取消、死亡 / 禁用、旧 Session 回调、保存失败均有明确结果；历史物品、状态与玩家数据隔离回归仍受保护。

本版暂不包含无限世界流式加载、完整程序化地牢、多人同步、编队 / 严格无碰撞多智能体规划、地图内完整建筑经营或玩家运行时地图编辑器。AI 自动编辑指可校验的数据与命令接口，不要求在游戏内接入在线模型服务。
