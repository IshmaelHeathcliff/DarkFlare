# 0.7.2-alpha 体验优化计划

状态：2026-10-25，范围与实施顺序已整理，尚未实施。当前运行版本仍为 `0.7.1-alpha.5`；`0.7.2-alpha` 表示本轮计划系列，阶段通过验收后再更新运行版本。

## 目标与资料入口

在已有玩法闭环上，减少界面遮挡和重复操作，提高持续施法与野外战斗的流畅度。本轮覆盖用户提出的七项改进，不扩展新的成长系统、装备规则或无限刷怪模式。

- [界面优化分计划](alpha-0.7.2/ui-optimization.md)：HUD、天赋棋盘、能量瓶装备入口。
- [战斗与地图分计划](alpha-0.7.2/combat-map-optimization.md)：按住连放、三投射物与穿透、地图缩小、300 名额。
- [0.7 活动总计划](alpha-0.7-plan.md)、[版本规则](../version-management.md)、[测试维护规范](../testing/test-maintenance.md)。

仅阅读 `Docs/docs/` 开发文档和相关实现；未读取 `Docs/design/`。本轮交付为优化计划，不包含功能实现、美术生成或 Unity 验收。

## 已确定的解释与可调参数

2026-10-25 用户确认：

- 棋盘以三属性最终位置为准，允许调整角度与显示映射，原“顺时针 15°”不作为必须锁定的角度。只调整显示，保留逻辑格坐标和已保存安装身份。
- 300 指每个新建或手动重置的野外实例；普通返回保留进度，不因重新进入或继续游戏补满。

实施起点采用以下候选，均需通过对应阶段的布局或实战验证后定稿，不是已经交付的数值：

- 地图先以城镇 32×32、野外 64×64 为候选；格宽、角色、怪物和移动速度保持原尺度，通过重排地形与对象缩短路线，不缩放世界根节点。
- HUD 技能槽先以 48–56 px、窗口入口图形 24–28 px / 点击区域 36–40 px 为候选，优先复用现有材质。
- 默认技能按当前新角色大剑普通技能 `skill:great_sword_normal` 落地；三枚先试 `-10° / 0° / +10°`。通用配置默认仍为单枚、零穿透，战斧、火焰和怪物技能不随通用机制自动增强。
- 多技能同时按住时各槽保持独立冷却；同一时刻满足条件时使用稳定的请求顺序，逐次复核法力，不另增全局冷却。

## 共用实施约束

- 沿用 QFramework 的 Query / Command / Event 分工；Controller 不发送领域 Event，不直接改领域状态。新的循环任务使用可取消 UniTask，归属现有 Session / Scene 生命周期。
- 输入仍由 Application 服务统一管理；资源沿用 Addressables；动效使用 PrimeTween；新增界面文本使用 Localization。
- 运行时 UI 延续 UI Toolkit；实际 UI 创建、布局与验证使用 Unity MCP。地图修改优先调用既有 `MapEditApi` 事务，不直接修改 Editor 已打开的场景文件。
- 新图标遵守[美术资产规范](../visual-asset-generation.md)：生成前确定家族尺寸，一张 PNG 一个生产 Sprite，自动检查与导入。复用可用资产，确需生成时使用 ImageGen 及相应资产工作流。
- 地图缩小必须先定义并验证旧档兼容；不能只改 Revision、静默删除越界对象或借升级清空地图。具体前置见战斗与地图分计划。
- 版本域按实际变化分别评估：纯界面迁移和显示旋转不改 Save Schema；技能配置语义 / 地图内容变化评估 core 与地图 Revision；DTO 或格式变化才改对应 Schema / FormatVersion。

## 验证与收尾

1. 各阶段先扩充现有模块测试，优先验证实际行为和失败回退，不创建按 0.7.2 命名的永久套件，也不锁死候选像素尺寸或一次性版本号。
2. UI 使用 1920×1080 × 中文 / 英文 / 伪本地化，覆盖鼠标、键盘和模拟手柄；截图记录当前画面，不能仅用控件数量证明“精简”。
3. 地图收尾测量进图、触发生成、持续战斗、切图与保存耗时 / 帧时间 / 分配；区分 300 总名额和实际同时存活数，不借用历史大规模测试宣称本版性能通过。
4. 收尾运行受影响的定向回归及项目两个程序集的 EditMode / PlayMode 综合回归，记录源码、运行版本、Unity 版本、实际结果与未执行项。恢复 Reload Scene Only 基线，清理临时采集代码。
5. 本轮没有 Player 验收请求，默认只安排 Editor 验证；构建、真实设备和跨进程结论分别记录，不虚报。
6. 每阶段同步相应模块文档；整个小版本完成后，将计划和证据归档到 `Docs/docs/plan/archive/0.7.2/` 的 `plans/`、`acceptance/`，补齐版本 `README.md`，保留 0.7 活动总计划。

完成标准：七项优化全部达到各自行为与界面标准，旧数据兼容有明确结果，相关回归通过，文档与实际交付一致。
