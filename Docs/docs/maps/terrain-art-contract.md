# 地表材质家族合同

家族 `terrain-basic-v1`，2026-09-18 C1 合同修订 2，在第二次生成前冻结。第一次要求 1024×1024，但内置生成器实际输出 1254×1254，画布审计拒绝；依据已验证的工具能力，整个家族统一采用原生 1254，不对单张图做补救缩放。范围是泥土、草地、水、道路的独立材质源；C1 生产 `terrain_dirt_source_00.png` Pilot，C3 扩展四材质双变体。实现顺序见 [C 计划](../plan/archive/alpha-0.5.0-terrain-art-plan.md)。

## 参考与尺度

风格参考为已交付 `Assets/Art/Sprites/Environment/GroundTiles/Base/ground_base_stone_00.png`：暗色奇幻、冷暗背景、受控高光。只继承光照 / 饱和度 / 画面层级；泥土源必须去除石板结构，不把旧 8 单位地砖缩成 1 单位。

角色 / 镜头只读测量见 [scale.json](./acceptance/c1/scale.json)：半径分别为玩家 0.32、普通 / 重装 0.30、迅捷 0.36；Main 正交 size=5，在 1080 高下为 108 屏幕像素 / 世界单位。逻辑 / 显示格采用 1 单位，编译输出 64 px / 单位，与现有角色 PPU64 接近；屏幕采样非整数的问题沿用当前镜头合同，C1 不引入 Pixel Perfect Camera。

0.75 / 1 / 1.5 / 2 单位直通道对最大半径的单侧剩余净空为 0.015 / 0.14 / 0.39 / 0.64。0.75 太接近擦边，不作为首期主通道目标；本轮用 1、1.5、2 单位对照。导航子格与拐角扫掠留待 D，不仅凭这些数值宣称可达。

## 材质源合同

| 项目 | 固定值 |
| --- | --- |
| 生成 / 保存画布 | 1254×1254，不裁切、不缩放源 PNG；一图一种材质 |
| 目标路径 | `Assets/Art/Sprites/Environment/TerrainSources/terrain_{dirt,grass,water,road}_source_{00,01}.png` |
| 画面密度 | 用约 64×64 的粗像素材质语言构图；全图均匀，纹理连续，无主物件、边框、中心聚光、渐晕或 UI |
| 覆盖与中心 | 全不透明，Alpha 覆盖率 1，包围盒 1254×1254，四边留白 0；Alpha 加权中心 (627,627)，容差 0.5 px |
| 泥土 | 压实、细碎块面与少量浅裂纹；低饱和灰褐，局部冷灰高光；无石板、草叶、水或道路图案 |
| 草地 | 低饱和灰橄榄色短草，粗像素簇均匀分布，无花、灌木、露珠或高光草尖 |
| 水 | 冷暗蓝灰，少量短而平缓的破碎涟漪；无岸、泡沫、物体倒影、天空或亮白高光 |
| 道路 | 比泥土略灰的压实细砾路面，稀疏断续车辙；不画道路轮廓、石板、路肩或标线 |
| 第二变体 | 同材质、尺度、明度与光照，仅改变内部块面 / 纹理分布；始终引用批准泥土 Pilot，可附对应基准图，编译时继承基准边带 |
| 变体明度一致性（C3） | 同材质两源的平均 sRGB 亮度差 ≤0.015；同时观察混用后的明暗方块，数值通过不能替代平铺复核 |
| 色彩层级 | 平均 sRGB 感知亮度 0.10–0.28（0.2126R+0.7152G+0.0722B），95 百分位 ≤0.40；保持角色优先；数值只是背景层级护栏 |
| 光照 / 朝向 | 平面正俯视材质，微弱左上冷光，无投影立体物件，不旋转变体来改变共享边 |
| 源图导入 | Single、FullRect、PPU1254、Center、Point、None、无 mipmap、sRGB、Clamp、Alpha Is Transparency=true、maxTextureSize2048（实际纹理保持 1254，不做 NPOT 缩放）；共用 `Assets/Settings/TerrainSourceImport.preset` |
| 源图预览 | Sprite 完整 1×1 单位，Transform=(1,1,1)；后续运行时地图消费编译 Tile，不直接加载源图 |

源图是 C2 编译输入，允许边缘原始纹理不逐像素周期一致；这不豁免生产 Tile 的接缝要求。Pilot 通过只表示材质与尺度接受，生产平铺必须在 C2 验证；源图不加入运行时 core 或独立 Addressables 条目。

## 编译输出合同（C2 已实现）

固定全画布 32/627 等比采样到 64×64；采用统一面积采样，不按各图包围盒计算。与 B 共用 64 采样位置和整数分区，生成单 PNG / 单 Sprite；PPU64、Center、FullRect、Point、None、无 mipmap、sRGB、Clamp，单位 Transform。

周期化只属于显式编译过程：边界采样带宽 2 px，过渡到内部的带宽 8 px；同一材质的第二变体继承 Pilot 的固定边带。水平 / 垂直对边、兼容 Wang Key 共享边 RGBA 差值必须为 0；四角分区归属不变。编译摘要包括源 Hash、采样与边带算法修订、分区修订和变体身份。纹理质量若不合格应重新生成源，不能用周期化掩盖不合格的源风格。

正式过渡资产和完整材质配置在 C2/C3 绑定，不在布局 `.dfmap` 写 PNG 路径或 Unity GUID。C 完成前不将缺失材质悄悄换成诊断色，也不升级运行版本。
