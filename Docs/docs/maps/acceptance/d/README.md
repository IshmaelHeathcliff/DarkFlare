# D：同源碰撞与静态几何验收

日期：2026-09-18；Unity 6000.6.0f1，AMD Ryzen 7 PRO 8845HS。当前模块合同见[地图几何](../../map-geometry.md)。这里记录 Editor / 隔离 Physics2D 与 PlayMode 验证，不替代 500 / 1000 怪物的独立 Player 导航验收。

## 尺度与物理

[scale.json](./scale.json) 包含 288 组细分 / 宽度 / 平移 / 半径组合：2、4、8 细分；0.59、0.61、0.71、0.73、0.75、1、1.5、2 宽直道；0、0.0625、0.125、0.1875 偏移；0.30、0.32、0.36 半径。默认冻结 **4×4**，物理余量 **0.0125**。

- 半径 0.36 的 1 单位直道：4×4 在四种偏移均可通过；2×2 在其中两种偏移漏掉通道。
- 0.75 直道：连续几何可通过，4×4 只在本轮 offset=0.125 时有合法列；8×8 也未消除所有离散误拒绝。没有缩小角色半径或将零宽鞍点当通路。
- 40 条获准通道的真实 CircleCast 对照，误放行 0。

首次扩展采样发现默认 0.005 余量下，正式几何 / 半格边界样例分别存在 1 / 4 个“纯查询可用但物理 OverlapCircle 命中”的落点，原始诊断见 [skin-investigation.json](./skin-investigation.json)。最近边界实测有约 0.01 世界单位的 Polygon 形状扩展，因此提高到 0.0125，并添加长期稠密点阵回归；该文件为修复前证据，不代表当前通过结果。

[integration.json](./integration.json) 是修复后的结果：两个样例各取固定种子 2,000 组候选，获准点 1,498 / 896、获准线段 1,384 / 736；OverlapCircle 与 CircleCast 误放行均为 0。第二张图为 origin=(-13.25,7.5)、cellSize=0.5 的跨 chunk / 负坐标样例。未声称穷举连续空间。

长期测试另覆盖全部 256 Key 的分区归属、端点合法但中间薄墙阻挡、斜边正交约束、旋转 footprint、Safe / Spawn、签名失效、预算与取消、孔洞 / 重叠合并、约 10,000 个水岸 / 边界点阵检查，以及大 origin 投影拒绝。PlayMode 中真实 Rigidbody2D 圆形角色分别向水岸和边界移动，重复两轮投影后场景根对象归零。

## 往返与事务

正式样例 `terrain_geometry.dfmap` 含四材质、U 形障碍与刷怪 / 安全区。规范导出后作为临时 `.dfmap` 导入，SourceHash 与 GeometryHash 均保持一致；临时源及 meta 已删除。原始地表截图见 [1920×1080](./geometry-terrain-1920.png)，它仅记录地表渲染；[几何窗口截图](./geometry-window.png)显示 U 形阻挡及半径 0.36 的可走节点，足迹净空在障碍两侧正确内缩。截图直接采集 Editor GUIView，未更改地图外观。

在新帧已开始填充 Polygon 路径时取消：旧帧完整保留并标记过期，新投影销毁；随后 Dispose，等待 100ms 后无迟到发布。最近取消约 0.17ms、释放约 0.62ms，仅为单次工具测量。内容校验 0 项问题。

## 容量与构建性能

[performance.json](./performance.json) 使用重复水域 / 道路 / 草地区域，每个尺寸三轮。纯编译计入线程切换，投影计入分批让出与最终同步轮廓合并；无 Deep Profile。`ArrayBytes` 为核心常驻数组，memorySamples 为整个 Editor 的阶段采样，不能当作精确峰值或该模块全部内存。

| 逻辑尺寸 | 导航节点 | 合并矩形 | 物理路径 / 顶点 | 核心数组 |
| --- | --- | --- | --- | --- |
| 64² | 65,536 | 300 | 4 / 568 | 164,868 B |
| 128² | 262,144 | 1,216 | 12 / 2,280 | 660,324 B |
| 256² | 1,048,576 | 4,944 | 52 / 9,256 | 2,645,124 B |

最终三轮纯编译范围分别为 83.5–110.3 / 136.7–141.2 / 375.4–394.5ms；完整投影为 6.1–10.4 / 14.1–40.2 / 47.8–49.3ms。早一轮曾观测到 256² 投影约 1.9 秒，因此分批让出的 Editor 墙钟时间不能作为稳定物理成本；最终数据记录在 JSON，不作为固定单元测试阈值。三种尺寸前后预览场景数量回到同一基线。

[capacity.json](./capacity.json) 记录沿用 C4 的逐格随机四材质 256² 地图：在 262,144 个合并前矩形上限处完整拒绝。该极端源的地表预览仍可用，当前几何后端未通过它的完整构建；后续需要支持这类高频噪声布局时，应改进压缩 / 分块投影，不提高内存上限后宣称优化完成。
