# 紧凑地图与历史实例兼容

0.7.2-alpha.5 将城镇改为32×32、野外64×64，格宽仍为1，角色、怪物、碰撞和移速不缩放。正式地图当前修订为城镇r3、野外r11，core15；Save12 / Settings1 / 地图V4保持。普通返回保留进度，明确重置才创建新代次。

## 迁移输入

`Assets/Data/Maps/History/town-r1.json` 与 `wilderness-r9.json` 是改图前的真实源文件。导入器通过源依赖将旧JSON嵌入正式MapDefinition，一起由现有内容目录 / Addressables资源持有；运行时不读取磁盘或Docs，不重复登记MapId。

WorldMapCatalog校验已发布的编译语义Hash，野外r1 / r4 / r7仍从真实128×128旧r9接续。r7的12个原名额先按原算法扩到100，保留原12个种子和进度，再迁移空间。早期无修订的LegacyPreserved野外及无怪城镇沿原布局迁移；早期缺失独立MapRandom时复制原有Run.Random，不推进随机序列。

## 计划与空间

新建、从未访问及明确重置的野外使用300个普通名额：50入图，十区各25，Boss独立。已访问旧实例保留完整100计划；LegacyPreserved不推测或补发名额。完整批次、名额身份、怪物类型及预选的两类种子识别旧100 / r7扩容100 / 新300合同；缺失、截短或混合计划拒绝。

旧位置按两图边界归一化投影；先试投影点，再按固定网格环搜索合法位置，不消耗玩法随机数。玩家、Boss优先，普通怪物按实例ID确定顺序；预留0.8圆半径及相互占用，普通怪避开安全区。掉落用0.3半径且可重叠。实际Prefab足迹仍在地图资源预热后验证。

位置、行为锚点、有效记忆点 / 闲逛目标、Boss记忆点和固定导航点一并转换。方向、动作 / 冷却余量、资源、词条、物品、状态层、实例代次、分配器和随机状态不重建。已是当前修订时不重复迁移。

## 事务与拒绝
