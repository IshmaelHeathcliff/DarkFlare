# 批量导航与怪物移动

阶段 H 已完成（`0.5.4-alpha`）；实现使用统一网格、共享 Flow Field、受限 A* 池、Spatial Hash 与 Separation。H 的完整矩阵保留为[阶段基线](./acceptance/h/README.md)；`0.5.5-alpha` 的当前组合压力与大规模切图 / 保存见 [I 验收](./acceptance/i/performance.md)，短测不能替代正式矩阵。

## 数据与计算

`NavigationMap` 归 `MapScope`，Session 注册 `NavigationModel / NavigationSystem`。地图准备时复制几何与地形代价到 NativeArray，使用 Burst Job 构建四个圆足迹 Profile：0.30、0.36、0.50、0.75。网格仍为每逻辑格 4×4 子格。配置半径不得小于实际世界圆半径；运行时放大超出配置时停车并报告 BudgetExceeded。

边沿用 `MapGeometrySnapshot.CheckEdge`：八方向，正交 / 对角权重 10 / 14，目标材质决定进入代价；斜角检查两个正交点与完整 swept circle。可走节点与可走边分别编码，因此合法孤立节点不会被误认为障碍。积分使用 ulong，不把大代价与无路哨兵混淆。

反向 Dijkstra 使用对应正向边的目标成本。A* 使用 octile × 最小正地形代价。二者使用索引二叉堆和持久前沿，单批预算分别为 65536 / 8192 次扩展；预算耗尽保持 Pending，只有前沿穷尽才给出 Unreachable。完整场发布前不对 Agent 暴露候选数组。

最多 1024 Agent、8 个共享场、2 个流场工作区、4 个 A* 工作区。A* 最长 4096 个节点，超长返回 BudgetExceeded；不将部分路径冒充成功。共享场按目标语义身份与 Profile 聚合，空闲场按 LRU 回收，有主缓存不强制淘汰。地图准备先按完整缓存、搜索池及 1024 条路径的最坏容量预检，超限不激活。原生容器申请统一经过 128 MiB 门禁，包含切图源图与候选、动态拓扑替换时的同时驻留。

## 目标与固定步

配置默认普通怪物为 Flow Field，铁壳尸傀为 A*。`SetNavigationIntentCommand` 可指定配置默认 / 模式覆盖，以及玩家、同图稳定 Actor、固定点或 None。句柄包含 Session、Map generation 和单调注册序号，重新启用单位后旧句柄失效。显式更换意图撤销原策略关联，迟到搜索不能恢复它。

目标移动时保留已接纳搜索，只合并最新待处理目标，每 100 ms 至多接纳一次同一目标的重建。A* 工作区轮转服务单位，持续移动不反复清空前沿。完整旧目标结果只在同拓扑、同目标身份下短暂使用，500 / 1000 规模分别以 200 / 400 ms 为上限，超过即停车等待。有效窗口从最后一次匹配当前目标的时刻或该结果实际接纳搜索的时刻（取较晚者）计算；静止后刚跨格不会立即过期，发布旧结果也不会重置请求延迟。

地图只启动一个 `UniTaskAsyncEnumerable.EveryUpdate(FixedUpdate)` 驱动，并在物理暂停时立即响应取消。0.6.1 起由 `MonsterBehaviorMap` 先提交动态几何、完成感知与动作决策，再驱动导航集中采样、轮询 / 发布已完成搜索、调度增量搜索和转向 Job。转向依赖明确 Complete 后统一写 Rigidbody2D 速度。怪物 Controller 不运行逐单位导航 FixedUpdate，也不遍历全怪物列表求分离。独立导航夹具仍可使用导航自身驱动，正式地图只启用外部调度。

当前位置与固定目标位置不变时复用合法节点查询；缓存同时核对网格 Revision，意图 / Profile 切换及传送失效会清除缓存。玩家目标按每个 Profile 每步查询一次后共享。缓存不代替行动许可、实际半径和每步 swept circle 检查；方向归一化与接入方向的计算在 Burst 转向中完成。

空间索引按整数格键和运行内稳定怪物序号排序。每 Agent 最多访问 96 个候选，至多采用 24 个邻居；密集桶从稳定轮换偏移开始。同点两方使用同一成对方向的相反向量，避免同向漂移和 NaN。最终速度受移速、行动许可和实际位移安全检查约束。

最新位置、实际半径、步长与静态 / 动态障碍共同决定是否可提交移动。贴墙恢复点不会瞬移到最近格：仅在物理接触容差内允许经过验证、持续增加净空的短段接入；否则停车。眩晕 / 死亡 / 注销清零，传送会撤销旧路径并重新接入。

## 动态阻挡与所有权

`ChangeNavigationStampCommand` 排队到下一物理边界，使用稳定 ID 增删或替换临时矩形。最多 32 个阻挡、1 个待处理请求；同一步的额外请求立即返回 Capacity，可在收到前次结果后重试，保证已接纳的新墙不会因队列积压晚于下一物理步生效。覆盖活跃 Actor 返回 Occupied。相互重叠的 ID 独立持有阻挡，删除一个不会移除其他覆盖。

提交变更前完成相关 Job，原子替换几何与 Physics2D 投影、递增 Revision，并废弃旧场 / 路径。新网格未完成期间停车。容量失败保留旧拓扑；旧修订不能作为新结果发布。临时阻挡不保存，地图释放时销毁。

切图停用源图时取消驱动、完成访问源容器的 Job、清零速度；保留资源供回退。候选地图不注册活跃单位。成功后 Dispose 源图；准备取消、回退和 Session 退出均遵循相同容器所有权。Token 取消不等于中断 Job，释放前始终完成依赖。

## 存档与战斗

Schema 5 在 `MonsterRunStateDto.Navigation` 保存模式覆盖、目标语义、同图身份、固定点及停止距离。历史 4→5 为活动和冻结地图怪物补“配置默认模式 + 玩家目标”，保留身份、属性、掷值、状态与 RNG。未知模式、非法目标形状 / Run 身份和跨图引用在预检拒绝；即使目标声明当前 MapId，只要实际出现在其他冻结图也会拒绝。新命令指定 Actor 时要求它在当前活动图中。恢复已死亡、格式合法且没有跨图归属冲突的身份时可保留意图，运行时为 TargetUnavailable，不擅自换目标。

不保存网格、流场、搜索前沿、路径、速度、缓存或调试阻挡。Schema 6 为正式怪物增加行为状态，恢复后由行为重新产生意图；导航调试接管不跨图保留。正式 `ContactAttackCommand` 只请求前摇动作，命中点再次检查同源几何中心视线，不能隔墙攻击；导航 Tick 已移除直接攻击入口。详见[普通怪物](../behavior/monsters.md)。

## 调试与验证

菜单 `DarkFlare/调试/批量导航` 提供模式 / 目标切换、临时墙、500 / 1000 单位补充、修订 / 队列 / 内存 / 候选统计。SceneView 展示选中单位的完整路径或已发布流场链、足迹、分离半径和空间哈希格；采集只在诊断界面发生，不进入模拟热路径。

修改正式怪物意图须显式接管行为控制权；`SetNavigationIntentCommand(..., takeBehaviorControl: true)` 先注销其自主行为，结束后用“归还怪物行为控制”重新绑定并决策。默认命令拒绝覆盖自主意图。

Profiler 标记为 `DarkFlare.Navigation.Tick` 与 `DarkFlare.Navigation.SteeringWait`。可显式启用 GC.Alloc 当前线程采样，并用 512 B 分配作正向探针；事件 Value 不当作字节，仅在探针有效且区间事件为零时报告 0 B。调试记录默认关闭。

普通怪物在点目标、等待和玩家目标间频繁切换。正式行为实例登记时准备 A* 路径缓冲，此后模式切换只清空路线 / 请求身份，缓冲保留到 Agent 注销或地图释放；未接入行为的实例仍在首次需要 A* 时申请。地图准入原本即预留全部 1024 个 Agent 的路径上限，不扩大容量。无导航目标的样本只提供邻居位置并提交零速度，不读取移动属性或碰撞缩放；重新发起移动后继续使用当前真实形状。边界节点与近目标线段查询复用同一几何算法，通过 Burst 静态入口执行；托管与 Burst 的墙边 / 边界结果有差分回归。实现依据见 [Unity Burst 调用规则](https://docs.unity.com/en-us/engine/6000.6/manual/scripting/compilation-and-code-reload/script-compilation/burst/csharp-language-support)。

NavigationModel 额外区分搜索结果发布、单位采样、搜索调度与转向等待耗时，便于判断热点是否来自长路径、单位采样或 worker 等待；总主线程计时包含这些开销，不把分段 P95 直接相加。

可通行格直接返回当前节点，只有受阻时才进入 Burst 邻域搜索；等待路径的实例不查询尚不会使用的移动许可，得到有效方向后仍在当前步检查许可。搜索任务在本步转向完成后投递，结果仍于后续步骤接收，避免异步搜索与必须立即完成的转向争用 worker。

长期回归覆盖几何差分、非对称代价、预算续算、无路、内存门禁、密集分离、薄墙、贴墙接入、混合策略绕障、状态停止、旧句柄、重叠 stamp、冻结意图和 20 轮释放。实际 Player 性能及其边界另见验收记录。
