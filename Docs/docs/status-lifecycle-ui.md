# 状态时间、保存与查看

状态核心、异常规则分别见[状态系统](./status-system.md)、[异常与来源](./status-ailments.md)。本模块连接 Session、存档和 UI，不改变叠层、抗性或伤害规则。

## 游戏时间

`GameSessionHost` 在 Running Session 启动唯一 `status-clock` UniTask。`StatusTimeDriver` 每帧累积缩放游戏时间；暂停租约、平台挂起和 Session 停止期间不增加时间，不补算离线时间。所有状态共享 `StatusStore` 时钟。

每轮最多处理核心预算允许的事件，`HasPendingTime` 时分帧用零增量续算；新经过的时间保留在 `PendingElapsed`，旧批完成后再提交。积压期间允许登记空目标，但普通状态写入仍返回 Busy。事件排序保存独立目标顺序，恢复后不依赖对象创建次序。

调试窗口通过 Query 显示自动 / 暂停 / 手动模式、时钟和积压。手动 Command 仅在自动驱动未运行或玩法已暂停、没有待提交时间及保存独占时可推进；领域提交门禁仍生效。

## 一致保存与恢复

Schema 3 在 Run 中增加 `StatusSaveDto`。历史 `0 → 1 → 2 → 3` 迁移保留，2 → 3 加入空时钟与状态列表。真实历史格式夹具保留在 Tests/Fixtures/Migration，验证迁移不改写物品、资源或随机数进度。

`IPreparedSessionSnapshotSource.CaptureAsync` 通过 Session 子作用域申请短暂暂停，停止接收新状态时间，离开事件调用栈后分帧结清积压。到无推进、无通知、无排队操作、无未发布事务的边界同步捕获；随后释放暂停，磁盘 IO 不持有暂停。取消或异常同样释放租约；同步 Capture 在忙碌时明确失败。

状态变更与有状态时的自然时间推进都标记 dirty revision；只更新脏标记，不每帧写盘。

DTO 保存冻结规则、每层效果、抵抗前后记录、来源归属、层身份、逻辑施加 / 到期 / 下次跳伤时间及整数跳数。时间均相对同一持久化游戏时钟；采用绝对逻辑时刻避免反复转换剩余时长造成相位漂移。无限时间用 nullable 字段，不写 JSON Infinity。旧 Session generation 不入档；注册序号仅用于对应历史来源，导入时全部重新映射。

恢复预检验证角色关系、状态定义、层数、冻结规则、统一层数值、共享时钟、相位及容量（总 16384 层、单角色 4096 层）。恢复事务先建立角色与装备，导入状态和最终属性投影，再恢复绝对生命 / 魔力以及角色行动时钟。导入不调用普通施加、不重算抵抗、不首跳、不消费随机数；失败回滚整个新 Session。

死亡玩家没有活动状态，恢复时保持死亡清理，复活后重绑。已离场来源的限时效果保留伤害归属，但映射为不可操作当前角色的脱离身份；同名新 Actor 不继承旧来源权限。

## 来源维持合同

`IStatusSourceRestoreProvider` 基于分离 DTO 和内容目录证明来源所有权，预检不得修改正在运行的 Session。默认登记装备提供方：目标必须为玩家自身、来源键必须属于真实已装备物品，且定义仍提供该状态。恢复后装备重建沿用来源键幂等规则，不重复叠层。

新增天赋或光环模块时，应把对应提供方加入保存与恢复共用的策略，并实现该模块的权威重建；本阶段只提供接口和可注入验证接点。未登记提供方的 SourceOwned（例如临时调试来源）明确拒绝保存，不能静默丢弃。Timed / Infinite 无需维持提供方。

## 查看与资源

`GetStatusViewQuery` 返回玩家及当前有效怪物的只读快照；怪物按稳定键排列，名称附身份尾号。目标失效退回玩家。`StatusPanelController` 由菜单持有，在 HUD 右上角显示玩家状态条，在菜单“状态”中显示角色列表和状态图标。

显示档位取自 StatusDefinition：显示不受隐藏开关影响；可隐藏默认显示，可用 HUD / 状态窗口共用的开关隐藏；从不显示不进入这两个界面。开关在当前界面绑定期间保留，界面重建或进入新 Session 时恢复默认，不写入战斗存档。过滤不改变实际层数、属性、计时、驱散或存档；调试核心快照仍可读取全部状态。隐藏最后一个可见状态时显示“当前没有可显示的状态”。

HUD 隐藏开关仅在玩家拥有可隐藏状态时出现；状态窗口始终提供开关。三档规则、输入交互与右上角布局见[补充验收](./assets/acceptance/status-visibility-hud/README.md)。

每定义一个图标，显示持有层数和下一层到期秒数；来源维持 / 无限显示 ∞，详情说明具体生命周期。详情逐层列出实际生效 / 被压制、来源、抵抗后属性与伤害、行动门禁和剩余时间。异常动态值取快照，不使用配置中的固定描述冒充结果。

鼠标悬停或键鼠 / 手柄焦点打开同一浮窗。确认进入详情滚动，方向键滚动，返回先回图标、再关闭状态查看。状态消失时清除浮窗并移至相邻图标或关闭入口；从暂停进入查看保留暂停租约。Gameplay 不启用 UI Navigate，不抢角色移动。

八个正式图标每图一个 96×96 PNG，Sprite Single、PPU64，来自统一暗色像素家族。通过 `DarkFlare-Session-Sprites` Addressables 组和 Session `SpriteAssetLoader` 预热；视图子作用域取消刷新，Session 结束统一释放资源。缺图保留可读名称；倒计时每 100ms 刷新，复用图标节点，不推进玩法时间。资产合同与可见验收见[阶段 4 证据](./assets/acceptance/alpha-0.4-status-lifecycle-ui/README.md)。
