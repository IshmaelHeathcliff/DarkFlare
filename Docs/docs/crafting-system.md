# 打造系统

## 模块职责

打造系统负责在玩家背包内对物品的稀有度和显式前后缀执行随机修改。正式入口只接受物品、操作和范围，不接受具体词条、词条 ID 或索引。

主要入口：

- `ItemRarityRules`：四档稀有度的唯一容量和正常生成范围。
- `CraftingOperations`：无 Model 依赖的随机规划与原子物品状态提交。
- `CraftingSystem`：配置、背包归属、金币、随机根种子和领域事件。
- `CraftItemCommand`：Controller 的唯一写入入口。
- `GetCraftingSnapshotQuery`：物品、14 个操作变体成本及可用性的只读快照。
- `CraftingPanelController`：独立打造槽、背包候选、范围选择和结果反馈。

## 稀有度合同

| 稀有度 | 最大前缀 | 最大后缀 | 正常生成总数 |
| --- | ---: | ---: | ---: |
| 普通 | 0 | 0 | 0 |
| 魔法 | 1 | 1 | 1–2 |
| 稀有 | 3 | 3 | 2–6 |
| 传奇 | 3 | 3 | 4–6 |

`ItemBaseDefinition` 不再保存独立前后缀容量。`ItemGenerator`、掉落、打造、UI 和内容校验都读取 `ItemRarityRules`。随机移除可以让非普通物品低于正常生成下限，并保持原稀有度；只有还原普通会清空全部显式词缀并改回普通。

## 六类操作与价格

| 操作 | 任意 / 无范围 | 精准前缀 | 精准后缀 |
| --- | ---: | ---: | ---: |
| 普通→魔法 | 15 | — | — |
| 魔法→稀有 | 60 | — | — |
| 稀有→传奇 | 160 | — | — |
| 还原普通 | 20 | — | — |
| 随机全部词缀 | 40 | 120 | 120 |
| 随机增加一条 | 60 | 180 | 180 |
| 随机移除一条 | 60 | 180 | 180 |
| 重随一条数值 | 80 | 240 | 240 |

前缀、后缀精准操作统一使用任意范围的 `3×` 价格。范围只约束词缀类型，不锁定具体定义。升阶固定为 `普通 → 魔法 → 稀有 → 传奇`；数值重随可以变高、变低或显示相同。

## 事务规则

`CraftingSystem.Craft` 按以下顺序处理：

1. 检查配置、物品、背包归属、操作可用性和金币。
2. 取得 `GameplayRandomChannel.Crafting` 根种子并派生数量、分布、目标、定义和数值子种子。
3. 生成完整候选，不修改原物品。
4. 按预期 `Revision` 一次性提交稀有度与完整前后缀。
5. 扣除一次金币并发送一次携带 `CraftingResult` 的 `ItemCraftedEvent`。

失败保持物品与金币不变，不发送成功事件。候选生成按权重无放回回溯，并排除等级、标签、类型、非正权重、重复定义和已有互斥组；不存在完整方案时禁止提交半套结果。

## UI 数据与刷新

`GetCraftingSnapshotQuery` 返回：

- 配置是否就绪、当前金币；
- 按背包格子顺序排列的物品；
- 名称、类型、稀有度、前后缀容量、正常总数范围、物品价值和出售价；
- 当前物品 14 个操作变体的动态成本、可用状态和领域失败原因。

`CraftingPanelController` 只发送 `CraftItemCommand(operation, scope, item)`，其中 `item` 必须来自当前打造槽；并订阅背包、金币和打造事件重新查询快照。它不复制候选、容量或成本规则。背包点击只更新详情和“放入”候选，不会直接改变打造目标；拖入打造槽或使用“放入打造槽”按钮才会锁定目标。物品被售出、装备或以其他方式离开玩家背包时，打造槽会在快照刷新时自动清空。

`alpha 0.2.3` 中，打造页的范围说明、成本、失败原因和结果摘要均由 `ui` String Table 格式化。Controller 保存最近一次领域 `CraftingResult`，Locale 变化时仅按该结果和当前槽位状态重绘，不重新执行打造、不重复扣费，也不改变候选或焦点。

打造页物品、属性和词条名称使用正式内容的 `LocalizedContentReference`，快照不缓存最终语言字符串；显示边界与 Key 维护规则见[用户设置与本地化](./infrastructure/user-settings-localization.md)。

打造页直接使用共享玩家 10×6 格子背包，并在右侧提供与背包格基准一致的 2×3（100×152 px）打造槽。鼠标可把背包物品拖入槽位；键盘 / 手柄可以先选中背包物品，再使用“放入打造槽”和“取回物品”按钮。物品放入后从共享背包视图移除，取回时恢复原位置，避免同一物品在槽位和背包中重复显示。页面没有词条列表、具体词条选择或滚动条，只显示槽内目标摘要、升阶 / 还原、任意 / 前缀 / 后缀范围、四项随机操作和最近结果。完整词条仍由唯一顶层浮窗显示；整理或点击背包不会隐式打造，槽位为空时全部打造操作禁用。

## 配置、价值与边界

正式配置为 `Assets/Data/Preset/Crafting/基础打造配置.asset`。内容校验会锁定八个基础价格、`3×` 精准倍率、25 词条完整覆盖，并确保每件正式装备至少有 3 个兼容前缀组和 3 个兼容后缀组。掉落条目必须满足目标稀有度正常生成范围；非法运行时请求不会静默截断。

`ItemValueCalculator` 按基础价值、稀有度和词缀数量计算价值，具体词缀数值尚未进入价格公式。

当前只允许把玩家背包内物品放入打造槽后进行打造；槽位接管该物品的 UI 表现，但不会把物品从 `InventoryModel` 临时移除，也不会释放原背包占格，以保持打造归属校验和原子事务不变。不包含独立通货物品、配方、材料消耗、锁词条、指定词条、撤销或批量打造。打造页只在工作台交互上下文开放。
