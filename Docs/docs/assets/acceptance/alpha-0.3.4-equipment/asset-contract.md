# 十槽装备与空槽图标合同

## 新装备图标家族

- 每件基底一个独立 PNG，不含多个物品展示或备选版本。生成画布统一 1254×1254；交付统一 96×96。生成器不能稳定提供原生 96 画布，因此预先固定全画布 NEAREST 等比导出比例 96/1254；不得按主体边界裁切、平移或逐图调整缩放。
- 首张头盔输出为 RGB 棋盘格背景，透明度检查失败，未导入。重新生成前统一冻结纯绿色底导出步骤：生成背景 RGB (0,255,0)，将 G > 120 且 G > R×1.5 且 G > B×1.5 的像素 Alpha 置零，其余像素 Alpha 255，再执行上述全画布导出。所有新图使用同一阈值，不按单图拟合或裁切；主体禁止绿色材质。原始 RGB、去底 RGBA 和交付 PNG 分别保留审计记录。
- 生成画布主体宽、高各 500–1050 px，至少一轴 900–1050；透明边距至少 100 px，Alpha 加权中心两轴均为 570–684；Alpha 覆盖 0.12–0.65。细长轮廓通过斜放或自然整体姿态容纳，不横向拉伸。
- 导出初稿为最长边 68–81 px；正式装备还必须满足项目既有长期合同 72–80 px。全量回归发现初稿遗漏该更严格约束，锁链腰带、红玉戒指、守护圆盾重新生成后通过；未放宽原测试。两轴视觉中心 43–53，四边至少 7 px 透明边距；原生查看轮廓和材质，与现有图标在相同消费者中比较。
- Sprite Single、Full Rect、PPU 64、中心 Pivot、Point、无压缩 / Mipmap、sRGB、Clamp、Border 0。核对原装备消费者与长期导入测试后，在导入前将初稿 PPU 100 修正为原家族的 64，避免世界掉落缩小。Transform 为 1，不对单件设置额外比例。
- 消费者为掉落、背包、十槽装备、商店、打造、详情及来源行。验收画布 1920×1080；槽位 100×152 / 60×72、网格 48 px、来源缩略图与详情图标均须可辨识。
- 头盔 Pilot 原图通过审计和原生检查后，作为该批不可变风格参考；之后十三件逐张生成和审计，通过后导入。

## 空槽剪影

复用旧武器、身体、戒指语义图。新增头部、手部、腿部、副手、项链、腰带分别一个单图语义图，先完成一个 Pilot 再扩展；复用装备 Pilot 风格但只呈现低细节中性剪影，由运行时低透明度表达空槽。沿用相同画布、导出和导入合同，不烘焙文字、边框或装备稀有度。

按钮和槽位背景复用 0.3.3 的正式底板，不重新生成。所有新图审计、GUID、消费者绑定和最终运行截图在本目录归档；临时替代资源和采集代码验收后删除。
