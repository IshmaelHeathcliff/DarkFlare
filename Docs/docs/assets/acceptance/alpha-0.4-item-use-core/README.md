## 排查与清理

初轮核心失败源于 EditMode 夹具未执行真实角色注册，补齐 CombatModel 登记后通过。全量检查发现新配置缺少内容身份、文档映射和命名空间登记，已补齐相应合同；没有删除或忽略失败测试。复核发现准备期间的无关金币变化可能产生重复余额通知，已在实际提交点捕获余额并补充回归。

新增测试集中在物品使用模块，内容注册与保存恢复扩展原套件。无一次性截图 / 版本核验测试，无临时运行入口；运行时测试配置均清理。Editor 保持 Reload Scene Only（EnterPlayModeOptionsEnabled=true，DisableDomainReload=1）；构建与掉落配置无修改。PlayMode 产生的动态字体噪声单独还原。

实际 API、候选顺序、Session 操作号和通知异常边界见[模块说明](../../../item-use-system.md)，下一步见[统一物品使用总计划](../../../plan/archive/alpha-0.4-usable-items-plan.md)。
