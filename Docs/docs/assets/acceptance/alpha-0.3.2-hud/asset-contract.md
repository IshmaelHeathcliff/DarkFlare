# HUD 仪表底板合同

2026-09-09，在 1920×1080 三语言、Gameplay / 背包 / 三窗线框通过后冻结。

- 家族：HUD 资源仪表底板；生命与法力共用一个中性组件，不制作颜色变体或拼图。
- 参考：已批准的 `Assets/Art/Sprites/UI/Frames/ui_item_window_base.png`，保留文件不变。
- 生成与交付：沿用参考的 1254×1254 完整画布；不得裁切、非等比缩放或按主体重新定尺寸。
- 输出：`Assets/Art/Sprites/UI/Frames/ui_hud_resource_base.png`；一个不带文字、图标、数值和填充条的完整底板。
- 可见范围：全画布 1254×1254，Alpha 覆盖 0.99–1；中心各轴 626–628；刻意全出血、不要求透明边缘。
- 材质：低对比炭黑内底、硬边旧铁框、少量暗金铜角件；不在中区加入徽章或纹理焦点。
- 九宫格：四边 96 源像素；独特角件只在各角 88×88 内，96 切线不穿装饰；长边可拉伸且没有独特元素。沿用既有 Slice Scale 0.125，保护区约 12 屏幕像素。
- 导入：Sprite Single、Full Rect、PPU 100、中心 Pivot、Point、无压缩、无 Mipmap、sRGB、Clamp；不进行人工切图。
- 消费者：`Hud.uss` 的生命 / 法力资源容器，当前实测尺寸 300×136 px；内容内边距 24×16 px。最小 / 常规 300×136，扩展验证 360×136。九宫格仅拉伸安全区域，角部不拉坏。
- 填充与数值：由独立 UI Toolkit ProgressBar / Label 绘制；0%、25%、50%、100% 不修改底板、不拉伸纹理表示进度。
- 每张生成图在导入前执行 Skill 自动审计，随后检查原生图与运行截图；不合格重新生成。Pilot 通过前不扩展家族。
