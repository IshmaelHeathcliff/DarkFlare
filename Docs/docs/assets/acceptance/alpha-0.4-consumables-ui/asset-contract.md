# 消耗品图标合同

正式内容沿用矿石的粗像素、高光和深描边语言；新药水家族独立管理。参考：`Assets/Art/Sprites/Items/Materials/item_forging_ore.png`。状态沿用 `status_equipment_guard.png` 的深色底图标。

图像工具连续两次请求 1024 方形均返回 1254 方形；初稿占比超出原请求，未导入。扩展前以第二张样本修订整个药水家族合同：生成画布固定 1254×1254；有效 alpha 阈值 8，宽 700–850、高 950–1050，中心 x 580–680、y 600–800，四边留空至少 100。所有药水采用同一全画布缩放至 96×96，无裁切、无按主体单独缩放。导出使用最近邻，Sprite Single、Full Rect、中心 Pivot、64 PPU、Point、无压缩、无 mipmap、sRGB。世界 Transform 沿用现有消费者。

每张独立生成、审计、保留透明背景。先审计生命药水样本，再以其作为其余药水的固定参考。状态图标独立沿用 96×96 深色底规格；若生成器输出较大方图，统一全画布缩放，不裁主体。

验收覆盖背包、商店、详情、世界掉落和状态 HUD；界面为 1920×1080 与 1280×720。
