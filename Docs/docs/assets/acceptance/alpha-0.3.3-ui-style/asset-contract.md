## 小型框家族

- 生成与交付均为 1254×1254 完整画布，不裁切或重采样；一个不带文字、图标或物品的组件。
- `ui_control_base.png` 为轻微凸起的中性旧铁按钮底板；`ui_slot_base.png` 为下凹的槽位底板，后者在按钮 Pilot 通过后制作。
- 四边 Border 32；独特角件限定 24×24，32 切线保留 8 源像素安全距离。边缘规则、可伸展，无中段徽章或不规则大纹理。中心接近均匀炭黑，不能使用跨整幅的渐变光斑。
- 全出血、不透明，覆盖 0.99–1，可见宽高 1254，中心各轴 626–628；允许可见内容接触边缘。
- Sprite Single、Full Rect、中心 Pivot、PPU 100、Point、无压缩 / Mipmap、sRGB、Clamp；不建立独立 Addressables 句柄。
- USS Slice Scale 0.125，保护区 4 屏幕像素。按钮最小 24×24，常规 144×32，最大验收 434×52；状态用固定边框颜色与底板 tint，不改变 Transform、布局或命中。图标按钮内图标沿用既有资源。
- 长文本次要操作额外验证约 207×86：前台两按钮等分可用宽度，高度随换行增加，保持内容与面板边界。此为文本布局自适应，不是按下 / 焦点状态缩放；证据见 `front-end-qps-ploc.png`。
- 槽位最小 48×48、常规 60×60、扩展 100×152 与跨格物品；只用于外层槽 / 物品框，不在每个占格上重复厚框。

## 大型面板复用

外窗口和 Shell 继续复用 `ui_item_window_base.png` 的 1254 / Border 96 / Scale 0.125；HUD 资源与轻量提示 / 浮窗按消费者验证复用 `ui_hud_resource_base.png`，其边角保护区约 12 屏幕像素。小型框的 32 Border 不反向修改既有大底板。

图像先通过自动 Alpha / 画布审计，再查看原生与最小 / 最大运行尺寸；九宫格切线穿过独特装饰或纹理变形时重新生成。每张 PNG 独立审计；动态状态没有独特形状时不生成重复图。
