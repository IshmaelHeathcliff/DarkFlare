# alpha 0.1.7 特效 Pilot 与逐帧生成记录

> 状态：四个 Pilot 与剩余 19 帧均已通过量化、原生像素及 Unity 导入检查
> 生成日期：2026-08-12 至 2026-08-13
> 生产方式：内置图像生成 + 本地色键透明化 + 统一整画布导出

## 统一生产合同

- 源画布固定为 1254×1254；交付画布固定为 96×96。
- 全家族只使用一次 `16/209`（约 `0.0765550239`）Lanczos 整画布等比导出，不裁切、不重排、不按主体边界逐图缩放。
- 每张 PNG 只包含一个运行时 Sprite；Unity 自动合同为 Single、64 PPU、Center Pivot、Full Rect、Point、Uncompressed、MipMap Off、Clamp、sRGB、Alpha Is Transparency。
- 透明源使用纯 `#ff00ff` 色键；飞行 Pilot 使用一次 `edge-contract 1` 清除残余边缘色键，其他 Pilot 使用标准 soft matte + despill。
- 两个受击 Pilot 使用中性灰白亮度底图，运行时再根据主伤害类型 Tint；低 Alpha 抗锯齿边缘允许轻微通道偏差，但 Alpha 加权主体保持视觉中性。

- 用户通过四张 Pilot 视觉门禁后，按“不可变 Pilot + 上一张已通过帧”逐张扩展剩余 19 帧；每张先透明化和整画布导出，再独立审计，失败帧不进入下一张的连续性链。

- 四份完整 family report 共覆盖 23 assets / 0 errors / 0 warnings，位于 `reports/`；并排图仅用于本次原生像素复核，保存在忽略的 `Temp/Alpha017Effects/`，不进入生产资产。
