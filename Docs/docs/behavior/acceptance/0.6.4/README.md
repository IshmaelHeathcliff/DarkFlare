# Alpha 0.6.4 手动重置验收

日期：2026-09-23。交付版本 `0.6.4-alpha`，地图 V4、core v10、存档 Schema 9。此记录区分自动化验证与未实测项目。

## 实现结果

- 正常离开、返回和继续游戏保留目标图的名额、怪物、Boss、触发进度、掉落与实例代次。只有传送门的“重置并进入”在二次确认后创建下一代次；普通进入不重置。
- 新代次按正式野外配置恢复 100 个普通怪物名额：入图 20 个、10 处标识清晰的范围触发点各 8 个，另有独立 Boss。玩家资产、其他地图和全局身份序号不随目标图重置。
- 候选图装配后，经 SaveCoordinator 排他租约提交完整世界快照。写盘前明确失败恢复旧图；确认写盘成功才反馈成功和释放旧图。保存结果不可判定时进入 Fatal，不冒险回滚。
- Schema 8→9 为活动图及冻结图补持久实例代次 0，旧档原有生成进度、掉落和 Boss 状态不因迁移刷新。中文与英文传送门选择、确认、成功和保存失败文案已入 Unity Localization 表。
