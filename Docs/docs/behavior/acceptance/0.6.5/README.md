此前环境故障发生在 Unity Addressables 构建准备期间：系统策略禁止 Unity 自带的 `NiceIO.dll` 加载到构建用 `dotnet.exe`，构建报告为 `Unknown` / `NoTarget`，没有生成新 EXE。这不是游戏代码的 Player 运行结果，也不能以 Editor PlayMode 代替。今后仅在用户明确指定 Player 验收时再安排构建及相应 I4/I5 项目。
