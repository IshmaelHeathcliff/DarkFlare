# 物品 UI 工作台

## 模块职责

`GameMenuController` 在同一个 PanelRenderer 中管理独立背包、商店、打造和属性窗口。`OpenWindows` 表示打开集合，`CurrentPage` 表示活动窗口；暂停页面和 Application Shell 的阻挡分别处理。背包可以与商店或打造同时显示，并打开独立属性，关闭一个窗口不关闭另一个。

`ItemWorkspace` 由菜单宿主持有，协调唯一物品高亮、普通 / 对比详情和拖放会话，并保存背包选择与打造槽的表现占用。它不复制领域 Model；宿主持有的 `ItemInteractionSession` 负责单一拖放 / 动作菜单，`ItemActionRouter` 用 Query 预检并通过 Command 提交领域意图。商店与打造在背包关闭时通过 `ItemSourceListView` 呈现自己的玩家物品来源，不依赖隐藏的 `InventoryPanelController` 转接选择、浮窗或焦点。

## 窗口、来源与生命周期

公共皮肤位于 `Components.uss`：装备槽、跨格物品、来源行和打造目标共享内凹底板，详情与操作菜单复用轻量面板。金色只表示共享会话的当前物品；有效 / 无效投放区域在悬停和焦点状态下仍保持语义色及动作文字。背景不产生新的输入节点，窗口尺寸与网格保持原合同。见[组件规范与验收](./ui-component-style.md)。

| 窗口 | 内容与行为 |
| --- | --- |
| 背包 | 十个真实装备槽、10×6 背包、穿脱操作、三主属性摘要与标题栏属性入口。按 `EquipmentSlots.All` 绑定控件，稳定槽位 ID 与视觉顺序独立。 |
| 商店 | 默认联动背包；固定视口内纵向滚动的十列商人网格、价格和买卖按钮。背包同时打开时直接从背包选择出售物品；关闭背包后显示可折叠出售来源。 |
| 打造 | 默认联动背包；2×3 打造槽、放入 / 取回、范围与随机打造操作；关闭背包后显示自己的候选选择器。 |
| 属性 | 独立五组详情、来源与条件解释、滚动和展开；无需世界授权，不参与物品来源或放置。见[属性详情](./attribute-details.md)。 |
| 暂停 | 保存、设置、返回主菜单与继续游戏；可直接从 Gameplay 打开，暂时隐藏并保存物品窗口组合。 |

世界交互请求携带具体 `WorldInteractionTarget`，宿主记录当前 Session 代次。功能窗口与操作提交都校验目标、可见性和授权。顶部商店 / 打造页签仅在当前可打开时显示，不可用时隐藏并退出布局与导航；授权恢复后重新显示。目标禁用、销毁或玩家交互焦点失效时撤销对应功能；关闭最后一个窗口恢复 Gameplay。切换世界目标不保留旧工作台占用，Session 解绑清理事件、捕获和共享状态。

关闭打造窗口解除槽位的表现占用；关闭背包、进入暂停或被 Shell 遮蔽则保留打造目标。原物品始终属于背包并占原格；快捷取回解除占用，拖回新格必须先成功移动，失败仍保留打造目标。物品被售出、装备或移除后，刷新时清除失效目标。

Settings / Modal / Busy 接管时，玩法窗口、详情和拖动图标一起隐藏并取消拖动。上层返回恢复有效组合；底层已关闭则不重开。输入与暂停所有权见[输入与运行时 UI](./input-ui-system.md)。

## 物品操作与导航

同窗导航允许选择屏外商品，选择后 `ScrollTo` 显露目标；跨窗空间邻居只包含滚动视口内实际可见元素，屏外商品不能抢走焦点。扩充商品数量不改变玩家背包容量，交易后的实例 / 邻近恢复会同步滚动。

装备布局以头部、护甲、腰带为中轴，主武器 / 副手在两侧，手部 / 腿部位于两侧下方，项链和双戒指靠近护甲。格基准与物品相同：头手腿 2×2（100×100 px），护甲 / 主武器 / 副手 2×3（100×152 px），项链 1×2（48×100 px），腰带 2×1（100×48 px），戒指 1×1（48×48 px）。空槽图案应用灰阶滤镜并降低不透明度。上下左右由实际矩形确定，槽位为空或装备物品时均可导航。唯一兼容槽可自动确定，多目标戒指仍要求明确目标。

- 鼠标按住并移动超过 10 px 后开始拖动；单击只固定选择。进入拖动后，由覆盖整个窗口组的根节点持有 Pointer Capture。
- 所有物品来源共用一套拖放：背包 / 单窗玩家来源、装备槽、商人网格和打造槽。目标包括背包指定格、兼容装备槽、买入 / 出售区、打造槽 / 取回区及明确丢弃区。背景和窗口外不是丢弃目标。
- 右键按当前可见上下文执行买入、出售、放入、取回或穿脱；普通背包的戒指先打开菜单明确选择左右槽。Enter / 手柄南键打开动作菜单，丢弃始终是明确动作。失败显示本地化原因，不换成其他操作。
- Space / 手柄西键拿起或放置；Cancel 先关闭动作菜单或取消拖动。背包内按格移动，边缘按实际矩形进入兼容装备、交易、打造与丢弃目标；商人和打造槽可反向进入背包指定格。
- 底部操作区显示当前动作、买卖价格和失败原因；动作菜单跳过不可用项，提交后按物品实例或原视觉位置恢复有效焦点。来源失效、关闭 / 暂停、Shell 接管、操作设备断开或 Session 结束均取消未提交操作。菜单外点击只关闭动作菜单，同次松键不穿透到下层物品。
- 四向浏览由宿主统一消费 UI Toolkit 导航事件；按方向、投影重叠和边缘距离选择控件。未对齐目标还需位于对应方向的范围内，避免“向上”跳到几乎同高但很远的侧面控件。
- 隐藏、禁用、零矩形控件不参与导航；列表目标滚动显露后聚焦。左右肩键额外提供窗口循环，不能代替自然跨窗移动。
- 各窗记忆有效焦点，列表按实例 ID 校验选择；来源列表使用刷新代次拒绝旧按钮回调。暂时预览与固定选择共享唯一描边，通用按钮焦点样式不再让旧物品继续高亮。

## 详情与布局

以 1920×1080 为当前验收画布：上沿约 12 px，底部预留约 144 px；背包 / 商店 / 打造统一 560 px、属性 440 px、普通物品详情 400 px，窗口间隔 16 px。窗口组居中，不再常驻预留右侧详情空白。打开商店 / 打造时自动打开背包；背包可单独关闭。背包同时可见时隐藏重复来源列表，关闭背包后恢复独立来源。商店隐藏重复来源摘要，打造隐藏重复价值摘要，背包隐藏与底部动作栏重复的目标 / 反馈行。顶部标签栏关闭一次清理全部窗口、拖放和打造占用，恢复 Gameplay；每个窗口自己的关闭按钮仍只关闭该窗口。

背包与商人保持原占格基准（48 px 格子、4 px 间隔），不为布局裁掉物品。装备区高 316 px，背包主属性摘要紧凑排列，详情进入独立窗口展开和滚动，穿脱操作行与摘要均完整可见。商店出售来源和打造候选可折叠和滚动。装备区仅呈现真实槽位。

普通预览使用一个 `ItemTooltipView`，停靠窗口组外侧，与窗口上沿对齐，全部子元素均输入穿透。详情不显示物品图标。显示时先隐藏参与布局，定位后再显示；详情正文自动撑高，受安全区域约束。四条以上显式词缀使用紧凑排版，完整显示六条词缀。拖动和取消后的防闪现规则继续保留。

按住 `UI/Compare`（默认左 Shift / 手柄左扳机，可重绑定）显示当前物品及兼容槽位已装备物品的并排信息栏；双戒指同时比较左右槽，排除当前物品自身和空槽。对比组居中，每栏通常 360 px，窄屏按组宽约束。松开恢复普通预览，拖放、暂停、关闭、Shell 接管和 Session 结束均清理对比。`ItemWorkspace` 通过宿主 Query 获取装备快照，不直接访问 Model。

三窗两侧空间不足时，物品预览临时替换属性滚动阅读区，并隐藏其被覆盖的分组控件；标题与关闭按钮保留。切回属性焦点结束预览并恢复阅读区，不产生隐藏焦点或第二个物品详情。

主要资源：`GameRoot.uxml`、`ItemWorkbench.uxml`、`Inventory.uxml`、`Shop.uxml`、`Crafting.uxml`、`Attributes.uxml`；`Windows.uss` 与 `Attributes.uss` 定义窗口组合和属性布局。先创建依赖样式再导入 UXML；新增样式时必须核对实际导入结果与运行时布局。

四个窗口共享 `Theme.uss` 引用的正式暗石 / 旧铁底板。九宫格绘制不增加命中节点，角件不占内容区；[UI 组件视觉规范](./ui-component-style.md)记录资产合同与后续家族语义。完整 HUD、按钮 / 槽位 / Shell 皮肤仍属后续阶段。

## 领域边界与验证

UI 通过只读 Query 获取快照，通过 `MoveInventoryItemCommand`、`EquipItemFromGridCommand`、`UnequipItemToGridCommand`、`MoveEquippedItemCommand`、`BuyItemCommand`、`SellItemCommand` 、`DiscardItemCommand` 与 `CraftItemCommand` 提交意图。原子交换、失败回滚、费用和随机规则仍由原有领域模块负责。

长期回归复用 `Phase0ExperiencePlayModeTests`、`Phase1UxPlayModeTests`、`EquipmentPhase2PlayModeTests` 和 Shell / 生命周期用例；几何邻居由 `SpatialNavigationTests` 保护，输入所有权由 `ApplicationInputServiceTests` 保护。布局覆盖 1920×1080 × 中文 / 英文 / Pseudo Locale。临时截图与迁移工具不进入长期测试。[独立窗口证据](./assets/acceptance/alpha-0.3.0-windows/README.md)与[统一物品操作验收](./assets/acceptance/alpha-0.3.0-actions/README.md)分别归档。

指定格购买在发布事件前完成背包、库存和金币提交，失败不自动换格。穿戴入口统一要求旧装备回填来源区域；卸下快捷操作自动寻找合法空位，拖动卸下使用指定格。世界丢弃与拾取的唯一归属规则见[随机化与掉落](./randomization-system.md)。代表视觉组件及布局收尾见[0.3.0 验收证据](./assets/acceptance/alpha-0.3.0-visual-pilot/README.md)。
