# 物品 UI 工作台

## 模块职责

物品 UI 工作台统一承载背包、四槽装备、商店、打造、当前属性和物品详情。界面由一个共享玩家列和一个可切换的右侧上下文组成：扩容后的装备区位于共享列上方，10×6 真实背包位于下方；商店使用同规格的 10×6 固定商人背包，打造显示词缀与操作区。共享列最大占内容区 49%，在商店和打造中不会超过一半。商人背包不使用滚动条，玩家和商人格内都只显示居中的物品图标，名称、价格和属性统一进入信息栏。

运行时只有一个 360×680 固定展开的物品信息浮窗，详情正文不使用滚动容器。浮窗位于菜单面板之外的顶层 overlay，顶部与主菜单面板对齐：玩家背包和打造物品固定停靠左侧，商人物品固定停靠右侧；空间不足时才按屏幕安全边距夹紧或使用另一侧。浮窗不参与主布局宽度分配，也不接管焦点。每次显示都先以 `Visibility.Hidden` 参与布局，计算并写入最终侧边位置后再切为可见，禁止从屏幕中央闪现到左右侧。拖放结束或取消时先隐藏浮窗，直到指针离开并重新悬停或焦点重新进入，避免物品重建后立即遮挡背包。

## 领域边界

- `InventoryGrid` 负责指定坐标放置、移动和单目标交换的预检与提交。
- `MoveInventoryItemCommand` 提交背包内移动或交换。
- `EquipItemFromGridCommand` 从真实来源位置装备物品；替换时旧装备必须能原子回填来源区域。
- `UnequipItemToGridCommand` 将装备精确卸到玩家指定位置。
- `MoveEquippedItemCommand` 处理双戒指槽位移动与交换。
- UI Controller 只提交意图、监听事件和重建快照，不直接修改背包或装备 Model。
- 成功移动发送带前后 `RectInt` 的 `InventoryChangedEvent`；失败和取消不发送领域事件。

## 交互规则

- 鼠标左键按下只建立拖拽候选；持续按住左键并移动超过 `10 px` 阈值后才创建完整占格 ghost。未移动直接松开只固定选择，不会拿起物品；来源保留占位，合法与非法目标使用不同形状和亮度状态。
- 来源按钮只负责识别按下和拖拽阈值，进入拖拽后由工作台根节点统一持有 Pointer Capture，保证跨装备、背包和上下文区域仍能收到移动与抬起。
- 背包物品可精确移动到空位，或与唯一相交物品原子交换；越界、多个相交物或无法回填时整笔失败。
- 背包装备可拖到兼容装备槽；已装备物品可拖回指定背包格；左右戒指槽可移动或交换。
- 玩家与商人背包的物品格只显示图标；物品名称不进入占格按钮，避免单格戒指和长名称越框。
- 商人物品格只读。拖到商人格子、打造操作区或上下文按钮不会触发交易或打造。
- 商店页中右键点击玩家背包物品会直接出售；商人库存右键不触发出售，购买仍使用选择后确认按钮。
- 打造页中，背包点击只选择和预览候选；只有拖入独立打造槽，或使用“放入打造槽”按钮后才建立打造目标。放入后物品按钮从共享背包视图移除，取回后恢复原背包位置；领域层仍保留背包归属与占格，物品真正离开背包时槽位自动失效。
- `Space` / 手柄西侧按钮进入拿起或放置，方向键 / 摇杆移动候选目标，`Escape` / `B` 优先取消拖拽，再按菜单规则关闭。
- 悬停与焦点只改变临时预览，点击或 Submit 固定选择；临时预览会暂时接管唯一选择描边，不能与固定选择同时高亮。菜单每次重新打开都会清空玩家背包固定选择，页面内刷新才按 InstanceId 恢复；默认焦点落在当前页签，没有悬停或物品焦点时浮窗必须隐藏。
- 商店页中，共享玩家背包最右侧物品继续向右导航时，焦点和唯一选择转移到商人背包最左侧的邻近物品。
- 背包物品与装备槽的固定选择高亮互斥：点击背包时只高亮物品，点击装备槽时只高亮槽位；逻辑上的兼容目标仍可保留，但不会造成两个区域同时显示为已选择。
- 浮动物品详情的整个 VisualElement 子树均为输入穿透，不能遮挡其下方的装备槽或物品格命中。

## UI 结构

- `GameRoot.uxml`：菜单外壳、共享模板、全屏 tooltip layer 与 drag layer。
- `ItemWorkbench.uxml`：四槽装备区、两个非交互扩展预留位、玩家背包与统一操作提示。预留位只负责冻结后续扩展空间，不属于运行时装备规则。
- `Inventory.uxml`：当前有效属性、目标槽位、装备/卸下按钮和反馈；不再显示装备比较。
- `Shop.uxml`：固定 10×6 无滚动商人背包、价格与买卖操作。
- `Crafting.uxml`：与背包基准一致的 2×3（100×152 px）独立打造槽、放入 / 取回操作、容量价值和随机打造操作。
- `ItemTooltipView`：唯一详情实例的绑定、玩家左侧/商人右侧语义停靠与安全区夹紧。
- `MerchantGridLayout`：按库存顺序进行确定性行优先虚拟排布，不回写 `EconomyModel`。

视觉使用深色底、暖金强调和 1 px USS 细边框。物品图标、稀有度、焦点、选择、拖拽与落点状态共用同一套样式语言；不依赖旧粗 Frame，不新增 SpriteSheet 或人工切图流程。

物品详情在显式词缀达到 4 条时进入紧凑排版：词条效果内容先显示并使用更高对比度与粗体，前/后缀名缩小为辅助标签；标题、组间距和行高同步压缩。最多 3 前缀 + 3 后缀时仍完整展示全部内容，不通过滚动条或裁切隐藏信息。

装备与背包使用 48 px 格子、4 px 间隔作为统一尺寸基准。武器和护甲槽固定为 100×152，完整覆盖 2×3 格占位；左右戒指槽固定为 60×60，均不小于 1×1 格且横宽比为 1:1。装备图标绝对定位到槽位四边 4 px，槽位名以底部覆盖标签显示，因此文字不会再压缩图标；同一物品装备后的图标可见范围不得小于它在背包占格中的图标。玩家背包面板固定压缩为 408 px，高分辨率下装备面板使用剩余高度；1920×1080 运行时实测装备区约 419 px、背包区 408 px。紧凑布局保留完整 10×6 网格，通过缩减边距和隐藏背包操作提示适配，不缩放物品格。

右侧当前属性卡按 `StatIds.All` 动态生成两列，完整显示 23 项登记属性，并保留固定名称、百分比格式及元素 ID，新增属性时由覆盖率测试要求同步展示定义。

## 响应式与验证

主菜单基准尺寸为 1160×940，限制在屏幕宽 92%、高 96% 内；相较旧布局增加纵向占比并降低横向占比。菜单在 `1280×720`、`1920×1080`、`2560×1440` 下验证关键元素均位于根容器和所属面板内，装备始终位于背包上方，商店 / 打造中的共享列不超过内容区一半，按钮不越框。`1920×1080` 及以上画面额外验证浮窗不与主面板重叠、顶部对齐且位于页面语义指定侧。

自动化覆盖：

- 背包移动、交换、装备替换、精确卸下、戒指交换及失败回滚。
- 商人 10×6 固定格排布确定性、无重叠、无滚动容器与图标中心对齐。
- 输入层的拿起/放置、导航和 Cancel 消费。
- 单一无滚动物品浮窗、共享工作台、背包属性卡和无装备比较的结构约束。
- 商店购买后的邻近选择与焦点恢复，以及三档分辨率布局。
- 真实 Pointer 放下物品后浮窗保持隐藏，下一次主动预览再恢复。
- 无物品悬停时不建立默认选择且浮窗隐藏；浮窗定位完成前保持不可见，避免中央闪现。
- 真实 Mouse Pointer 完整覆盖背包换位、拖到武器槽装备、从武器槽拖回背包。
- 真实 Mouse Pointer 覆盖单击不拿起、背包与装备高亮互斥，以及商店页右键直接出售玩家物品。
- 真实 Mouse Pointer 覆盖背包物品拖入打造槽；另验证点击背包不直接成为打造目标、放入 / 取回按钮和背包移除后的槽位失效。
- 三个右侧上下文模板仅让当前页参与布局，背包、商店、打造页与共享玩家列上下边缘一致。
- 放入打造槽后背包不再重复生成物品按钮，取回后恢复；商店页背包最右侧向右可进入商人背包。
