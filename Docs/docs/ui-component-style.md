# UI 组件视觉规范

## 当前落地范围

Alpha 0.3.0 的代表组件是独立物品窗口底板，使用炭黑内底、旧铁轮廓、少量金铜角部强调。背包、商店和打造共享同一 Sprite，内容、状态与布局继续由 UI Toolkit 管理。完整按钮、槽位、HUD、详情和 Shell 位图家族尚未制作。

`Theme.uss` 持有底板引用及九宫格参数；`Windows.uss` 持有窗口布局。背景不增加 VisualElement，没有新增命中或导航节点。活动窗口仍用既有外边框强调；物品选择和目标区使用独立语义，不能因新皮肤增加第二件选中物品。

## 已验证基础规格

| 项目 | 当前规则 |
| --- | --- |
| 验收画布 | 1920×1080，Panel 坐标与屏幕比例为 1 |
| 窗口宽度 | 背包 560；商店 / 打造 760；窗口间距 16 |
| 窗口高度 | 三语言实测 788–798，窗口组最高至 y=920；装备画布 162，保留 152 px 大槽 |
| 窗口内区 | 内容内边距 12，保留原 2 px 边框盒模型；装饰不扣除额外内容空间 |
| 内容网格 | 背包 10×6，48 px 格子、4 px 间隔；商品维持完整原网格 |
| 底板 | `ui_item_window_base.png`，1254×1254 原图直接导入，无裁切或重采样 |
| 导入 | Sprite Single、Full Rect、Point、PPU 100、中心 Pivot、无压缩、无 Mipmap、sRGB、Clamp |
| 九宫格 | 四边 Border 96 源像素，Slice Scale 0.125；保护区约 12 屏幕像素 |
| 装饰保护 | 角部独特元素在 88×88 内，切线留出至少 8 源像素；中部暗色近均匀，长边无独特纹理 |
| 字体层级 | 窗口标题 20；来源物品与正文通常 16；操作反馈 14；物品详情沿用可完整显示六词缀的布局 |
| 关闭入口 | 36×32 的固定按钮，22×22 既有图标；本地化 tooltip，保留输入和焦点行为 |
| 当前属性摘要 | 整行名称与右侧数值、纵向滚动；名称可换行，穿脱行不被属性区域压缩 |

精确生成约束与量化结果见[资产合同](./assets/acceptance/alpha-0.3.0-visual-pilot/asset-contract.md)及[单图 manifest](./assets/acceptance/alpha-0.3.0-visual-pilot/panel-manifest.json)。源图较大不代表边框使用同样粗的屏幕尺寸；UI Slice Scale 与 PPU 分别记录，不能互相替代。

## 状态语义与后续家族

| 状态 / 组件 | 语义与实现边界 |
| --- | --- |
| Default | 炭黑底、低明度旧铁边；金铜装饰保持弱于交互焦点 |
| Hover | 普通按钮底色响应鼠标；物品预览交由唯一共享会话 |
| Pressed | 明确的按压反馈，不改变控件布局；后续皮肤不使用缩放掩盖资产尺寸 |
| Selected | 当前操作物品的唯一描边；多个来源视图不得同时画出选中 |
| Focused | 普通控件可辨识的键鼠 / 手柄焦点；物品焦点服从共享选择，不另加通用边框 |
| Disabled | 文字、底色和可交互状态同时表达；不可用商店 / 打造页签隐藏，不作为禁用装饰保留 |
| 拖放目标 | 有效 / 无效区域提示保留绿色 / 红色与动作文字，不将第二件物品画成选中 |
| 面板和分区 | 外框建立轮廓，内部标题和分隔轻量；标题、关闭按钮和正文保持独立控件 |
| 槽位与详情 | 后续沿用同样材质、像素颗粒与信息层级，具体 PNG 画布 / Border 必须按实际消费者另行冻结 |
| HUD | 生命红、法力蓝；只呈现已有资源、自动攻击状态和有效入口；Reduce Motion 关闭非必要动效 |
| Shell | 0.3.3 复用共同材质和基础状态，保留 Settings / Modal 的输入和暂停所有权 |

以上是状态职责，不表示已生成每个状态的位图。新家族先产单个 Pilot，再逐张生成一个组件或状态，不能将参考板切成生产资源。

## 后续布局参考

独立属性详情与底部资源仪表已有临时运行时线框，见[验收目录](./assets/acceptance/alpha-0.3.0-visual-pilot/README.md)。属性按资源、基础 / 移动、攻击、防御、修改器分组；线框不包含新 Query、战斗公式或综合战力。

底部约 160 px 的预留区可容纳双资源容器与技能 / 窗口入口区。优先推荐横向切角容器：数值和原因文字较易保持同一阅读方向。圆形方案也保留比较证据，但正式数字应放在稳定的可读区域，不能依赖圆内狭小宽度。正式 HUD 外形、资源填充和异常反馈在 0.3.2 验证。

十槽只完成此前空间线框；真实装备控件、内容和导航扩展仍属于 0.3.4。临时线框与采集对象不进入生产场景。
