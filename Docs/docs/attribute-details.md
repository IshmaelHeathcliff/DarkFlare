# 独立属性详情

HUD 共用 `GetAttributeRuntimeQuery` 的资源 / 技能状态，运行快照提供技能 ID、耗蓝、间隔和归一化剩余冷却；间隔为零时比例为零。此查询不推进时钟或重建完整来源解释，见[战斗 HUD](./hud-system.md)。

## 职责与入口

`GameMenuController` 管理独立属性窗口，背包标题栏图标、HUD 按钮和菜单页签打开同一窗口。属性无需世界目标，可单独显示或与背包、商店 / 打造并排；交易与打造仍校验各自授权。背包只保留力量、敏捷、智力摘要。

`AttributePanelController` 是菜单的 SceneSessionBinding 所有的普通 `IController`。它查询数据、订阅事件和管理文本，不持有独立输入 / 暂停 lease，不发送领域事件。属性不参与物品来源、放置目标或拖放事务。

## 数据与解释

| 入口 | 合同 |
| --- | --- |
| `CombatActor.CaptureBaseStats` / `StatsRevision` | 返回基础属性副本；正式重建后递增修订号，避免将上次派生值再次作为输入 |
| `EquipmentEffectResolver` / `ModifierOrigin` | 在收集隐式、前缀、后缀时记录物品 ID、装备槽和本地化物品 / 词条身份；不靠数值猜来源 |
| `CombatStatResolver.Build` 可选 trace | 与实际聚合共用 Flat / Override 顺序、Increase 合计、逐项 More 和主属性派生；UI 不复制公式 |
| `GetAttributeDetailsQuery` | 只读属性、步骤、修改器和配置基础伤害范围；不暴露装备实例、可写 Model 或原始列表 |
| `GetAttributeRuntimeQuery` | 轻量读取生命、法力、恢复能力、剩余间隔、资源 / 技能状态与属性修订号 |
| `PlayerSkillStateRegistry` | Session System 登记 PlayerController 的技能状态读取器；OnEnable 注册、OnDisable 注销、Session 销毁清空；仅读取现有冷却时钟 |

资源、基础与移动、攻击、防御、修改器五组可折叠；单项可展开基础值、计算步骤、聚合值、生效值及来源。修改器按属性 ID 与 Scope 分组，显示操作、必需 / 任一 / 排除标签和标签作用域。ModifierOrigin 区分装备、怪物词条、状态和兼容角色来源。状态展示定义 ID 与有效层数，Increase / More 计算步骤保留来源；条件解释读取同一角色标签，见[状态战斗接入](./status-combat.md)。

`CombatStatValues` 与正式消费者共享暴击率 0–100%、抗性 -100–75% 和暴击倍率边界。额外暴伤 50% 对应最终 1.5 倍。法力恢复复用正式恢复 System 的计算；移动、主属性和额外暴伤不统一强制非负。生命 / 法力上限读取 Actor 的有效上限。

直接属性仅将当前解析器消费且条件匹配的修改器标为生效。攻击伤害修改器显示需要攻击或目标上下文；未消费的操作或 Scope 显示不支持。基础伤害是武器 / 技能配置范围，不是最终命中范围；命中、闪避和护甲减伤依赖目标 / 来袭伤害，不生成模拟 DPS 或虚构百分比。

打开窗口会暂停玩法：恢复能力仍显示正常每秒数值，另标注暂停，冷却不随现实时间推进。无玩家、无有效伤害来源、法力不足、死亡、禁用、资源已满均有状态说明。Query 不发起攻击、不推进任何具名随机通道、不改变装备或资源。

## 刷新与生命周期

- 打开时立即获取详情；装备、Actor 注册 / 注销使静态解释失效。资源、死亡和复活事件更新动态区。
- 可见时每 200 ms 使用不受 TimeScale 影响的 UniTask 更新动态值；检测 StatsRevision 变化才重建解释。当前没有技能配置切换功能，技能间隔 / 来源配置在打开时读取，剩余间隔由动态 Query 读取。
- 刷新任务归属 Scene scope 的 `attribute-window` 子作用域；隐藏、解绑和 Session 结束取消，任务失败走既有生命周期报告。
- Locale 改变只重新解析文本，保留折叠、滚动和焦点；静态重建按稳定控件名称恢复有效焦点和阅读位置。
- 文本使用 `ui`、`stats`、`items`、`affixes` 等现有 Localization 表。技能名称使用 `ui:attributes.skill.{技能ID}`；新增正式技能时补齐对应条目。

## 布局与输入

正式画布为 1920×1080。属性宽 440 px，背包 560 px，商店 / 打造 760 px，间隔 16 px；三窗不缩小物品格子。属性单窗居中，与其他窗口并排时顶部 / 底部对齐。折叠行与解释允许换行，滚动条使用同一深色主题。

窗口关闭、组标题和单项展开参与既有四向空间导航，纯说明文字不抢焦点；边缘可以跨窗，焦点滚动显露。Settings / Modal / Busy 接管时与其他玩法窗口一起隐藏，取消返回恢复有效组合，最后一个窗口关闭才释放菜单暂停。

物品预览优先停靠窗口组外侧。三窗两侧空间不足时，唯一物品详情临时替换属性滚动阅读区；属性标题与关闭按钮保持可访问。此时组标题随阅读区隐藏，避免产生被覆盖的焦点；重新聚焦 / 进入属性窗口会结束物品预览，恢复原阅读内容与滚动位置。物品详情不成为拖放目标。
