# 物品使用配置

使用能力独立于物品类型、堆叠性和消耗性，实际行为见[统一使用模块](../item-use-system.md)。当前提供运行时核心，尚未添加正式药水资产、商品或 UI。

## ItemUseDefinition

创建菜单 `DarkFlare/Data/Items/Item Use Definition`，由 ItemBaseDefinition.UseDefinition 引用。正式资产使用 `item_use:<id>` 内容身份，随内容目录登记和物品依赖加载；本阶段无正式预设。旧物品的空引用继续表示不可主动使用，不升级存档 Schema。

| 字段 | 类型 / 默认 | 约束 | 消费者与兼容 |
| --- | --- | --- | --- |
| `_id` | `string` / 空 | 必填，合法小写 snake_case | 内容注册、校验；发布后稳定，不存入物品实例 DTO |
| `_consumeCount` | `int` / 1 | 0–物品有效堆叠上限；大于 0 必须有消耗资格 | 精确扣选中实例；0 表示使用不消耗 |
| `_effects` | `List<ItemUseEffect>` / 空 | 1–64 项，无空项，配置顺序有意义 | 候选上下文顺序模拟；全部无变化不扣除，非法项整次拒绝 |

`EquipmentConfigurationValidator` 调用能力校验；正式 Session 还验证所用物品和状态在内容目录中。配置在 Prepare 时读取并冻结为候选结果，提交时再次检查能力引用与消费资格。变更配置不能重写已经存在的状态快照。

正式样例：生命药水回血 40、法力药水回蓝 60、坚韧药剂施加 30 秒最大生命 +20% 状态、净化药剂回血 20 后驱散异常；均每次消耗 1，物品可堆叠 10。完整获得路径和 UI 见[消耗品模块](../consumables.md)。

## ItemUseEffect

嵌套于使用能力。首期目标为使用者自身；类型包括恢复生命、恢复法力、临时状态、驱散异常。

| 字段 | 类型 / 默认 | 约束 | 消费者与兼容 |
| --- | --- | --- | --- |
| `_kind` | `ItemUseEffectKind` / Heal | 必须为已定义类型 | 决定候选效果处理 |
| `_recoveryMode` | `ItemRecoveryMode` / Fixed | Fixed 或 Percent | Percent 按 0–100 百分比单位配置，允许超过 100，恢复仍裁剪到上限 |
| `_amount` | `float` / 0 | 有限、非负；计算溢出拒绝 | 恢复执行时的候选上限用于百分比，复用角色资源裁剪规则 |
| `_status` | `StatusDefinition` / 空 | 施加时必填且必须 Timed；驱散时可空 | 施加沿用状态时长 / 刷新 / 抗性；驱散为空表示不限异常定义 |
| `_count` | `int` / 1 | 1–4096 | 施加层数或最多驱散层数；驱散仍遵守可驱散标记 |
| `_tags` | `List<TagDefinition>` / 空 | 非空引用、合法标签 ID | 驱散要求全部标签且类别为 Ailment，不驱散有益状态 |

来源属性和目标抵抗读取施加准备时的真实角色快照，同次前置增益不重复放大来源；效果随机种子使用物品 Seed 加效果下标，反复预览不推进随机通道。资源上限随候选状态顺序变化：先提升上限再固定恢复，与先恢复再按比例提升上限，结果可不同。

完全抵抗视为该项无变化；与有效恢复组合仍可成功。状态规则冲突、满层拒绝、非法引用等保留结构化 StatusCode 并整次拒绝。临时状态来源记录物品实例与操作身份；物品耗尽后状态仍按独立时长存续。
