# 视觉规范
## 适用范围

本文定义初版体验优化阶段 0 与阶段 0.5 的视觉基线，先服务于 `Main.unity` 的垂直切片。当前规范用于验证资源生产与 Unity 接入，不代表后续全部内容已经完成。

风格参考图见 [阶段 0 风格板](./assets/visual-style/phase-0-style-board.png)，具体资源规格见 [视觉资产清单](./visual-assets.md)。

## 视觉方向

- 视角：2D 俯视 3/4，世界物件保持统一的左上方冷光与右下方暗部。
- 风格：暗色奇幻、低分辨率手绘、像素化硬边；强调轮廓和材质块面，不追求细碎写实纹理。
- 氛围：冷灰、低饱和、压暗背景；角色、敌人、交互物和技能效果通过有限高亮建立层级。
- 可读性：玩家、怪物、交互物必须同时依靠轮廓、明度和局部色彩区分，不能只依靠色相。

## 色板

| 用途 | 色值 | 规则 |
| --- | --- | --- |
| 深色背景 | `#111821` | 场景暗部、菜单遮罩 |
| 冷灰地表 | `#26313A` | 石材和主要面板 |
| 灰色细节 | `#59616A` | 边缘、禁用状态和次要文字 |
| 玩家识别色 | `#35B9A5` | 披风、焦点和正向反馈 |
| 怪物识别色 | `#C64B3C` | 裂隙、危险和负向反馈 |
| 交互金铜 | `#B58A45` | 商人、打造、边角和稀有标记 |
| 技能青光 | `#62D8FF` | 投射物和短时技能反馈 |
| 正文 | `#E6E8E9` | 主要文字和高对比图标 |

场景大面积区域只使用背景、地表和灰色细节。识别色只用于信息焦点，避免整屏高饱和。

## 世界 Sprite 规格

| 类型 | 画布 | PPU | Pivot | Filter | 压缩 |
| --- | --- | --- | --- | --- | --- |
| 地表切片 | 512×512 | 64 | Center | Point | None |
| 角色单帧 | 96×96 | 64 | `(0.5, 0.12)` | Point | None |
| 怪物单帧 | 96×96 | 64 | `(0.5, 0.12)` | Point | None |
| 投射物 | 64×64 | 64 | Center | Point | None |
| 物品图标 | 64×64 | 64 | Center | Point | None |

- 角色动画默认 10 FPS；Idle 允许 4 帧，Move 使用 4 帧。
- 玩家先验证四方向共用轮廓与水平翻转；怪物阶段 0 使用左右翻转。
- 角色脚底、武器握点和主要体块在相邻帧中不得漂移。
- 世界排序先沿用 Default Sorting Layer，通过 Sorting Order 保证地表 < 掉落 < 角色 < 特效；批量生产前再评估是否拆分 Sorting Layer。

## 动画状态

| 状态 | 阶段 0 接入 | 验收重点 |
| --- | --- | --- |
| Idle | 运行时 | 呼吸幅度小、脚底稳定 |
| Move | 运行时 | 步幅可读、移动方向一致 |
| Attack / Cast | 预览 | 武器或施法方向稳定 |
| Hit | 预览 | 轮廓收缩且不依赖纯红闪 |
| Death | 预览 | 明确失去战斗姿态，避免与 Idle 混淆 |

## 阶段 0.5 运动、边界与掉落基线

- 玩家移动使用 `Rigidbody2D.Interpolate` 衔接物理帧与渲染帧；相机保留 `LateUpdate + SmoothDamp`，切换目标时必须清空旧平滑速度。
- 当前不挂 Pixel Perfect Camera，也不引入 Cinemachine。只有原生输出再次出现非整数采样问题时才重新评估。
- `Main.unity` 的 `WorldBounds` 是物理边界、相机范围和怪物生成范围的共同来源；视觉地表必须继续覆盖镜头边界之外。
- 世界掉落排序为地表 < 投影 / 稀有度框 < 图标 < 标签。悬浮和呼吸只修改视觉子节点，不移动根碰撞体。
- 掉落至少同时使用图标轮廓、框体形状、稀有度颜色和中文名称；稀有度不得只依赖颜色。

## UI 规格

- 背包面板使用深石板底、铁质边框和克制的金铜角件。
- 基础间距按 4 px 倍数；格子基线维持 48 px，不改变现有 10×6 布局逻辑。
- 普通、悬停、焦点、选中、禁用至少具有边框粗细、亮度或角标差异。
- 键鼠悬停与手柄焦点可以共用强调色，但焦点必须在没有鼠标时持续可见。
- 稀有度除颜色外增加边框或角标；阶段 0 的大剑使用金铜角标验证该规则。
- UI 位图只承担纹理和装饰，文字、布局、交互状态仍由 UXML / USS 管理。

## 命名与目录

```text
Assets/Art/
  Animations/
    Clips/
    Controllers/
  Sprites/
    Environment/VisualSlice/
    Characters/Player/
    Characters/Monsters/Basic/
    Items/Equipment/

```

- Sprite：`{domain}_{subject}_{state}_{direction}_{index}.png`。
- Clip：`{Subject}_{State}.anim`。
- Animator Controller：`{Subject}.controller`。
- UI 纹理：`ui_{component}_{variant}.png`。
- 不删除 `PrototypeSquare.png`；完成回归后仍作为原型回退资源保留。

## 生成基线

- 生成模式：内置 imagegen。
- 风格板用途：统一地图、玩家、怪物、投射物、大剑和背包面板的材质、轮廓与色彩。
- 透明 Sprite：先生成均匀色键背景，再在本地移除背景并验证 Alpha。
- 生成提示词与最终文件路径记录在 [视觉资产清单](./visual-assets.md)。
