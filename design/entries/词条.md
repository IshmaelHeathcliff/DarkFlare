# 词条

词条为物品提供随机修改器；基础物品还可以自带固定的固有修改器。本页先记录当前实际规则，再保留旧案数值作为未实现候选，避免将未来设想误写成现行玩法。

## 当前词条形态

- 随机词条分为前缀与后缀，分别占用基础物品规定的数量上限。
- 固有修改器直接配置在基础物品上，生成物品时固定创建，并在物品详情中单独显示。
- 虽然词条类型中保留了“固有”枚举，但当前运行流程不会把固有词条作为随机词条加入物品；固有能力应继续配置在基础物品上。

## 当前数据结构

每个随机词条包含：

| 字段 | 当前含义 |
| --- | --- |
| 稳定 ID | 唯一英文标识；当前资产尚未统一命名风格 |
| 中文名 | 物品详情中显示的词条名称 |
| 词条类型 | 前缀或后缀 |
| 互斥组 | 非空时，同一物品不能同时拥有相同组的词条 |
| 最低物品等级 | 低于该等级的物品不能生成此词条 |
| 权重 | 大于 0 时参与同池加权随机 |
| 允许物品标签 | 非空时，物品至少拥有其中一个标签 |
| 禁止物品标签 | 物品拥有任意一个时排除该词条 |
| 修改器列表 | 一个词条可以同时产生多个数值修改器 |

每个修改器包含目标属性、计算方式、作用域、数值范围、伤害类型映射、必须标签与禁止标签。当前没有词条自身 `Tags`、`AnyTags` 或多档 `Tier` 字段。

## 当前生成规则

- 掉落条目直接指定物品稀有度、前缀数量和后缀数量；稀有度本身不会自动决定词条数量。
- 请求数量会被基础物品的前后缀上限截断。当前三件基础物品均最多拥有 3 个前缀和 3 个后缀。
- 候选词条必须类型相符、权重大于 0、达到最低物品等级，并通过允许与禁止物品标签筛选。
- 候选词条按权重加权随机。同一次生成不会重复选择同一个词条定义。
- 非空互斥组由物品实例阻止重复；当前两个词条的互斥组均为空，因此没有实际互斥关系。
- 数值范围内使用连续随机值，不是等概率整数。
- 当前没有 T3、T2、T1 等词条档级。打造中的“升级词条”只在同一词条、同一数值范围内重新随机，并且仅在修改器数值总和变大时成功。

## 当前计算方式

| 计算方式 | 当前状态 |
| --- | --- |
| 附加值 `Flat` | 已支持普通属性与伤害 |
| 提高值 `Increase` | 已支持普通属性、伤害与承受伤害 |
| 总增值 `More` | 已支持普通属性、伤害与承受伤害 |
| 覆盖值 `Override` | 已支持非伤害的角色全局属性 |
| 伤害转换 `Conversion` | 已支持伤害管线 |
| 额外获得 `GainAsExtra` | 已支持伤害管线 |
| 概率 `Chance` | 仅保留类型，尚无效果处理 |
| 触发 `Trigger` | 仅保留类型，尚无效果处理 |
| 限制 `Limit` | 仅保留类型，尚无效果处理 |

## 当前作用域

| 作用域 | 当前状态 |
| --- | --- |
| 角色全局 `GlobalActor` | 已支持；非伤害属性进入角色属性，伤害属性进入攻击结算 |
| 物品局部 `LocalItem` | 已支持武器局部伤害；非武器装备上的局部修改器会被忽略 |
| 技能 `Skill` | 可进入攻击伤害结算，当前没有正式词条内容 |
| 目标承受 `TargetTaken` | 支持以提高值或总增值修改承受伤害，当前没有正式词条内容 |
| 区域 `Area` | 尚未形成装备到玩法的完整生效流程 |
| 临时 `Temporary` | 尚未形成装备到玩法的完整生效流程 |

## 当前已配置词条

| 稳定 ID | 中文名 | 类型 | 条件 | 修改器 |
| --- | --- | --- | --- | --- |
| `DamageIncrease` | 基础伤害提高 | 前缀 | 最低物品等级 1、权重 100、适用所有当前物品 | `damage` 提高 10%～30%，角色全局 |
| `HealthAdd` | 生命增加 | 后缀 | 最低物品等级 1、权重 100、适用所有当前物品 | `max_health` 附加 20～50，角色全局 |

两个词条均没有互斥组、允许或禁止物品标签，也没有生效上下文标签。因此当前掉落中任何基础物品都能获得“基础伤害提高”和“生命增加”。

| 物品 | 当前内容 |

三件物品的物品标签目前均为空。

## 当前掉落与打造

### 怪物掉落

- 基础怪物掉落率为 35%。
- 大剑、皮甲、铁指环权重相同。
- 大剑掉落为魔法稀有度；皮甲和铁指环掉落为普通稀有度。
- 三种掉落都请求 1 个前缀和 1 个后缀。
- 当前掉落池只有一个前缀和一个后缀，因此成功生成时词条名称固定，只有数值随机。
- 普通稀有度目前同样可以拥有前后缀；这是当前配置事实，不应沿用“普通装备没有词条”的常见默认认知。

### 打造

| 操作 | 金币成本 | 当前行为 |
| --- | ---: | --- |
| 添加词条 | 20 | 从打造池添加一个仍有栏位的随机词条 |
| 重随机全部 | 40 | 保持前后缀数量，重新生成全部词条 |
| 移除并重随机 | 30 | 以相同词条类型替换选中词条 |
| 升级词条 | 25 | 在同一定义范围内重随机，只有总值更高才成功 |

当前打造池只有“基础伤害提高”前缀。因缺少后缀候选，对带后缀物品执行“重随机全部”或重随机后缀时会失败并恢复原词条。这是当前内容缺口，不是预期的完整打造体验。

由于“基础伤害提高”的互斥组为空，重复执行“添加词条”可以在前缀栏位未满时加入多个同名词条；初次掉落生成不会重复选择同一词条定义，但打造添加不具备这项去重规则。

## 已决定

- 当前正式词条池仅包含“基础伤害提高”和“生命增加”。
- 固有修改器与随机前后缀分开处理。
- 候选词条在属性、标签、触发或状态依赖未完成前不得加入正式掉落池。

## 待验证

- 稀有度与词条数量之间的正式规则；当前数量完全由掉落条目指定。
- 词条档级采用独立定义还是扩展数据结构。
- 当前两个空互斥组是否应补充，以验证互斥规则。
- 打造池是否应与掉落池一致，至少提供一个可用后缀。

## 开放问题

- 普通稀有度是否允许拥有随机词条。
- 物品类型筛选最终依赖标签、装备槽还是两者组合。
- “升级词条”应提高数值、提升档级，还是允许二者并存。
