# DarkFlare

受流放之路、塔科夫、DND、Roguelite等类型游戏启发的一款刷宝、背包管理、跑商经营类RPG游戏。
游戏有和平模式、标准模式、地狱模式等，会很大程度影响游戏游玩方式。
游戏的重复游玩性上，将在和平模式以外设置一个游戏时间限制。
游戏背景设定为在魔王即将毁灭世界的前夕不断轮回，角色应尽力成长从而尝试在末日来临前击败魔王。
每局游戏的平均时长目标为10到20小时，游戏结束后，玩家的剩余资产将转化为局外成长点数，之后的游戏可消耗成长点数解锁更多的选择和提供更多的初始资源。

## 主要玩法

- 刷宝养成
- 背包管理
- 装备制作
- 跑商交易

## 里程碑

### 最小循环

在一个场景里完成基础的刷怪、掉落、装备、交易、打造。

### 原型

- 城镇与野外两个场景切换
- 完整登录、开始游戏、存档
- 仓库与资源
- 技能与天赋
- 怪物与Boss

### EA

- 经济系统
- 公会与家园
- 经济与交易
